# 상업용 헬스장 머신 — 범용(브랜드 무관) 목록 리서치 노트

작성: 2026-11-20 · 대상: 마이로그 운동 기록 앱 (한국 사용자)
표기: **[출처 N]** = 하단 출처 번호, **[추론]** = 출처로 확인 못 한 일반 지식/추정. 근육명은 한국어(영문).

## 0. 요약 (앱 설계에 바로 쓰는 결론)

1. 브랜드가 달라도 **"동작 + 부하 방식"**만 같으면 같은 범용 머신으로 묶을 수 있다. 아래 1장 목록(약 60종)을 기본 카탈로그로 쓴다.
2. 머신마다 **부하 방식**(스택/플레이트/케이블/가이드 바/맨몸)과 **좌우 방식**(양손 함께/좌우 독립)을 필드로 둔다. 기록 무게 기준(한쪽/합계)은 사용자가 고르게 하되, 머신마다 기본값을 둔다.
3. 스택 숫자는 실제 저항이 아니다(캠·도르래 비율, 시작 저항 때문). **같은 머신 안에서만 비교하는 게 정확하다.** 다른 브랜드끼리는 대략적인 비교만 가능하다. [출처 13, 11]
4. 한국 헬스장에는 kg 머신과 lb 머신(수입품)이 섞여 있다. **기록할 때 사용자가 단위를 고르게 하고, 원래 값과 단위를 그대로 저장한다.** 표시할 때만 환산한다.

## 2. 부하 방식과 좌우 독립 여부

| 부하 방식 | 대표 머신 | 무게 읽는 법 | 좌우 | 기록 기본값 제안 |
|---|---|---|---|---|
| 셀렉터라이즈드(스택+핀) | 레그 익스텐션·컬, 펙덱, 어덕션·어브덕션, 체스트·숄더 프레스(스택형), 랫풀다운 | 핀 꽂은 플레이트 번호/숫자 + 애드온(보조추) | 대부분 B | **스택에 표시된 숫자**(+애드온) |
| 플레이트 로딩 | 45도 레그프레스, 핵, V/펜듈럼/벨트 스쿼트, T바, 해머 아이소 계열 | 꽂은 원판 합계 (+슬레드 무게?) | 해머 아이소는 I [출처 6] | 원판 합계. 슬레드 포함 여부는 옵션(4장) |
| 케이블 | 크로스오버, 펑셔널 트레이너 | 스택 숫자 | 스택 2개면 I | **한쪽 스택 숫자**. 도르래 비율(2:1, 4:1) 때문에 실제 저항이 다름 [추론] |
| 가이드 바(스미스) | 스미스 머신 | 원판 합계 + 바 | B | 원판 합계. 바 무게는 기종마다 다르고 카운터밸런스형도 있음 → 옵션 [추론] |
| 맨몸/보조 | 어시스트 풀업, 로만체어, 캡틴스 체어 | 보조량 또는 추가 원판 | B | 어시스트는 **보조 무게**로 저장하고 "적을수록 어려움" 표시 [추론] |

**좌우 독립(아이소래터럴) 머신:** Hammer Strength Iso-Lateral 라인(Bench Press, Horizontal Bench, Decline, Wide Chest, Chest/Back, Row, Low Row, High Row, D.Y. Row, Front Lat Pulldown 등)은 좌우 암이 따로 움직이고 원판 혼도 따로 있다. [출처 6] Matrix Ultra Independent Biceps Curl, Diverging Seated Row 같은 스택형 독립 암 머신도 있다. [출처 9]

**한쪽 기준 vs 합계:** 업계 표준은 없다.
- 플레이트 아이소 머신은 "한쪽에 20kg 2장"처럼 **한쪽 기준**으로 말하는 경우가 많다.
- 제조사 스펙은 시작 저항을 "per arm"(한 팔당)으로 적기도 하고 "total"(합계)로 적기도 한다(예: HS Pendulum-X 81 lb per arm, Cybex T-Bar 41 lb total). [출처 14]

그래서 **기록 필드에 `per_side | total`을 명시**해야 나중에 기록끼리 비교할 수 있다. [추론]

**정리**
- lb 계열 머신은 **10 lb(4.5 kg) 플레이트 + 5 lb(2.3 kg) 미세 증량**, kg 계열 머신은 **5 kg 플레이트 + 2.5 kg 미세 증량**이 흔하다. [출처 8, 9, 11, 16] (5 kg 플레이트는 일부만 확인, 나머지는 [추론])
- lb 머신에 kg를 같이 적을 때는 반올림된 값이 붙는다(10 lb → "4.5 kg", 5 lb → "2.3 kg"). 그래서 같은 머신이라도 라벨 단위에 따라 숫자가 다르다. [출처 9]
- **스택 숫자는 실제 저항이 아니다.** 캠·레버·도르래 비율 때문에 같은 숫자라도 머신마다 체감이 다르다. Life Fitness도 같은 원판이 기계 설계에 따라 다른 저항을 낸다고 설명한다. 45도 레그프레스는 대략 "원판의 약 70% + 슬레드" 정도로 본다. [출처 13] 그래서 **브랜드 간 비교는 대략적으로만** 하고, 진척도 그래프는 같은 머신 기록끼리 그리는 게 맞다. [추론]

## 5. 한국의 단위 사정

| 항목 | 내용 | 출처 |
|---|---|---|
| 법정 단위 | 한국의 법정 질량 단위는 kg이다. 파운드는 비법정단위지만, 단속은 사실상 평·돈 위주였다. 운동기구 표기를 직접 규제하는 조항은 못 찾음 | [출처 21] |
| 헬스장 현실 | 국산 머신과 유럽 브랜드(Technogym, Panatta)는 kg, 미국계(Hammer Strength, Cybex, Matrix, Precor, Life Fitness 일부)는 lb 또는 병기다. **한 헬스장 안에 두 단위가 섞여 있다** | [출처 8–11, 15, 16] · 섞여 있다는 부분은 [추론] |
| kg 원판 | 1.25 / 2.5 / 5 / 10 / 15 / 20 / 25 kg | [출처 22] |
| lb 원판 | 2.5 / 5 / 10 / 25 / 35 / 45 lb | [출처 22] |
| 환산 | 1 lb = 0.45359237 kg (정확한 정의값). 45 lb ≈ 20.41 kg, 20 kg ≈ 44.09 lb | [출처 22, 23] |

**표시·반올림 제안** ([추론], StrongLifts 방식 참고 [출처 23])
- **저장:** 사용자가 입력한 값과 단위를 그대로 둔다(예: `{value: 150, unit: "lb"}`). 환산값만 저장하면 다시 바꿀 때 오차가 쌓인다.
- **표시 환산:**
  - kg 표시는 0.5 kg 단위로 반올림한다(예: 150 lb → 68 kg).
  - lb 표시는 2.5 lb 또는 5 lb 단위로 반올림한다.
  - 환산된 값 옆에는 "≈"를 붙여 원래 값이 아님을 표시한다.
- **합산·볼륨 통계:** 정확한 계수로 kg로 바꿔 계산한 뒤, 표시할 때만 반올림한다.
- **스택 머신 입력 UI:** 머신의 단위와 증량 단위에 맞춘 스테퍼를 쓴다(예: lb 머신은 10 단위 + 미세 증량 5, kg 머신은 5 단위 + 미세 증량 2.5).

## 6. 앱 데이터 모델 권장안 ([추론] — 위 근거를 바탕으로 한 설계 제안)

### 6-1. 범용 머신 레코드 (`machine_generic`)

| 필드 | 타입/예시 | 설명 |
|---|---|---|
| `id` | `leg_press_45` | 고정 키 |
| `name_ko` / `aliases_ko[]` | "레그 프레스" / ["레그프레스","45도 레그프레스","인클라인 레그프레스"] | 검색은 공백·대소문자 무시 |
| `name_en` / `aliases_en[]` | "45° Leg Press" | |
| `category` | 가슴/등/어깨/팔/하체/코어/케이블 | |
| `primary_muscles[]`, `secondary_muscles[]` | ["quads","glutes"], ["hamstrings","adductors"] | 근육 코드 + 한국어 라벨 |
| `load_type` | `selectorized` \| `plate_loaded` \| `cable` \| `guided_bar` \| `bodyweight` \| `assisted` | 기본값. 브랜드에 따라 바뀔 수 있음(예: 체스트 프레스는 S/P 둘 다) |
| `load_type_options[]` | ["selectorized","plate_loaded"] | 사용자가 자기 헬스장 기종을 고를 때 쓰는 후보 |
| `sidedness` | `bilateral` \| `iso_lateral` \| `unilateral` \| `rotational_lr` | 토르소 로테이션은 좌우 방향 따로 |
| `default_weight_basis` | `total` \| `per_side` | 아이소 플레이트 머신은 `per_side`, 그 외는 `total` |
| `increment_defaults` | `{kg:{step:5, micro:2.5}, lb:{step:10, micro:5}}` 또는 원판형 `{kg:[1.25,2.5,5,10,15,20,25], lb:[2.5,5,10,25,35,45]}` | 입력 스테퍼용 |
| `starting_resistance_note` | "슬레드 약 34–57 kg, 기종마다 다름. 보통 기록에 넣지 않음" | 플레이트·스미스 머신 전용 |
| `assist_inverted` | bool | 어시스트 머신은 숫자가 클수록 쉬움 |
| `variants[]` | ["linear","combo_hack"] | 그립·각도 변형 |

### 6-2. 사용자의 세트 기록 (`set_log`)에 꼭 넣을 것

- `weight_value`, `weight_unit` (`kg`|`lb`) — 입력한 그대로 저장
- `weight_basis` (`total`|`per_side`)
- `includes_start_resistance` (bool, 기본 false)
- `machine_instance_id` (선택) — 아래 6-3

### 6-3. 나중에 브랜드·모델을 고르는 방법 (선택 기능)

1. **"내 헬스장 기구"(`machine_instance`)**: 사용자가 범용 머신을 하나 골라 별명을 붙인다(예: "OO짐 레그프레스(파란색)").
   - 저장 항목: `generic_id`, `unit`, `increment`, `max_stack`, `starting_resistance`, `brand?`, `model?`, `gym?`
   - 브랜드를 몰라도 "단위 lb, 한 칸 10" 정도만 정하면 된다.
2. **브랜드 카탈로그(`machine_model`)**: 나중에 추가한다.
   - 예: `{brand:"Hammer Strength", model:"Plate Loaded Linear Leg Press", generic_id:"leg_press_45", load_type:"plate_loaded", sidedness:"bilateral", starting_resistance:{value:118, unit:"lb"}}`
   - 고르면 인스턴스 기본값이 자동으로 채워진다. 해당 브랜드를 고를 때만 Cybex Twist Select, Insignia 다이얼 같은 브랜드별 애드온 규칙을 보여 준다.
3. **진척도 비교 규칙**:
   - 그래프는 기본적으로 **같은 `machine_instance`** 기록끼리 그린다.
   - 같은 범용 머신의 다른 인스턴스와 합쳐 보면 "기종이 달라 무게 비교는 대략적"이라고 안내한다.
4. **카탈로그에 없는 머신**: 커스텀 머신으로 만들게 하되 부하 방식·좌우 방식·단위는 꼭 고르게 한다.

### 한계·미확인
- 국산 브랜드(DRAX, 뉴텍, IMP, 레드엔진)의 스택 규격은 온라인에서 확인하지 못했다. 실제 헬스장 기구를 촬영하거나 대리점에 문의해야 한다.
- Nautilus 스택 규격, V 스쿼트 시작 저항, 스미스 바 무게는 확인하지 못했다.
- 한국어 별칭 상당수(펙덱, 이너타이·아웃타이, 브이스쿼트, 벨트스쿼트 등)는 커뮤니티 용례로 확인했다. 표준 명칭이 따로 있는 게 아니다.
- ExRx, ACE, NASM 원문은 이번에 직접 확인하지 않았다. 근육 표기는 일반적인 운동학 지식에 기반한다([추론] 수준).
