1. 클린 정돈형

장점 기존 화면에 가장 자연스럽게 이어지고, 휴대폰에서도 한글 이름이 먼저 읽힙니다.

단점 헤일로의 의미는 마크를 이미 아는 사용자에게 더 잘 전달됩니다.

2. 영문 워드마크형

장점 소문자와 은은한 그라데이션이 브랜드 인상을 또렷하게 만듭니다.

단점 한글 앱 이름의 시각적 우선순위가 낮아집니다.

3. 헤일로 모티프형

장점 하루의 진행 상태와 마이로그의 핵심 상징을 왼쪽 브랜드 영역에서 함께 보여줍니다.

단점 실제 기록 상태에 연동해야 하며, 0/3이나 3/3에서도 모양과 문구가 잘 읽혀야 합니다.

4. 인사형

장점 앱을 열었을 때 시간대와 사용자에 맞춘 환영을 전합니다.

단점 모바일에서 긴 닉네임은 줄바꿈이나 축약 처리가 필요합니다.

5. 미니멀 모노그램형

장점 오른쪽 버튼이 많은 모바일에서도 가장 넉넉한 여백을 확보합니다.

단점 처음 방문한 사용자는 ‘my·log’만으로 정식 앱 이름을 알아보기 어려울 수 있습니다.
