# GPT 지시서 02 — 아이콘 3번(솔리드) 다듬기 + 같은 모양의 선 버전

> 사용법: 아래 "복사할 프롬프트" 상자 안의 내용을 GPT에 그대로 붙여 넣는다.
> 결정: 대표님이 10종 중 **03 솔리드**를 선택(2026-11-20). 활성 탭은 솔리드, 비활성 탭은 같은 모양의 선 버전으로 쓴다.

## 복사할 프롬프트

```
지난번 마이로그 기능 아이콘 10종 중 '03 솔리드'로 결정했어. 이번에는 03을 다듬고, 같은 모양의 '선(outline) 버전'을 짝으로 만들어 줘.

[쓰는 방식]
- 하단 탭에서 지금 보고 있는 탭(활성) = 솔리드, 나머지 탭(비활성) = 선 버전.
- 아이폰 기본 앱처럼, 탭을 누르면 같은 모양이 선 → 면으로 바뀌는 느낌이어야 해.
- 그래서 솔리드와 선 버전은 바깥 실루엣이 완전히 같아야 한다(겹쳐 놓으면 외곽선이 일치).

[대상 아이콘 8개 — 파일 이름 고정]
home(홈), body(몸·체중계), food(식단·그릇과 김), add(추가), workout(운동·덤벨), history(기록·달력), settings(설정·톱니), ai-review(AI 검토·문서와 체크)
- 03의 은유와 기본 모양은 유지한다. 새로 디자인하지 말 것.

[03에서 고칠 점 — 반드시 반영]
1. 모서리 통일: 지금 몸·기록은 둥근 모서리, 홈·추가·운동은 각진 모서리다. 8개 모두 같은 모서리 반경으로 맞춘다(바깥 모서리 반경 2px, 작은 안쪽 모서리 1px 기준).
2. 크기 균형(시각 보정): 운동(덤벨)은 넓고 낮아 작아 보이고, 추가(+)는 커 보인다. 8개를 나란히 놓았을 때 같은 크기로 느껴지게 맞춘다.
   - 기준: 사각형 계열(몸·기록·AI 검토)은 18×18 안, 원·다각형 계열(설정)은 19×19, 가로로 긴 것(운동)은 20×14, 추가(+)는 16×16.
3. 홈 지붕 아래 튀어나온 처마 각(현재 'l8 7 -2 -1' 부분)을 정리해 깔끔한 집 모양으로.
4. AI 검토의 문서 오른쪽 아래가 깨져 보이는 부분을 정리해 '문서 + 체크'가 분명히 읽히게.

[선 버전 규격]
- 선 굵기 1.75px, 둥근 끝(stroke-linecap round), 둥근 이음(stroke-linejoin round), fill none.
- 솔리드의 안쪽 구멍(체중계 눈금, 달력 칸, 톱니 가운데 등)은 선 버전에서도 같은 위치에 선으로 표현.
- 24px에서 선이 뭉개지지 않게 좌표는 가능한 한 0.5 단위로 맞춘다.

[공통 기술 규격]
- 인라인 SVG, viewBox="0 0 24 24", 바깥 2px 여백 안에 그림.
- 색은 currentColor만 사용. 배경색으로 구멍을 칠하지 말고 fill-rule="evenodd" 또는 mask로 비운다.
- 요소에 style 속성·스크립트·외부 참조를 넣지 않는다. <svg xmlns viewBox aria-hidden="true">와 <path>만.
- 색 참고: 배경 #101625, 비활성 #a8b8cc, 활성 #8ce4e0, 추가 버튼 배경은 청록 그라데이션(#91e5df→#b0d9ed) 위에 #101625 아이콘.

[결과물]
1. 파일: `GPT Source/icons-final/solid/<이름>.svg` 8개, `GPT Source/icons-final/line/<이름>.svg` 8개 (모두 16개)
2. 비교 페이지: `GPT Source/icons-final/index.html`
   - (a) 8개를 솔리드·선 두 줄로 48px
   - (b) 같은 것을 24px
   - (c) 솔리드와 선을 반투명으로 겹친 '외곽선 일치 확인' 줄
   - (d) 실제 앱 하단 탭 미리보기 7칸(홈·몸·식단·추가·운동·기록·설정): 높이 64px, 배경 #0d1424, '홈'만 활성(솔리드+청록), 나머지는 선+#a8b8cc, 가운데 '추가'는 청록 그라데이션 둥근 버튼. 이 미리보기를 '홈 활성', '운동 활성' 두 가지로.
   - 폭 360px에서 가로로 넘치지 않게.
3. 03 원본 대비 무엇을 바꿨는지 아이콘별 한 줄 정리.

[검수 — 제출 전에]
- 파일 16개가 모두 있는지 세기.
- 비교 페이지를 360px·1280px로 직접 열어 보고 넘침·깨짐 여부를 적기. 못 했으면 못 했다고 쓰기.
```
