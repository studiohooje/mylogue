# GPT 지시서 03 — 시간대별 오로라 배경 + 기록 오브제

> 사용법: "공통 스타일"은 두 작업에 모두 들어가 있다. **작업 A(배경)와 작업 B(오브제)를 따로 요청**하는 게 결과가 좋다. 한 번에 다 시키면 스타일이 섞이기 쉽다.
> 순서 권장: 작업 B의 '기준 오브제 1점'을 먼저 받아 스타일을 확정 → 나머지 오브제 → 배경.
> 이미지 안에는 **글자·숫자·로고·사람·마스코트를 넣지 않는다.** 글자는 앱이 코드로 얹는다.

## 작업 A — 홈 상단 시간대별 오로라 배경 4장

### 복사할 프롬프트

```
마이로그(Mylogue) 앱 홈 화면 맨 위 '히어로 카드'에 깔 배경 이미지 4장을 만들어 줘. 접속하는 시간대에 따라 바뀌어서, 들어올 때마다 분위기가 조금씩 달라 '자꾸 들어오고 싶게' 만드는 게 목적이야.

[앱 분위기 — 공통 스타일]
- 몸·식단·운동을 하루 시간순으로 기록하는 개인 기록 앱. 모던하고 트렌디하고 차분한 고급스러움.
- 테마 이름 Aurora Halo: 짙은 남청 바탕 위에 청록과 푸른 보라의 오로라 빛, 얇은 빛의 고리(halo), 겹쳐진 반투명 레이어의 깊이감.
- 기본 색: 바탕 #101625~#283758, 청록 #8ce4e0·#1c7a92, 보라 #7c6db7·#b8aaf2, 하늘 #9cb7f3. 순백·형광색·원색 금지.
- 질감: 부드러운 빛 번짐, 아주 옅은 필름 그레인. 사진처럼 사실적인 풍경이나 별·달·태양·구름·산 같은 구체적인 사물은 넣지 않는다(추상적인 빛과 형태만).
- 브랜드 모티프: 얇은 원형 빛 고리(오른쪽 위에 걸쳐 잘린 큰 원)와, 그 아래로 흐르는 가는 빛의 호. 과하지 않게.

[4장의 차이 — 같은 구도, 빛만 바뀜]
1. morning(05~11시): 청록이 주인공, 오른쪽 위에서 막 떠오르는 듯한 맑은 빛, 가장 밝고 상쾌
2. day(11~17시): 청록과 하늘색이 균형, 선명하고 활기찬 빛
3. evening(17~21시): 보라와 옅은 장밋빛(#c99ab8 정도까지만)이 섞인 따뜻한 노을 톤
4. night(21~05시): 가장 어둡고 고요, 짙은 남청에 보라 빛 고리만 은은하게
- 4장은 같은 구도·같은 빛 고리 위치를 유지해서, 바뀌어도 같은 앱으로 느껴져야 한다.

[구도 — 글자가 얹히는 자리]
- 왼쪽 55%는 글자(제목 2~3줄, 흰색 #edf4f8)가 올라가는 자리. 이 부분은 어둡고 단순하게 비워 둔다(밝은 빛·복잡한 무늬 금지). 흰 글자가 충분히 읽혀야 함.
- 빛의 주인공(고리·오로라)은 오른쪽 위 40% 영역에.
- 카드 모서리가 둥글게 잘리므로(반경 22px) 네 귀퉁이 근처에 중요한 요소를 두지 않는다.

[규격]
- 각 시간대마다 2가지 비율로: 
  - 와이드(PC·태블릿): 2400×800px (3:1)
  - 모바일: 1200×800px (3:2) — 휴대폰 폭 360px에서 카드가 약 328×230px로 보임
- PNG로 저장(내가 압축한다). 파일 이름: `hero-morning-wide.png`, `hero-morning-mobile.png` … (morning·day·evening·night × wide·mobile = 8장)
- 저장 위치: `GPT Source/hero-bg/`

[검수]
- 8장을 한 화면에 나란히 놓은 미리보기 페이지 `GPT Source/hero-bg/index.html`도 만들어 줘. 각 이미지 위 왼쪽에 흰 글자 "가장 쉬운 건강 관리의 시작, 기록."을 실제 크기(모바일 30px·와이드 47px, 굵게)로 얹어서 글자가 잘 읽히는지 보이게.
- 4장의 구도·고리 위치가 같은지, 왼쪽 글자 자리가 충분히 어두운지 스스로 확인하고 결과를 적어 줘.
```

## 작업 B — 빈 화면·첫 기록 안내용 오브제 5점

### 복사할 프롬프트 (1단계: 기준 오브제 1점)

```
마이로그(Mylogue) 앱의 빈 화면과 첫 기록 안내에 쓸 '기록의 오브제' 시리즈를 만들 거야. 먼저 스타일 기준이 될 1점만 만들어 줘: [몸] 체중계 겸 측정 다이얼.

[앱 분위기 — 공통 스타일]
- 몸·식단·운동을 하루 시간순으로 기록하는 개인 기록 앱. 모던하고 트렌디하고 차분한 고급스러움.
- 테마 Aurora Halo: 짙은 남청 바탕, 청록·푸른 보라의 오로라 빛, 얇은 빛 테두리.

[오브제 스타일]
- 소재: 무광 흑연(짙은 회청 #2a3448~#3d4a63)과 반투명 청유리(청록 #8ce4e0 빛이 비침)의 조합. 미니멀한 제품 사진 같은 3D 렌더 느낌.
- 조명: 오른쪽 위에서 오는 부드러운 빛 + 가장자리에 청록·보라 오로라 림라이트(가장자리만 은은하게 빛남).
- 시점: 정면에서 약간 위(약 20°)에서 내려다본 각도. 오브제는 하나만, 단순한 형태.
- 브랜드 디테일: 오브제 어딘가에 작은 점 3개가 나란히 있는 디테일(기록점). 눈에 띄되 과하지 않게.
- 금지: 글자·숫자·눈금 숫자·로고·사람·손·음식의 실사 표현·만화풍·귀여운 캐릭터화.

[규격]
- 1024×1024px, 투명 배경 PNG. 오브제는 가운데 70% 안에. 바닥 그림자는 아주 옅고 짧게(투명 배경 위에서도 자연스럽게).
- 파일: `GPT Source/objects/object-body.png`
- 확인용으로 #101625 배경 위에 얹은 버전 `object-body-preview.png`도 함께.
```

### 복사할 프롬프트 (2단계: 나머지 4점 — 1단계를 대표님이 승인한 뒤)

```
방금 만든 object-body.png와 완전히 같은 소재·조명·시점·크기·그림자로 나머지 4점을 만들어 줘. 시리즈로 나란히 놓았을 때 한 세트로 보여야 해. 각 오브제에도 작은 점 3개(기록점) 디테일을 넣어 줘.

1. object-food.png — 식단: 낮은 그릇 또는 접시(빈 그릇. 음식 실사 금지, 그릇 안쪽에 청유리 빛만)
2. object-workout.png — 운동: 웨이트 원판 한 장(세워 둔 모습, 숫자 표기 없음)
3. object-timeline.png — 타임라인(기록이 없을 때): 얇은 유리판 3장이 시간순으로 비스듬히 겹쳐 선 모습
4. object-ai.png — AI 검토함(초안이 없을 때): 반투명 유리 카드 한 장과 그 위에 작은 빛 하나

[규격] 1024×1024px 투명 배경 PNG, 오브제는 가운데 70% 안, 저장 위치 `GPT Source/objects/`.
[검수] 5점(body 포함)을 #101625 배경에 가로로 나란히 놓은 `objects-lineup.png`를 만들고, 크기·밝기·그림자가 고른지 스스로 확인해 적어 줘.
```

## 받은 뒤 Claude가 할 일

- 배경: WebP로 압축(장당 150KB 이하 목표), 홈 히어로에 시간대별 자동 적용, 글자 대비 확인, 5개 폭 캡처 검증.
- 오브제: WebP 변환(256·512px), 몸·식단·운동·타임라인·AI 검토 빈 화면과 첫 기록 안내에 배치.
- 아이콘: 솔리드(활성)·선(비활성) 하단 탭과 빠른 기록에 적용.
- 적용 후 웹·APK 함께 배포.
