# 마웨로그 04번 미세 조정 5안

01은 `mockups/icon-bar-variations-10/04-halo.svg`의 형태와 색을 그대로 재현한다. 02는 호만 청록, 03은 호를 짧고 얇게, 04는 세 줄기를 밝은 파랑, 05는 프레임·줄기·호의 톤을 깊고 차분하게 조정한다. 앱에는 아직 적용하지 않았다.
