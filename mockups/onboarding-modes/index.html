나에게 맞춘 마이로그 — 시작 문답과 기록 방식

처음 시작할 때 다섯 가지 질문(30초)으로 기본 설정을 정하고, 언제든 설정 → 나의 기록 방식에서 바꿀 수 있게 합니다. 아래 탭으로 화면을 넘겨 보세요. 모든 값은 예시입니다.

질문 다섯 개, 모두 건너뛸 수 있음

질문정해지는 기본값
1. 무엇을 기록할까요? (여러 개)하단 탭과 홈 구성, 헤일로 완성 기준(고른 것만 다 하면 완성)
2. 운동 경험은?운동 설명·사용 근육·자세 안내 표시, 추천 루틴 노출
3. 운동할 때 기록은?운동 기록 방식(세트마다 / 계획→안내 / 끝나고 한 번에)
4. 식단은 어떻게?식사 입력 첫 화면(정확히 / 간단히 / 사진 먼저)
5. 어디서 운동해요?헬스장 장소 검색 / 홈트 / 여러 곳

원칙

  • 질문은 짧게, 답은 버튼으로. 30초 안에 끝.
  • 건너뛰면 가장 무난한 기본값(세트마다 기록, 정확히 입력).
  • 답은 설정에 저장되고 로그인하면 다른 기기와 같이 쓰임.
  • 정답·오답 없음. 판단하지 않는 앱의 톤 유지.

운동 화면 위쪽의 ‘계획→안내 ▾’ 버튼으로도 바로 바꿀 수 있어요.

바꾸는 방법을 세 군데에서 알려 줌

  1. 결과 화면에 경로를 그림처럼 표시(설정 › 나의 기록 방식).
  2. 해당 화면에 바로가기: 운동 화면 위 ‘기록 방식 ▾’, 식단 화면 위 ‘입력 방식 ▾’ 칩.
  3. 첫 일주일 안내: 3번째 기록 뒤 한 번만 “방식이 불편하면 여기서 바꿔요” 말풍선.

저장 위치

설정(db.settings.preferences)에 저장 → 백업·동기화에 포함. 문답은 언제든 설정에서 다시 할 수 있음.

같은 운동, 세 가지 기록 방식

‘계획→안내’를 실제로 만들 때의 기술 조건 (조사 결과)

  • 화면 꺼짐 방지: Android Chrome은 오래전부터 지원. iPhone은 Safari 16.4부터, 홈 화면 앱은 iOS 18.4에서 고쳐져 지원.
  • 폰을 잠그면 웹 타이머가 멈추거나 늦어질 수 있음 → 기본은 화면을 켠 채 진행. Android 앱(APK)은 휴식 끝 알림을 미리 예약하는 방식으로 잠금 상태에서도 울리게 할 수 있음(앱 알림 기능 추가 필요).
  • iPhone 홈 화면 앱은 알림이 오지만 백그라운드 작업이 약함 → iPhone은 ‘화면 켜 두기’를 기본 안내.
  • 음성 안내(3·2·1)는 기기 음성 합성으로, 소리는 첫 터치 뒤에만 재생 가능.

지금과 달라지는 점

지금은 헬스장 이름만 저장 → 이름을 치면 주소가 붙은 실제 장소 목록에서 고름. 같은 지점을 고른 사람끼리 나중에 ‘같은 헬스장’ 기능(머신 목록 공유, 소모임)의 기반이 됨.

조사 결과

  • 카카오 지도 웹 도구의 장소 검색으로 브라우저에서 바로 검색 가능. 앱 키와 사용할 주소(도메인) 등록 필요.
  • 무료 사용량은 계정의 첫 번째 지도 앱에만 주어지고, 넘으면 건당 과금. 2026-07 정책 변경이 있어 등록 전에 공식 쿼터표 확인 필요.
  • Android 앱(APK) 안에서도 쓰려면 앱 주소도 허용 목록에 등록해야 함 — 실제로 시험해 봐야 함.
  • 장소 이름·주소만 저장하고 사용자 위치는 저장하지 않음(위치정보 처리 부담 회피).
