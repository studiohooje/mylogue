# 마웨로그 홈 디자인 10종

`index.html`을 Chrome 또는 Edge에서 열면 디자인 전환과 버튼·팝업을 조작할 수 있습니다. **컴퓨터에서 상단의 `📱 앱 화면` 버튼을 누르면 390px 휴대폰 프레임**으로 바뀝니다. 프레임 안을 스크롤하고 기록 버튼을 누를 수 있습니다. `웹 화면` 버튼으로 되돌립니다. 왼쪽 목록, 이전/다음 버튼, 키보드 좌우 화살표로 01~10 시안을 전환합니다. 모바일에서는 상단 가로 목록으로 전환합니다. `?v=1`부터 `?v=10`까지 직접 열어 특정 시안을 공유할 수 있습니다.

모든 화면은 **같은 예시 데이터와 홈 정보 구조**를 사용합니다. 날짜와 기록 동기화는 실제 서비스와 연결되지 않습니다. 기록 버튼은 디자인 확인용 팝업을 엽니다.
