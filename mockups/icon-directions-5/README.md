# 마웨로그 아이콘 후보 5종

2026-11-19. Aurora 계열 앱의 실제 팔레트(`#101625`, `#1c2842`, `#8ce4e0`, `#a9a5ee`, `#edf4f8`)를 사용한 **제안 시안**이다. 웹·Android 앱에 적용하거나 배포하지 않았다.

| 번호 | 방향 | 의도 | 검토 포인트 |
|---|---|---|---|
| 01 | 기록의 궤적 | 점이 쌓여 변화의 선이 된다는 제품 목표 | 24px에서 점과 궤적을 읽을 수 있는가 |
| 02 | 세 기록의 합류 | 몸·식단·운동 세 기록이 한 일지로 모임 | 파비콘에서는 점 3개의 의미가 약해질 수 있음 |
| 03 | M 기록 모노그램 | 이름의 첫 글자 M과 연결된 기록 | 가장 즉각적인 브랜드 인식, 다소 일반적인 M과 구분 필요 |
| 04 | 완료한 기록 카드 | 입력 완료의 보상과 습관 | 체크 아이콘이 흔하므로 독자성은 약함 |
| 05 | 오로라 기록 신호 | 기존 맥박 심볼을 새 색·프레임으로 계승 | 가장 안전한 전환, 건강 측정 앱처럼 보일 수 있음 |

**추천:** 01. 기록하는 습관과 변화의 시각화를 함께 담으며, 앱의 타임라인·그래프에도 같은 점과 선을 확장할 수 있다. 보수적 리브랜딩은 05.

실제 적용 시에는 하나를 고른 뒤 Android adaptive icon의 foreground/background, PWA maskable icon, 16·32px favicon, Apple touch icon, 앱 헤더 로고와 스플래시를 각각 같은 형태로 정리한다. 작은 크기용은 세부 테두리를 덜어낸 별도 SVG가 필요하다.
