# 마웨로그 · 식단 5안 + 운동 5안 클릭형 목업

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 왼쪽 목록(좁은 화면에서는 상단 선택창)에서 10개 안을 전환하고, 휴대폰 화면 안의 버튼을 눌러 시연합니다. 화면 오른쪽에는 각 안의 조작 순서, 우선 표시 규칙, 추적 항목을 적었습니다.

| 번호 | 식단 입력 | 운동 입력 |
| --- | --- | --- |
| 1 | 최근 음식·조합 → 음식별 g 선택 | 헬스장 → 최근 종목 → 첫 세트 기록 → 동일 값 한 번에 다음 세트 기록 또는 중량·횟수 변경 |
| 2 | 오늘 식사 카드 안에서 음식 추가 | 오늘 운동 카드 안에서 완료 세트 추가 |
| 3 | 음식·조합·g 선택지 라이브러리 | 헬스장·제조사·모델별 머신 라이브러리 |
| 4 | 사진·메모 임시 저장 → 수치 확정 | 한 줄 메모 → 중량·횟수 확인 후 확정 |
| 5 | 식사 저장 즉시 목표·누적 결과 | 세트 저장 즉시 같은 머신 직전 기록 비교 |

시연 데이터는 가상 값입니다. 이 목업의 저장은 해당 화면을 보는 동안의 임시 상태이며 앱 계정·서버·실제 영양 데이터베이스에 연결되지 않습니다. 사진의 영양 분석도 수행하지 않습니다. 운동 1안은 첫 세트와 다음 세트 입력 시 현재 시각을 채우고, 사용자가 수정할 수 있습니다.

색은 검정 배경과 진한·밝은 파란색을 사용했고, 작은 화면에서는 탐색 목록이 상단 선택창으로 바뀝니다. 글꼴은 Pretendard CDN을 먼저 사용하고 접속할 수 없으면 기기 기본 글꼴로 표시합니다.

검증: `node smoke-test.cjs` — 10개 화면 렌더, 음식 중량 수정, 임시 식사 합계 제외, 세트 수정, 운동 메모 파싱, 이전 값 재사용, 모바일 CSS 규칙을 확인합니다. 브라우저 시각 점검은 현재 실행 환경의 로컬 URL 및 `file:` 접근 제한으로 수행하지 못했습니다.
