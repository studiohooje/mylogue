# Aurora Halo 모션 조합 10종

대표님이 고른 **10-5 Aurora Halo**의 색, 레이아웃, 타이포그래피, 카드와 버튼 외형을 고정하고 움직임만 비교하는 별도 목업입니다. `index.html`을 Chrome/Edge에서 열면 됩니다. 컴퓨터에서는 `📱 앱 화면`으로 휴대폰 크기를 확인할 수 있습니다. 왼쪽에서 조합을 고르고 웹 화면의 `팝업 열기 / 화면 전환 / 저장 피드백 / 뒤로 가기`를 눌러보세요. 휴대폰 프레임 안에서는 빠른 기록 버튼, 하단 탐색, 팝업 안의 저장 시연, 화면의 뒤로 가기를 직접 누르면 됩니다.

| 번호 | 조합 | 호버·탭 | 화면 진입 | 팝업 | 뒤로·닫기 | 저장 피드백 |
| --- | --- | --- | --- | --- | --- | --- |
| 01 | Halo Glide | 카드 3px 부상, 짧은 눌림 | 오른쪽에서 30px 이동 | 작게 시작해 제자리 | 진입 경로로 되돌림 | 아래에서 올라옴 |

**비교 기준:** 빠른 기록은 ‘오늘 한눈에 보기’ 위, 버튼 높이는 휴대폰 47px로 동일합니다. 모든 시안의 기록 수치는 예시이며 서버나 실제 저장소와 연결되지 않습니다. 모션은 상태 전환을 설명하는 목적에 한정했습니다. `prefers-reduced-motion: reduce` 설정에서는 애니메이션을 거의 즉시 완료하도록 CSS에서 줄입니다.

Apple의 [Motion 가이드](https://developer.apple.com/design/human-interface-guidelines/motion)는 짧고 목적 있는 피드백, 반복 조작의 절제, 동작 줄이기 지원을 권합니다. [Material 3 Motion](https://m3.material.io/styles/motion)은 화면 전체에 공통 모션 토큰을 적용합니다. 이를 참고했지만 위 10개 이름과 조합은 마웨로그 목업용으로 설계했습니다.

실제 앱 적용 시에는 하나의 조합을 선택해 공통 토큰(속도, 이징, 거리, 불투명도)으로 묶고, 웹과 Android에서 동일하게 검증해야 합니다. 현재 MyWeightLog 앱 코드는 수정하지 않았습니다.
