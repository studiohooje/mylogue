# 마웨로그 · 최종 입력 목업

대표님이 고른 **식단 1안 + 운동 1안**을 하나의 반응형 클릭 목업으로 합쳤다. `index.html`을 Chrome 또는 Edge에서 연다. 데스크톱에서는 왼쪽에서 식단·운동을 전환하고, 좁은 화면에서는 상단 선택창을 사용한다.

## 식단에서 눌러볼 순서

1. 상단 네 개 막대에서 현재 입력분을 포함한 **하루 누적 / 하루 목표**를 확인한다. 칼로리 하늘색, 탄수 앰버, 단백질 민트, 지방 라일락이다. 목표를 넘으면 초과량을 숫자로 표시한다.
2. `＋ 음식 하나 추가` → `최근 / 자주 / 조합`을 전환한다. 검색, 내 음식·제품 필터, 정렬도 동작한다.
3. 현미밥과 닭가슴살을 각각 추가하고 각 행의 `g` 버튼으로 독립적으로 수정한다. 식사 합계와 하루 막대가 즉시 다시 계산된다.
4. 식사 카드의 네 값 아래에는 **이 식사 값 ÷ 현재 하루 누적값**을 표시한다. 이는 하루 목표 대비 비율과 다르다. 하루 누적이 0이면 `—`다.
5. `목표 조정`에서 네 목표값을 수정할 수 있다.

## 운동에서 눌러볼 순서

1. 헬스장 `변경`에서 지점을 바꾸거나 `＋ 내 헬스장 추가`로 새 지점을 만든다.
2. `종목 변경`에서 부위·머신/프리웨이트를 필터링한다. 선택 지점에 등록된 머신이 있는 종목을 먼저 표시한다.
3. `머신 바꾸기`에서 **선택 지점의** 제조사·모델·단위를 고르거나 새 머신을 해당 지점에 등록한다.
4. 머신 도식과 마웨로그의 테크니컬 아틀라스 앞·뒷면을 본다. 빨강은 주 타깃, 사선은 보조 타깃이다. 현재 매핑은 **동작 기준 시연 데이터**이며, 제조사·모델별 확인을 마친 결과가 아니다.
5. 첫 세트를 마친 뒤 기록한다. 이어서 `동일 값 기록`을 한 번 눌러 같은 머신·중량·횟수로 다음 세트를 저장하거나 `중량·횟수 변경`으로 직전 값이 채워진 입력창을 연다. 각 세트의 시각과 값은 수정 가능하다.

`atlas-presets.js`는 기존 `app/exercise-ui.js`와 `app/atlas-art.js`의 마웨로그 고유 그림을 `generate-atlas.mjs`로 정적 출력한 것이다. 실제 머신 사진이나 정확한 모델별 근육 타깃 데이터는 포함되지 않는다.

시연 데이터는 브라우저 메모리에만 있고 새로고침하면 초기화된다. 이 목업을 실제 앱·APK·배포 웹에 반영한 것은 아니다. `node smoke-test.cjs`로 음식 중량 수정, 목표 막대, 근육 그림, 1~3세트 반복·수정, 지점별 머신 등록, 반응형 규칙을 확인한다. 현재 실행 환경의 브라우저 정책 때문에 로컬 HTML의 시각 점검은 수행하지 못했다.
