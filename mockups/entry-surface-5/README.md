# 마웨로그 입력창 5안

`index.html`을 브라우저에서 열면 설치 없이 조작할 수 있는 독립 목업입니다. 각 버전에서 **식단과 운동을 모두** 시험할 수 있습니다. 총 10개 흐름입니다.

| 안 | 창 구성 | 기록 흐름 |
| --- | --- | --- |
| 1 | 전체 화면 | 항목 선택 → 수치 조정 → 확인·저장 |
| 2 | 바텀 시트 | 아래에서 열기 → 검색·수정 → 하단 저장 |
| 3 | 옆 패널 | 오늘 기록 유지 → 옆에서 검색·수정 |
| 4 | 빠른 검색창 | 키워드·최근 항목 → 같은 창에서 수정 |
| 5 | 화면 안 펼침 | 팝업 없이 오늘 카드 아래에서 입력 |

식단은 음식별 g 선택과 직접 입력, 탄수화물·단백질·지방 합계, 식사 이름과 시각을 시험할 수 있습니다. 운동은 종목별 여러 세트, 직전 세트 복사, 중량·횟수·kg/lb·기록 시각, 운동날 이름을 시험할 수 있습니다. 불가리안 스플릿 스쿼트의 덤벨 중량은 한쪽 기준으로 표기했습니다.

예시 카탈로그와 영양값은 시연용입니다. 저장 버튼은 목업 화면에만 반영되고 실제 계정·Firebase·운동 데이터베이스를 변경하지 않습니다. 각 안을 선택하면 작업 중인 초안은 초기화되며, 저장한 시연 기록은 해당 안의 화면에 남습니다.
