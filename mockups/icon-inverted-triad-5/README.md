# 마웨로그 대칭 아이콘 재시안 5종

대표님 피드백: 이전 02번의 세 기록 합류를 뒤집어 M을 암시하되, 특정 글자나 다른 서비스 로고처럼 단정되지 않는 형태. 좌우·상하·중앙 정렬을 엄격하게 맞춘다. `index.html`과 `preview.png`에서 큰 앱 아이콘과 48·24px 작은 크기를 함께 비교한다.

| 안 | 핵심 형태 | 특징 |
|---|---|---|
| 01 거울 궤적 | 위의 M형 궤적과 아래의 W형 궤적 | 가장 직접적인 원안의 반전. 점이 많은 편. |
| 02 접힌 중심 | 두 개의 반사된 궤적과 가운데 선 | 작은 크기에서 선이 강하게 남음. |
| 03 빈 공간의 글자 | 면 사이의 M/W 음각 | 문자에 덜 매달리고 기호성이 큼. |
| 04 교차 궤도 | 네 점이 중앙으로 합류 | 부드럽고 독자적인 인상. |
| 05 합류의 문 | 위·아래 세 줄기와 중심 마름모 | 기존 02의 의미를 가장 많이 계승. |

다섯 SVG의 도형 배치는 512×512 중심(256,256)을 기준으로 좌우·상하 반사 관계를 사용한다. 색은 대칭된 위치에 동일하게 배치했다. 타사의 상표 유사성에 대한 별도 검색·법률 검토 결과를 뜻하지 않으며, 현재는 앱에 적용하거나 배포하지 않은 시안이다.
