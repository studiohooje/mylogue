# Aurora Motion 변형 5종

대표님이 고른 기존 10번을 기준으로 한 **별도 선택용 목업**입니다. 실제 MyWeightLog 웹·Android 앱은 변경하지 않았습니다.

`index.html`을 Chrome/Edge에서 열고 왼쪽의 01~05를 선택하세요. 상단 `📱 앱 화면`을 누르면 390px 휴대폰 프레임에서 스크롤·팝업을 확인할 수 있습니다.

| 번호 | 이름 | 달라진 표현 |
| --- | --- | --- |
| 01 | Aurora Flow | 기존 10번에 가장 가까운 유려한 곡선과 둥근 얇은 버튼 |
| 02 | Aurora Grid | 직선 카드·라인 강조·데이터 지향 헤더 |
| 03 | Aurora Editorial | 제목 글자 리듬, 비대칭 모서리, 편집형 표면 |
| 04 | Aurora Split | 히어로와 요약 카드의 분할색, 얇은 왼쪽 테두리 |
| 05 | Aurora Halo | 빛의 고리, 약한 발광, 레이어 깊이 |

공통 변경: **빠른 기록이 오늘 한눈에 보기보다 위**, 모바일 빠른 기록 버튼 높이 **47px**, 세 버튼 모두 한 줄. 몸·식단·운동에는 범용 이모지 대신 마웨로그 전용 SVG 기호의 초안을 사용했습니다. 자세한 아이덴티티 제안은 `IDENTITY_IDEAS.md`입니다.
