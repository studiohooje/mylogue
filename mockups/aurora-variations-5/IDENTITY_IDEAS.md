# 마웨로그 시각 아이덴티티 제안

## 확정된 방향

- 원안 10번 **Aurora Motion**의 짙은 남청, 청록·푸른 보라의 오로라색을 유지한다.
- 홈 화면에서는 **빠른 기록 → 오늘 한눈에 보기 → 오늘의 타임라인** 순서. 빠른 기록 버튼은 얇고 한 줄로 만든다.
- 실제 웹·Android 앱은 아직 변경하지 않는다. 이 문서는 별도 디자인 선택 단계의 제안이다.

## 권장안: 기록의 궤적

마웨로그는 '하루에 남긴 작은 기록이 연결되어 변화가 보인다'는 브랜드다. 아이콘을 제각각의 그림이나 범용 이모지로 채우기보다, **점(하나의 기록)과 선(시간의 흐름)**을 공통 문법으로 쓴다.

| 영역 | 전용 기호의 구조 | 뜻 | 사용할 곳 |
| --- | --- | --- | --- |
| 몸 | 세 개의 측정선 위에 서로 다른 위치의 점 | 체중·체지방률·골격근량의 변화 | 몸 탭, 체성분 카드, 입력 버튼 |
| 식단 | 원형 접시와 시간 방향으로 이어지는 선·점 | 한 끼씩 쌓이는 식사 | 식사 번호, 매크로 카드, 입력 버튼 |
| 운동 | 높이가 다른 세 기둥과 상승 궤적 | 세트가 누적되는 운동 | 운동날 카드, 세트 완료, 입력 버튼 |
| AI 초안 | 끊어진 점선이 확인 후 실선으로 연결 | 추정 → 사용자 검토 → 확정 | 검토함, 불확실한 기록 표시 |

첫 세 기호는 이번 5종 목업에 SVG로 넣었다. 선 두께, 끝 처리, 내부 여백은 하나의 규격으로 묶었다. 실제 제품에서는 `20px / 24px / 32px` 크기와 밝은·어두운 표면용 색을 정해 사용한다. 텍스트 라벨을 항상 함께 두고 색만으로 기록 종류를 구분하지 않는다.

### 브랜드가 기억되는 순간

기록을 저장할 때 점 하나가 선에 이어지는 짧은 움직임을 넣는다. 하루에 식사·운동·몸 기록이 쌓이면 홈의 작은 궤적이 채워진다. 기록을 빠뜨렸을 때는 끊긴 선을 탓하거나 벌점처럼 보여주지 않고, 다음 점을 찍을 수 있는 빈 자리로 남긴다. 마코치는 기념 순간에만 등장시키고 일상 입력 화면의 정보 밀도를 방해하지 않게 한다.

## 비교할 만한 다른 아이덴티티 4안

1. **기록 도장**: 저장할 때 작은 `MWL` 도장을 찍는다. 완료 피드백은 강하지만 반복하면 장식이 많아질 수 있다.
2. **하루의 좌표**: 식단·운동·몸을 삼각형의 세 점으로 표현하고 기록할수록 좌표가 채워진다. 분석 화면 확장성은 좋지만 초기에 뜻을 설명해야 한다.
3. **마코치의 장비함**: 마코치가 노트·접시·아령을 각각 들어 영역을 구분한다. 친근하지만 작은 버튼에서 가독성과 제작 비용이 불리하다.
4. **오늘의 파형**: 기록 종류마다 서로 다른 파형을 사용한다. 마웨로그 로고와 연결되지만 식단·운동·몸의 뜻이 직관적이지 않을 수 있다.

**권장 조합:** 기본 UI는 `기록의 궤적`, 완료 순간에는 작은 `기록 도장`, 마코치는 주간 회고나 성취 화면에 제한해 쓰는 안. 아이콘의 모양만으로도 구분되게 만들고, 이모지는 사용자의 감정 표현이나 자유 메모에서만 허용한다.

## 현재 목업과 실제 적용의 차이

이번 목업은 SVG 기호 세 개와 빠른 기록·타임라인 표시만 시범 적용했다. AI 초안 애니메이션, 완성 도장, 마코치 모션, 전체 앱 아이콘 세트는 구현하지 않았다. 디자인을 고른 뒤 실제 웹·Android에 공통 컴포넌트로 적용해야 한다.
