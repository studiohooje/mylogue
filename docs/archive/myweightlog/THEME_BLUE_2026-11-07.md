# 마웨로그 블루 테마 (2026-11-07)

대표님 요청에 따라 기존 보라색 테마를 파워에이드의 청량하고 강한 인상에서 착안한 **마웨로그 고유의 블루 테마**로 교체했다. 브랜드 로고나 고유 그래픽은 사용하지 않는다.

| 역할 | 색상 | 용도 |
|---|---|---|
| 배경 | `#07111E` | 앱 전체와 Android 아이콘 배경 |
| 표면 | `#101D2C` | 카드 |
| 보조 표면 | `#18283B` | 입력 그룹 |
| 경계 | `#2B4056` | 구획선 |
| 기본 글자 | `#EAF4FF` | 제목·본문 |
| 보조 글자 | `#A9BDD3` | 설명 |
| 전기 파랑 | `#3B8DFF` | 주요 동작·차트 |
| 아이스 블루 | `#9DDCFF` | 보조 강조·포커스 |

근육 타깃과 삭제·오류는 의미 구분을 위해 붉은 계열을 유지한다. 성공은 녹색, 경고는 금색을 사용한다. 글자 대비는 기본 글자/배경 약 17.0:1, 보조 글자/표면 약 8.8:1, 진한 글자/전기 파랑 약 5.8:1로 계산했다. 색만으로 운동 부위나 상태를 전달하지 않도록 텍스트 라벨도 유지한다.

적용 범위: 웹 CSS, 공유 카드 색상, 운동 선택 시각화, 웹 아이콘, PWA 테마 색과 캐시 버전, Android 런처 아이콘·배경. 설정 페이지 간격과 모바일 상단 안전 영역 수정도 포함한다.
