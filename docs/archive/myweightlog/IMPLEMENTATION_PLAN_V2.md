# 마웨로그 기능 확장 실행표

기준: [번핏 Pro 기능 격차 조사](BURNFIT_PRO_GAP_ANALYSIS.md). 마웨로그 자체 화면·자체 계산 규칙으로 구현한다.

## 이번 작업의 완료 기준

1. 식단: 날짜/끼니/보충제 구분, 음식명·분량·영양값 입력, 자주 먹는 음식 재사용, 수정·삭제, 일일 총합과 기간별 매크로 표시.
2. 운동: 종목 검색/선택, 과거 세트 참고·복사, 세트 유형/RPE/강도, 휴식 타이머, 루틴과 세션 수정·삭제, 유산소 기록, 자체 규칙 기반 여섯 세트 제안, 성장·부위 분석.
3. 공통: 기존 데이터/백업 호환, 자동 테스트, Android 에뮬레이터 입력·저장·재진입 확인, APK 재빌드.
4. 보고: 각 기능을 실제 구현/부분/미구현으로 다시 판정하고 검증 결과를 남긴다.

## 현재 연결 전제로 남기는 기능

생성형 AI의 사진 식단·자연어 식단·운동 추천·주간 해석은 모델/API를 연결하기 전까지 결과를 생성한다고 표시하지 않는다. 클라우드 저장은 인증·접근 규칙·백엔드가 없으므로 로컬 기록을 유지한다. 워치는 대표님 지시에 따라 보류한다. 번핏의 독점 이미지·화면·프로그램 콘텐츠·계산식은 사용하지 않는다.
