# MWL Beta 2.1.0 · 누락 및 후속 확인 감사

2026-11-19. 실제 코드·에뮬레이터 화면·배포 기록을 기준으로, 사업계획서 개정과 별도로 확인한 항목이다. **이번 PPT 개정이 앱 기능 수정·재배포를 뜻하지는 않는다.**

| 우선순위 | 확인한 차이 | 근거 | 다음 조치 |
|---|---|---|---|
| 높음 | Spring Touch의 **팝업 닫힘·뒤로 가기 퇴장 모션**은 실제 앱에 연결되지 않았다. | `app/aurora-motion.css`의 `.mwl-modal-exit`은 정의돼 있으나 `app/app.js`에서 사용하지 않고 닫을 때 즉시 다시 그린다. | 시트 닫힘과 뒤로 가기 상태 전환을 연결하고 입력 지연이 없는지 시험한다. |
| 높음 | 디자인 토큰이 앱 전 화면에 완전히 일원화되지는 않았다. | `app/app.css`, `app/quick-entry.css`에 고정된 기존 파랑·표면색이 남아 있고 식단·운동 화면에도 보인다. | 공통 변수로 옮기고 몸·식단·운동·설정·관리·AI 검토 화면을 모바일/데스크톱에서 대조한다. |
| 중간 | 로고는 기존 파란 맥박 아이콘이다. | `app/icon.svg`와 PWA 아이콘은 Aurora Halo에 맞춰 새로 설계되지 않았다. | 자체 아이덴티티를 확정한 뒤 아이콘·스플래시·앱 아이콘 세트를 갱신한다. |
| 중간 | 저장 성공은 토스트로 보이지만 Spring Touch 전용 완료 피드백 규칙은 없다. | `toast()`는 공통 텍스트 알림이며 저장 종류별 동작이 없다. | 잦은 입력을 방해하지 않는 저장 완료 신호를 설계·시험한다. |
| 중간 | 종단 간 실사용 범위는 제한적이다. | `releases/2.1.0.md`의 자동 테스트·Android 에뮬레이터·공개 웹 확인은 완료. 실제 두 계정의 AI 연결→초안→확정과 iPhone PWA·실제 Android 기기는 별도다. | 대표님과 테스터 계정에서 사진·자연어 기록을 끝까지 실행해 측정한다. |
| 낮음 | 이전 문서에 Beta 2.0.1 화면과 목업 단계 설명이 남아 있었다. | 이전 사업계획서와 제품 방향 문서 일부. | 현재 발표본을 Beta 2.1.0으로 교체하고 보존 문서는 이전 버전으로 명시한다. |

## 이 감사에서 완료한 것

- 새 PPT의 Beta 2.0.1 화면을 Beta 2.1.0 실제 캡처로 교체하고 실제 기록/시험 데이터의 경계를 명시했다.
- SWOT와 디자인·모션 결정, 현재/향후 AI 구조, 검증 지표를 추가했다.
- 위의 앱 후속 과제는 **미완료**로 유지한다. 완료 표시나 배포 완료 주장을 하지 않는다.
