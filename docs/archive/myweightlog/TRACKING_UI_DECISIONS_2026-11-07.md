# 식단·인바디·허리둘레·머신 기록 결정

2026-11-07. 이 문서는 대표님이 확정하거나 추가 요청한 입력·분석 방향이다. 아래 이미지는 **시각 목업**이고 앱에 구현된 기능이라는 뜻이 아니다. 첫 화면은 H02 타임라인, 폰트는 **04 트레이닝 보드**, 운동 입력 흐름은 번핏의 종목 선택 방식을 참고하되 실제 완료한 세트만 등록하는 마웨로그 방식으로 수정한다. 마스코트는 마지막 약 3등신 시안, 이름은 **마코치**로 확정한다.

## 식단 첫 화면과 입력

- 하루의 식사는 `식사① 09:00`, `식사② 13:35`처럼 **기록 순서와 시간**으로 표시한다. 운동이 식사보다 먼저 와도 실제 기록 순서를 유지한다. 식사 개수는 고정하지 않는다.
- 현미밥과 닭가슴살은 한 묶음으로 보일 수 있어도 **각각 독립된 음식 항목**으로 저장한다. 각 음식의 g 선택지는 사용자가 추가·수정·삭제한다. 즐겨 먹는 조합을 불러오면 각 음식의 최근 또는 자주 선택한 중량을 미리 채우되, 저장 전에 개별 수정한다.
- 식단 화면 최상단에는 **현재까지 기록한** 하루 총칼로리·탄수화물·단백질·지방을 표시한다. 기록되지 않은 음식은 포함하지 않는다.
- 각 식사에는 음식·중량 목록, 칼로리와 탄단지 g, 그리고 `각 식사 값 ÷ 현재 하루 누적값`의 비율을 표시한다. 이 비율은 **하루 목표 대비 비율이 아니다.** 하루 값이 0일 때는 비율 대신 `—`로 표시한다.
- 사용자는 하루 목표 칼로리와 탄단지 비율 또는 g을 설정한다. 비율 합계는 100%로 검증한다. 비율로 목표를 만들 때 탄수·단백질 4 kcal/g, 지방 9 kcal/g을 써 목표 g을 계산하고 반올림 차이를 표시한다.
- 고정 지표색: **칼로리 하늘색 `#72C7FF` / 탄수 앰버 `#F2B66D` / 단백질 민트 `#77DBBD` / 지방 라일락 `#D6A4EE`**. 색만으로 상태를 구별하지 않고 값과 `남음`, `달성`, `초과` 문구도 함께 쓴다. 목표 초과 시 목표선 밖으로 뻗는 막대와 초과량을 표시한다.
- FatSecret의 공개 도움말에서 확인되는 **식사별 칼로리 분해, 일일 칼로리 목표 비교, 탄단지 목표를 비율 또는 g으로 설정, 목표 대비 실제 섭취 확인**이라는 기능 개념을 벤치마킹한다. 화면과 문구는 마웨로그 자체 설계다. [FatSecret 리포트 안내](https://www.fatsecret.com/fatsecret-app-help/getting-started/how-to-use-reports), [목표 설정 안내](https://www.fatsecret.com/fatsecret-app-help/reports-page/set-macro-goals).

## 인바디 입력

- 결과지 사진을 올려 수치를 추출하거나 직접 입력한다. 추출값은 **측정 일시, 기기 모델, 체중, 체지방률, 골격근량, 체지방량**부터 확인·수정한 뒤 저장한다. BMI, 내장지방레벨, 점수 등은 결과지에 있을 때 추가한다.
- 사진에서 읽지 못한 수치는 비워 두고 사용자가 보완한다. 원본 사진을 저장할지와 수치만 저장할지는 별도 선택으로 설계한다. 추후 서버 동기화 시 원본 사진의 개인정보 접근 권한을 별도로 검토한다.
- 기록을 날짜별로 이어 체중·체지방률·골격근량 그래프에서 볼 수 있게 한다. InBody 공식 설명도 결과지의 체중·골격근량·체지방량·체지방률 항목을 구분한다. [InBody 결과지 설명](https://inbodyusa.com/general/result-sheet/).

## 허리둘레 입력과 화면 내 가이드

- 허리둘레를 cm로 기록하고 측정 일시를 자동 채우되 수정 가능하게 한다. 같은 측정 위치와 방법을 계속 쓰도록 최근 측정법을 보여 준다.
- 화면에는 `마지막으로 만져지는 갈비뼈의 아래쪽과 골반뼈 맨 위 사이의 중간 높이`를 표시한다. 똑바로 서서 발을 가까이 두고 팔을 편하게 내린다. 줄자를 바닥과 수평으로 두되 피부를 강하게 누르지 않고, **평소 숨을 자연스럽게 내쉰 끝**에 읽는다. 기록마다 위치나 방법을 바꾸었다면 메모한다. 이 설명은 WHO의 허리둘레 측정 절차를 따른다. [WHO 허리둘레 측정 지침 PDF](https://iris.who.int/bitstream/handle/10665/44583/9789241501491_eng.pdf?sequence=1).
- 추세 그래프는 같은 방법의 측정값끼리 비교한다. 허리둘레 한 값만으로 진단을 내리는 문구는 넣지 않는다.

## 헬스장·머신과 근육별 추정

### 운동 8종목 이상일 때의 홈 표현

H02 타임라인은 운동 세션 **한 건당 카드 하나**를 보여 준다. 카드에는 사용자가 정한 운동날 이름 또는 자동 제목, `8종목`, 실제 완료한 `24세트`, 첫·마지막 완료 세트 기록 시각에서 구한 `기록 간 87분`, 총 볼륨, 대표 종목 3개와 `외 5종`만 넣는다. 전체 종목은 `전체 운동 보기`를 누른 별도 상세 화면에서 세로 목록으로 본다. 종목 카드를 누르면 머신·kg/lb·개별 세트·기록 시각을 펼친다. 홈 카드 높이는 종목 수가 늘어도 거의 일정하게 유지한다. 운동 시작·종료 버튼이 없는 현 설계에서 87분은 **첫 세트와 마지막 세트의 기록 시각 차이**이며 정확한 운동 지속 시간이라고 단정하지 않는다.

### 운동날 이름: 프리셋 또는 자유 입력

- 운동날 이름은 `하체`, `가슴`, `Push Day`, `3분할 - 등`처럼 **완전히 사용자 정의**할 수 있다. 프리셋은 이름 문자열을 저장·편집·삭제하는 기능이며 운동 종목이나 세트 계획을 자동 생성하지 않는다.
- 직접 입력한 이름으로 세트를 저장하면 그 이름을 **해당 계정의 재사용 가능한 운동날 이름 목록에 자동 저장**한다. 같은 이름은 중복 생성하지 않고 다음 기록부터 선택지로 보여 준다. 이름 목록은 계정별로 분리한다. 서버 동기화 전에는 해당 계정의 로컬 기록 공간에 보관한다.
- 이름 선택지의 `×`를 누르면 `저장된 이름 목록에서 삭제할까요? 이전 운동 기록의 이름은 그대로 남습니다.`라는 확인창을 띄운다. **삭제 / 취소**를 명확히 구분한다. 삭제는 목록에서만 제거하며, 과거 운동 세션의 제목은 바꾸지 않는다. 현재 열어 둔 이름이 삭제되면 현재 입력값은 사용자가 다시 선택하거나 직접 수정할 때까지 유지하되, 다음 기록의 선택지에서는 빠진다.
- 첫 완료 세트를 입력할 때 이름 선택 화면을 제공한다. 프리셋 탭, 직접 입력, `이름 없이 기록` 중 고른다. 이름 선택은 건너뛸 수 있고, 세트 기록을 막지 않는다. 운동 시작 버튼은 요구하지 않는다.
- 이름을 정했다면 홈 운동 카드의 큰 제목과 상세 화면 제목에 그대로 표시한다. 이름이 없다면 **첫 기록 종목명 + `외 N종`**으로 자동 표시한다. 종목 하나면 종목명만 표시한다. 예: 네 종목이면 `레그프레스 외 3종`, 여덟 종목이면 `레그프레스 외 7종`.
- 운동 도중이나 끝난 뒤 이름을 바꿀 수 있다. 비워 둔 경우 자동 제목은 실제 기록된 종목 수가 바뀌면 함께 갱신된다. 별도 세션을 언제 나누는지는 기록 그룹 선택으로 결정하고, 시간 간격만으로 임의 분할하지 않는다.

- `내 헬스장 추가`에 헬스장과 제조사·모델별 머신을 등록한다. 운동 기록 시 헬스장을 선택하면 그 지점의 머신을 먼저 보여 주며, 같은 V스쿼트 동작에 여러 머신이 있으면 해당 지점의 최근 사용 머신을 우선한다. 다른 머신 또는 미등록 머신으로 바꿀 수 있다.
- 머신별 타깃 근육은 대표님이 추후 확인을 요청하면 제조사 자료와 동작 정보를 조사해 **근거·확신 수준**과 함께 등록한다. 한 세트의 중량·횟수로 근육별 운동량과 피로 기여도를 **보수적인 대략치**로 추적한다. 실제 근육에 걸린 힘의 정밀 측정치라고 표현하지 않는다.
- 헬스장·머신 목록은 개인 목록으로 시작한다. 나중에 공개할 경우 사진 권리와 위치·사용자 관련 정보의 공개 범위를 별도로 결정한다.
- 운동 입력은 계획·시작·완료 세 단계 대신 **실제로 마친 세트만** 저장한다. 세트 저장 시각을 자동 입력하고 수정도 허용한다. 연속 세트 기록 시각의 차이는 `기록 간 간격`으로 표시하며, 실제 휴식 시간과 같다고 단정하지 않는다. 휴식 타이머는 현재 요구에서 제외한다.
