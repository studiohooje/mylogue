# 마웨로그 첫 화면·쉬운 입력 5개 버전

> 이 문서는 첫 화면과 입력 방식을 묶어 보여 준 초기 탐색안이다. 대표님 요청에 맞춰 **첫 화면 5안과 입력 방식 5안을 각각 분리한 정정본**은 [MOCKUPS_SEPARATE_HOME_INPUT_2026-11-07.md](MOCKUPS_SEPARATE_HOME_INPUT_2026-11-07.md)를 참조한다.

2026-11-07 · **시각 목업, 아직 앱 기능으로 구현되지 않음.** 각 버전은 첫 화면 + 식단 입력 + 운동 입력이 한 세트다. 수치·음식명은 시각화 예시다. 웹/PWA와 Android에 동일한 반응형 UI 소스를 적용하는 것을 전제로 한다. 앱을 열 때마다 강제 스타트 화면을 띄우지 않고 홈 첫 뷰포트에서 동기부여한다. 실제 데이터 로딩 중에만 로딩 상태를 표시한다.

## V01 점화 대시보드 — 1순위

![V01 점화 대시보드](artifacts/recording-mockups/v01.png)

- **첫 화면:** ‘오늘을 기록으로 바꿔.’ 히어로와 `식사 남기기 / 지난 운동 이어하기` 버튼을 지표보다 먼저 배치한다. 아래에 최근 식사·운동을 바로 재사용하는 카드를 둔다.
- **식단:** 자주 먹는 한 끼 카드 선택 → ½·1·1½·2 양 선택 → 합계를 확인하고 기록. 처음 먹는 음식은 이름부터 남긴다.
- **운동:** 지난 운동을 불러오면 종목·머신·kg/lb·세트 값이 보인다. 실제 한 세트만 큰 버튼으로 완료하고, 다를 때 중량·횟수를 고친다.
- **강점/주의:** 기록 행동이 가장 먼저 보인다. 완성 링이나 목표 숫자를 쓴다면 미기록을 실패처럼 표현하지 않는다.

## V02 오늘의 타임라인 — 2순위

![V02 오늘의 타임라인](artifacts/recording-mockups/v02.png)

- **첫 화면:** 아침·점심·저녁·운동을 하루의 세로 흐름으로 보여 준다. ‘오늘의 흔적을 남겨.’라는 문구와 현재 시간 근처의 기록 자리를 강조한다.
- **식단:** 빈 끼니 자리 탭 → 해당 끼니의 최근 음식 3개 중 선택 → 양 선택 → 타임라인에 기록.
- **운동:** 운동 자리에서 이전 루틴 시작 → 완료한 세트가 시간축에 쌓임.
- **강점/주의:** 하루를 돌아보기 쉽다. 야간 근무나 순서가 다른 식사는 자유 추가를 허용해야 한다.

## V03 대화형 퀵로그 — 4순위

![V03 대화형 퀵로그](artifacts/recording-mockups/v03.png)

- **첫 화면:** ‘지금, 하나만.’과 `식사 / 운동 / 체중` 빠른 선택. **AI 대화가 아니라 규칙 기반 단계 입력**이다.
- **식단:** ‘무엇을 드셨나요?’에서 자주 먹는 음식 선택 → ‘얼마나?’에서 양 선택 → 저장. 상세 영양값은 나중에 보강.
- **운동:** 최근 운동 선택 → ‘지난 세트 그대로 했나요?’ → 그대로 완료 또는 중량·횟수만 수정.
- **강점/주의:** 한 번에 하나만 결정한다. 반복 사용자에게 질문 순서가 길게 느껴질 수 있으므로 바로 기록 단축 경로가 필수다.

## V04 미션 보드 — 5순위

![V04 미션 보드](artifacts/recording-mockups/v04.png)

- **첫 화면:** ‘작은 기록이 오늘을 움직인다.’ 아래 `한 끼 / 한 세트 / 몸 상태 / 돌아보기` 네 가지 행동 타일.
- **식단:** 한 끼 타일 → 자주 먹는 조합 하나 선택 → 양 선택 → 저장.
- **운동:** 한 세트 타일 → 지난 운동의 다음 세트 → 실제 완료 시 한 번 탭.
- **강점/주의:** 행동이 선명하다. 미완료 타일을 실패·벌점으로 표시하지 않고 휴식도 정상 상태로 둔다.

## V05 집중 세션 — 3순위

![V05 집중 세션](artifacts/recording-mockups/v05.png)

- **첫 화면:** ‘지금은 하나면 충분해.’ 아래 식단 기록과 운동 시작, 두 가지 큰 명령만 둔다.
- **식단:** 최근 식사를 큰 카드 한 장씩 넘기며 고르고 양을 선택한다.
- **운동:** 현재 세트의 중량·횟수와 거대한 완료 버튼을 중심에 둔다. 다른 값으로 수행했을 때만 수정한다.
- **강점/주의:** 운동 중 한 손 조작에 유리하다. 모든 기록·차트로 가는 길을 명확히 남겨야 한다.

## 공통 구현 기준

- 계획 세트는 기본 **미완료**. 실제 완료 세트만 운동량·피로도 추정에 반영한다.
- 영양값 미입력은 `0g`이 아닌 `미입력`, 추정은 `추정`으로 표시한다.
- 빠른 기록과 상세 수정은 같은 데이터를 편집한다. 기존 임시 저장·복구·되돌리기 기능을 주 동선에서 쉽게 찾게 한다.
- 상태별 문구는 하루 동안 안정적으로 유지한다. 기록 직후 짧은 반응만 주고 반복 점멸은 사용하지 않는다. `prefers-reduced-motion`을 따른다.
- 한국어 줄바꿈, 360px 휴대폰과 데스크톱, Android/PWA 동일 UI, 오프라인 복구와 키보드·화면 읽기 조작을 검증한다.
