# 마웨로그 목업 정정본: 첫 화면 5안 / 입력 방식 5안

2026-11-07. 이 문서의 두 묶음은 **서로 독립적인 선택지**다. 첫 화면 하나와 입력 방식 하나를 각각 고를 수 있다. 모두 시각 목업이며, 이미지 속 수치와 버튼은 예시다. 앱에 구현하거나 배포한 상태를 뜻하지 않는다. 웹/PWA와 Android는 같은 디자인 규칙과 입력 흐름을 쓰는 것을 전제로 한다.

## A. 첫 화면 레이아웃 5안

이 절은 앱을 열었을 때 보이는 **첫 화면만** 다룬다. 입력 순서를 포함하지 않는다.

| 안 | 첫 화면의 중심 | 기록을 유도하는 장치 | 주의할 점 |
| --- | --- | --- | --- |
| H01 점화 대시보드 | 강한 한 문장과 오늘의 핵심 행동 | `오늘을 기록으로 바꿔`와 식사·운동 진입 버튼 | 지표와 버튼의 위계를 유지해야 함 |
| H02 오늘의 타임라인 | 아침부터 현재까지의 시간 흐름 | 빈 기록 자리를 한눈에 보여 줌 | 시간 순서가 다른 생활 패턴도 허용해야 함 |
| H03 대화형 퀵로그 | 지금 할 한 가지 행동 | 식사·운동·체중 중 하나를 먼저 선택 | 매번 질문을 반복하면 느려질 수 있음 |

## B. 입력 방식 개선 5안

아래 **각 안마다 식단 4화면, 운동 4화면**을 별도 제작했다. 각 이미지는 왼쪽에서 오른쪽으로 진행한다. 첫 화면 H01~H05 중 어느 것과도 조합할 수 있다. 따라서 `H02 + I01`처럼 고를 수 있다.

### I01 최근 그대로: 반복 기록을 가장 빠르게

**식단:** ① 최근 식사를 선택 → ② ½·1·1½·2 중 먹은 양 선택 → ③ 칼로리와 탄단지를 확인·수정 → ④ 오늘 기록에 반영.

![입력 I01 식단 단계별 화면](artifacts/separated-mockups/input-v01-food.png)

**운동:** ① 지난 운동 선택 → ② 지난 중량·횟수를 가져오고 다른 값만 수정 → ③ 실제 세트 완료 후 휴식 타이머 → ④ 다음 세트 진행.

![입력 I01 운동 단계별 화면](artifacts/separated-mockups/input-v01-workout.png)

반복하는 식사와 루틴에 가장 빠르다. 첫 기록의 음식·종목 등록은 별도 흐름이 필요하다.

### I02 번핏 입력 흐름 벤치마크: 종목 선택과 세트별 완료

**운동:** ① 오늘 운동을 계획하면서 종목을 체크해 추가 → ② 운동 계획에서 순서를 확인하고 시작 → ③ 각 세트의 무게·횟수를 입력하고 실제 완료한 세트만 체크 → ④ 세트 완료 후 휴식 타이머를 보고 다음 세트 또는 운동 종료로 이동. 자세한 공식 순서는 아래 `번핏 확인 범위`를 참조한다.

![입력 I02 운동 단계별 화면](artifacts/separated-mockups/input-v02-workout.png)

**식단:** ① 끼니 선택 → ② 음식 선택 → ③ 수량·영양값 확인 → ④ 하루 기록에 반영. 이 식단 흐름은 **마웨로그 자체 제안**이며 번핏 식단 입력 화면을 재현했다는 뜻이 아니다.

![입력 I02 식단 단계별 화면](artifacts/separated-mockups/input-v02-food.png)

장점은 운동 계획과 실제 완료 기록을 분리해 운동량이 부풀지 않는다는 점이다. 단점은 짧은 운동에서도 종목 선택과 계획 화면을 거쳐야 한다는 점이다. 시각 디자인과 문구는 마웨로그 자체 설계다.

### I03 한손 라이브: 운동 중 큰 버튼

**식단:** ① 자주 먹는 한 끼 카드 선택 → ② 큰 수량 선택 → ③ 합계 확인 → ④ 저장 피드백.

![입력 I03 식단 단계별 화면](artifacts/separated-mockups/input-v03-food.png)

**운동:** ① 현재 세트의 큰 중량·횟수 표시 → ② 달라진 값만 증감 버튼으로 수정 → ③ 휴식 타이머 → ④ 다음 한 세트 표시.

![입력 I03 운동 단계별 화면](artifacts/separated-mockups/input-v03-workout.png)

운동 중 조작이 쉽다. 여러 종목을 한꺼번에 편집하는 데는 별도 계획 화면이 필요하다.

### I04 한 질문씩: 처음 기록하는 사람에게

**식단:** ① 무엇을 먹었는지 선택 → ② 먹은 양 선택 → ③ 확인 가능한 영양값 검토 → ④ 기록 완료.

![입력 I04 식단 단계별 화면](artifacts/separated-mockups/input-v04-food.png)

**운동:** ① 종목 선택 → ② 지난 세트와 같은지 질문 → ③ 실제 한 세트의 완료 확인 → ④ 휴식과 다음 행동 제시.

![입력 I04 운동 단계별 화면](artifacts/separated-mockups/input-v04-workout.png)

처음 쓰는 사람의 판단 부담이 낮다. 숙련자에게는 단계를 건너뛰는 빠른 경로가 필요하다.

### I05 묶음 기록: 한 끼와 한 루틴을 재사용

**식단:** ① 자주 먹는 한 끼 또는 어제의 식사를 선택 → ② 음식 묶음에서 개별 수량 수정 → ③ 합계 확인 → ④ 한 끼 저장과 템플릿 등록.

![입력 I05 식단 단계별 화면](artifacts/separated-mockups/input-v05-food.png)

**운동:** ① 지난 루틴 또는 저장한 루틴 선택 → ② 오늘 할 종목·세트 확인 → ③ 실제 완료한 세트만 기록 → ④ 다음 세트로 계속.

![입력 I05 운동 단계별 화면](artifacts/separated-mockups/input-v05-workout.png)

반복 루틴 전체를 빨리 구성할 수 있다. 복사한 계획은 완료 기록으로 계산하지 않아야 한다.

## 번핏 확인 범위와 마웨로그 설계 경계

번핏의 공개 공식 도움말에서 확인한 운동 기록 순서는 **오늘 운동 계획 → 종목 선택과 추가 → 운동 시작 → 세트마다 무게·횟수 입력 및 완료 → 운동 마치기**다. 이전 운동은 날짜 또는 종목에서 불러올 수 있고, 세트 완료 뒤 휴식 타이머가 자동으로 시작된다. 세트 종류로 워밍업·드롭·실패·RPE를 지정하는 방법과 슈퍼세트 설정도 별도 공식 안내에 있다.

I02는 이 **기능 순서의 벤치마크**다. 공개 도움말의 화면과 기능을 참고했으며, 현재 버전 앱의 모든 화면·상태·유료 기능을 직접 조작해 검증한 것은 아니다. 이미지 속 색, 구성, 버튼 문구, 식단 흐름은 마웨로그의 독자적인 제안이다. 이 문서의 다섯 입력 안 중 구현 기본값으로는 `I01 최근 그대로`에 `I02의 종목 선택·세트 완료 방식`과 `I03의 운동 중 큰 버튼`을 결합하는 것을 권한다. 각 안 자체는 비교 가능하도록 별도로 보존한다.
