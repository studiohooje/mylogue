## 디자인 확정 사항

- 공통 원본: `app/atlas-art.js`, 표현·접근성: `app/exercise-ui.js`.
- **타깃:** 일반적인 운동 동작의 주 타깃은 빨강, 보조 타깃은 사선과 문자 라벨.
- **추정부하:** 실제 최근 14일 완료 세트에 RPE·경과일·주/보조 가중을 적용. 보라로 보통/부담 큼을 구분하고, 기록 없는 부위는 자료 없음으로 표시한다.
- 계산 규칙과 빠진 정보는 화면에서 펼쳐 볼 수 있다. 의학적 피로·회복률을 측정했다고 표현하지 않는다.
- `mockups/body-atlas-v3/`는 5종 검토 이력이며, 앱의 확정 디자인은 3번이다. 다른 4종은 적용하지 않았다.

- 구 APK 설치→합성 몸·식단·운동·사진 기록→`adb install -r` 업데이트→기록 값·사진 바이트 비교·새 아틀라스·새 백업 검증 통과. `pm clear`를 실행하지 않았다. 에뮬레이터는 `-read-only -no-snapshot`으로 기존 디스크를 보존했다.

## 실제로 남은 사항

1. 대표님 Android 휴대폰과 iPhone Safari/PWA의 설치·파일 다운로드/복원·카메라·오프라인·잠금 복귀는 **실기기 미검증**이다. 데스크톱의 모바일 폭 테스트를 iPhone 테스트로 표현하지 않는다.
2. OCR은 기존 InBody 270 방식이다. 다른 양식·조명·회전 사진의 정확도 검증을 새로 완료하지 않았다.
3. 머신 사진 자동 식별, 음식 사진/문장 AI, 검증된 외부 식품 DB·바코드, 서버·2인 동기화, OS 건강 데이터는 **이번 로컬 구현 단계 밖의 후속 연결**이다. 워치는 기존 지시대로 보류했다.
4. 통합 백업은 저장 완료한 기록·진행 사진·머신 프로필 사진을 포함한다. 작성 중 운동 초안은 별도 로컬 저장소이며 설정에서 별도로 내보낼 수 있다. 복원 전에 있던 초안도 별도 내보내기를 제공한다.
5. 기존 연구 보고서의 선택/후속 아이디어(대규모 동작 영상, 주차별 장기 프로그램 진행, 정밀한 체성분 다중축 비교 등)를 전부 완료했다고 주장하지 않는다. 본 보고서의 구현 표가 이번 승인한 1~5단계의 실제 결과다.
6. 공개 배포·외부 AI/서버 전송·계정 변경·금전 집행은 실행하지 않았다.
