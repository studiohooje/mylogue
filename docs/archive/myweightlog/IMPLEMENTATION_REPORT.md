# 마웨로그 프로토타입 구현·검증 보고서

기준일: 2026-10-31 (Asia/Seoul)

## 결론

작동형 웹 앱의 원본과 배포 파일, Android 디버그 APK를 만들었다. 자동 테스트 18개가 통과했고, 제공된 인바디 270 검사표의 주요 수치에 대해 영역별 OCR을 실제 실행해 확인했다. Android 에뮬레이터에 APK를 설치하고 홈·몸·운동 화면의 표시와 이동을 확인했다. **실제 휴대폰 설치·사진 OCR의 기기 내 실행·iPhone Safari 검증·외부 AI·서버 동기화는 완료하지 못했다.** 따라서 전체 프로젝트를 완성 또는 완벽 검증으로 표시하지 않는다.

## 검증 결과

1. `npm test`: **18/18 통과**. 데이터 검증, 식단 합계·비율, 운동량·1RM, 백업, 인바디 OCR 텍스트·영역 값, 주간 요약, 초기 화면 생성·화면 이동을 확인.
2. `npm run build` 및 `node verify-build.mjs`: **통과**. 배포 폴더의 19개 필수 파일과 모듈 참조, PWA manifest 확인.
3. `npx cap add android`, `npx cap sync android`: **통과**. Android 프로젝트 생성 및 최신 웹 자산 복사 확인.
4. 제공된 인바디 270 이미지로 Node OCR 실행: 전체 페이지 OCR은 체중을 잘못 추출해 채택하지 않음. 주요 수치 영역을 따로 읽은 결과 **체중 84.7 kg, 골격근량 38.4 kg, 체지방량 16.8 kg, BMI 25.3, 체지방률 19.8%, 내장지방 레벨 7, 기초대사량 1837 kcal, 측정일 2026-10-26**을 확인. 인바디 점수는 자동 추출하지 않고 수동 확인 필드로 둠. 이는 **제공된 한 장에 대한 확인**이며 다른 검사표의 정확도를 보증하지 않음.
5. `gradlew.bat assembleDebug`: **통과**. Android Studio Rabbit 2의 JBR 25 대신 프로젝트 내부의 JDK 21과 설치된 Android SDK를 사용함. 디버그 APK: `app/android/app/build/outputs/apk/debug/app-debug.apk`.
6. Android 에뮬레이터: **설치·실행 통과**. `Medium_Phone_API_37.0`에 설치해 홈·몸·운동 화면 표시와 탭 이동을 확인. 실제 기기 입력·사진 선택·OCR·백업 동작까지 검증한 것은 아님. iPhone Safari 검사는 미실행.
7. `npm audit --omit=dev`: **0 vulnerabilities**. 전체 의존성에는 Capacitor CLI의 개발 도구 경로에서 moderate 4건이 보고됨. 강제 하위 버전 변경은 하지 않음.

## 번핏 Pro 비교에서 아직 남은 기능

공개 자료로 확인한 번핏 Pro의 기능 전체를 재현한 상태는 아니다. AI 데일리 추천·AI 세트 어시스턴트·음식 사진/자연어 분석·AI 주간 리포트는 **연결 규격만 준비**했다. 월간 상세 리포트, 광범위한 프로그램 라이브러리, GIF 운동 가이드, 상세 피로도 모델, 음식 데이터베이스, 서버 동기화는 아직 구현하지 않았다. 스마트워치는 대표님 지시에 따라 보류했다. 번핏 내부의 비공개 계산식과 모든 Pro 화면은 확인하지 못했다. [기능 조사표](FEATURE_INVENTORY.md)의 공개 확인 항목과 구현 항목을 혼동하면 안 된다.

- 실제 Android 기기에 디버그 APK를 설치해 입력·저장·사진 OCR·백업 검사.
- iPhone Safari에서 PWA 홈 화면 추가, 로컬 저장·백업·사진 OCR 검증.

- GitHub Pages 게시 전 배포 파일만 올리고 개인정보가 섞이지 않았는지 최종 점검. **현재 게시하지 않음.**
