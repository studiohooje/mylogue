# 마웨로그 기능 확장 및 검증 보고서

기준일: 2026-11-01. 이 문서는 [초기 구현 보고서](IMPLEMENTATION_REPORT.md) 이후 추가한 기능의 현재 상태를 기록한다. 번핏의 공개 기능을 참고했으며 화면, 자산, 비공개 계산식은 사용하지 않았다.

## 실제 검증

- `npm test`: 31개 통과. 기존 데이터·백업 호환, 영양 계산, 프로그램·운동 분석, Codex 파일 검증, 식단·운동 화면 입력·수정 흐름 포함.
- `npm run build`와 `node verify-build.mjs`: 통과. 배포 파일의 모듈 참조와 서비스 워커 파일 목록 확인.
- `build-android.ps1`: 웹 빌드, Capacitor 동기화, Gradle 디버그 APK 빌드 통과.
- Android API 37 에뮬레이터: 식단 500 kcal·탄수화물 55 g·단백질 35 g·지방 15 g 입력 후 홈 합계 표시, 앱 강제 종료·재실행 후 기록 유지 확인. 벤치프레스 60 kg × 10회 입력 후 600 kg 볼륨 표시 확인. 운동 입력 시트의 좁은 화면 가로 넘침을 수정하고 재확인.
- APK 업그레이드 시 이전 웹 서비스 워커가 오래된 화면을 유지하는 문제를 발견했다. 새 네이티브 빌드는 서비스 워커 등록을 중단하고 기존 캐시 제거 코드를 포함한다. 기존 사용 데이터 보존을 포함한 실제 구버전에서 신버전으로의 기기 업그레이드는 별도 검증이 필요하다.

디버그 APK: `app/android/app/build/outputs/apk/debug/app-debug.apk` (42,728,940 바이트, SHA-256 `1F321EDF9E2355D8E75B0B6298A3D84CC627F4512CB6E85AE75D7317F49C4509`).

## 부분 구현 및 남은 범위

- **생성형 AI:** 모델/API 호출 없이 Codex가 작성한 구조화 파일을 검토·저장할 수 있다. 사진 식단 분석, 자연어 영양 추정, 대화형 운동 추천은 실제로 실행되지 않는다.
- **음식 데이터:** 최근·사용자 저장 음식은 재사용한다. 검증된 대규모 식품 영양 DB와 바코드 조회는 없다. 입력값의 정확성은 사용자 확인이 필요하다.
- **인바디:** 제공된 InBody 270 사례의 주요 수치를 확인했다. 모든 기종·촬영 조건의 자동 인식을 보증하지 않는다.
- **사진:** 진행 사진은 기기의 IndexedDB에 보관된다. JSON 백업에는 포함되지 않으므로 기기 이전 시 개별 다운로드가 필요하다.
- **동기화·워치:** 서버 인증·저장·기기간 동기화는 미연결이다. Zepp·Apple Watch 연동은 대표님 결정대로 보류했다.
- **배포 검증:** iPhone Safari의 홈 화면 설치, 실제 Android 휴대폰의 사진 OCR·파일 가져오기·백업은 아직 검증하지 않았다. 웹은 아직 게시하지 않았다.
- **번핏 Pro 대응:** 공개적으로 확인 가능한 동작을 자체 설계로 구현한 범위다. 모든 Pro 화면과 비공개 로직을 확인하거나 동일하게 재현했다고 주장하지 않는다. [조사·격차 문서](BURNFIT_PRO_GAP_ANALYSIS.md)는 2026-10-31 초기 구현 기준이다.
