# 작업로그 — Mylogue Beta 3.16.1 (2026-11-21)

## 요청(대표님)
- '내 음식·운동 목록 복사'를 누르면 `filter is not a function` 오류가 난다.
- 직접 '등록'한 항목만이 아니라, 한 번이라도 입력한 항목은 모두 복사돼야 한다.

## 원인
- `app.js`가 `aiContextText(db, foodChoices())`를 불렀다. `foodChoices()`는 목록이 아니라 `{...db, foods}` 묶음을 돌려줘서 `.filter`가 없었다.
- 3.16.0 시험은 목록을 직접 넘겨서 이 오류를 잡지 못했다.
- 그리고 후보 목록은 최근 20개와 AI·등록 음식만 담아, 오래전에 한 번 먹은 음식은 빠졌다.

## 바꾼 것
- `app/ai-paste.js` `aiContextText(db)`: 인자를 `db` 하나로 바꾸고 직접 모은다.
  - 음식: 모든 식사 기록과 직접 등록한 음식(대표값·공용 도감 제외)을 이름+단위로 한 줄씩 묶는다. 값은 가장 최근 기록이고, 많이 먹은 순으로 최대 300개다.
  - 운동: 모든 운동 기록의 종목을 묶어 가장 많이 쓴 머신 이름을 붙인다. 많이 한 순으로 최대 150개다.
  - 문구: "양이 다르면 같은 비율로 바꿔서".
- `app/app.js`: 호출 두 곳을 `aiContextText(db)`로 바꿨다.
- `tests/v3160.test.js`: 실제 앱처럼 `db`만 넘긴다. 오래된 한 번짜리 음식, 등록 음식, 같은 음식 한 줄, 빈 db를 시험한다.
- 이 배포에는 3.17.0용으로 만들어 둔 AI 서버 연동 코드도 들어 있다(`ai-config.js`, `ai-prompt.js`, '말로 입력' 화면). 서버 주소가 비어 있어 화면에는 나오지 않는다.
