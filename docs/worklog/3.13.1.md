# 작업로그 — Mylogue Beta 3.13.1 (2026-11-20)

## 요청(대표님)
1. 웹 버전에서 뒤로가기 버튼이 안 먹는다.
2. 홈을 누르면 어디에 있었든 맨 위로, 식단을 눌러도 맨 위로(스크롤을 내린 채 다른 메뉴에 다녀와도).
3. 가운데 정렬이 안 되는 게 있다(설정 화면 캡처) — 이런 찐빠가 없어야 한다.
4. 털린 근육을 왜 파랗게? 붉은 계열로, 덜 털리면 주황, 더 덜하면 노랑.
5. 홈 운동 칸 그림이 너무 작다 — 오른쪽 정렬로 크게, 글자를 침범하지 않게.

## 원인과 수정
- 뒤로가기: 앱이 화면을 바꿀 때 브라우저 기록을 전혀 남기지 않았다. `syncHistory`를 추가했다.
  - 화면 이동은 `pushState({p}, '#page')`, 팝업 열기는 `pushState({m:1})`로 기록한다.
  - ×·바깥 누르기로 닫으면 팝업 기록을 지운다(`history.back` + 무시 표시). 닫으면서 화면이 바뀌면 `replaceState`를 쓴다.
  - `popstate`가 오면 팝업이 열려 있을 때 닫는다(작성 중이면 확인, 취소하면 기록을 되돌림). 아니면 이전 화면으로 간다.
  - `history.scrollRestoration='manual'`로 이동할 때마다 맨 위에서 시작한다.
  - 새로고침해도 `#food` 같은 주소를 그대로 둔다.
  - Android 앱은 Capacitor가 WebView 기록으로 뒤로 가므로 같은 동작을 한다(실기기 미확인).
- 맨 위로: 아래 메뉴·헤더 마이로그(`data-page`)를 누르면 렌더 후 `scrollTo(0,0)`. 같은 메뉴를 다시 눌러도 맨 위로 간다.
- 가운데 정렬
  - 토스트가 `left:50%; transform:translateX(-50%)`로 가운데를 잡는데, 등장 애니메이션(mwlSpringIn)이 transform을 덮어써 자기 폭의 절반만큼 오른쪽으로 밀려 있었다(캡처의 ‘평소 하는 운동: 웨이트(헬스)’ 안내). `left:0; right:0; margin-inline:auto; width:max-content`로 바꿨다.
  - 칩 줄은 줄마다 폭을 채우게 했다(`flex:1 1 auto`).
- 근육 부하 색
  - Body Atlas load 모드를 3단계로 바꿨다: 점수 6 이상 빨강 `#ef4b4b`, 3 이상 주황 `#ff9a3c`, 0 초과 노랑 `#f5c84b`.
  - 범례를 '많이·보통·조금'으로 바꿨다.
  - 홈 운동 칸은 최댓값 기준 60% 이상 빨강, 30% 이상 주황, 그 아래 노랑으로 칠한다.
  - 회복 지도는 회복 중을 빨강, 거의 회복을 주황으로 칠한다.
- 홈 운동 칸
  - 600px 이상에서는 몸 그림을 카드 오른쪽에 위아래를 꽉 채워 놓고, 글자는 왼쪽 48% 안에 둔다.
  - 폰에서는 그림 높이를 62에서 70px로 키웠다.
  - 글자와 겹치는지 자동으로 검사했다.
- 버전 3.13.1(versionCode 27), sw CACHE `mylogue-shell-v3-13-1-back`.
