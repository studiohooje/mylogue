# 작업로그 — Mylogue Beta 3.16.2 (2026-11-21)

## 요청(대표님)
- 사용자는 지시문만 복사해 붙이는 경우가 많을 것이다. '지시문 복사' 한 번에 지시문과 내 음식·운동 이력을 모두 넣는다.
- 목록 버튼은 없앤다.
- 기간은 기록일 기준이다(달력 날짜가 아니다). 30·50·10일 중 Claude가 제안하면 대표님이 수용한다.

## 결정(Claude 제안 → 적용)
- **기록한 날 기준 최근 30일.**
  - 한 달 정도면 자주 먹는 음식과 하는 운동이 대부분 들어가고, 지시문 길이도 부담이 없다.
  - 10일은 가끔 먹는 음식이 빠지고, 50일은 길이만 늘어난다.
- 음식은 식사 기록일, 운동은 운동 기록일로 따로 센다. 운동은 매일 하지 않으므로 더 넓게 담긴다.
- 직접 등록한 음식(대표값·공용 도감 제외)은 기간과 상관없이 넣는다.
- 상한은 그대로다(음식 300, 운동 150).

## 바꾼 것
- `app/ai-paste.js`
  - `CONTEXT_RECORD_DAYS = 30`. `aiContextText(db, {days})`는 기록일 집합으로 거른다. 머리글은 '[내 기록 목록] … 기록한 날 기준 최근 30일과 직접 등록한 음식 … 목록에 없는 건 새로 적어도 돼'.
  - `fullPrompt(db)` = 지시문 + 내 목록.
  - 화면에서 '내 음식·운동 목록 복사' 버튼을 지웠다. '지시문 내용 보기'에 전체가 보이고, 안내 문구를 바꿨다.
- `app/app.js`: '지시문 복사'가 `fullPrompt(db)`를 복사한다. 토스트는 '지시문과 내 최근 기록 목록을 복사했어요'. `ai-copy-mine` 처리는 지웠다.
- 친구 시험 안내 페이지: 앱의 '지시문 복사'를 권장으로 바꿨다. 페이지 버튼은 목록 없는 기본 지시문이다. 3.16.2 APK 링크.
