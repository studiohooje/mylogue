# 4.0.1 작업로그 — AI 초안 알림 확정 실패 이유 표시

작성 2026-11-21 · Claude

## 요청
대표님: PC의 AI와 연동된 상태에서 알림의 '확정'을 눌러도 입력이 안 됨. 토스트 "0건 확정 · 1건은 내용 확인이 필요해요", 알림에는 '✓ 확정했어요'가 남음(초안은 그대로 대기).

## 원인 조사
- `aiConfirmMany`가 `resolveAIDraft`의 오류를 삼키고 일반 문구만 띄웠다. 알림 패널은 성공 여부와 상관없이 '확정했어요'를 기록했다.
- 같은 모양의 식사 초안(현재·미래 시각, 추정치 포함)을 `validateDraftRecords`로 변환해 보니 정상 → 앱 쪽 변환(4.0.0 예정 판정 포함)은 문제 없음. 거절은 서버 확인 단계에서 남: ①같은 내용 기존 기록(날짜·분·끼니·음식·양이 같음) ②이미 처리된 초안 ③같은 초안 기록 존재.
- 화면상 타임라인에 이미 '콩 현미밥 200g'이 든 식사가 있어 ①일 가능성이 높음. 대표님 계정 데이터는 보지 않았으므로 확정하지 않음.

## 바꾼 것
- `ai-drafts.js`: 중복 거절 문구가 겹치는 기존 기록의 날짜·시각·이름·양을 알려 줌(`duplicateMessage`, code `duplicate`).
- `app.js`: `aiConfirmMany`가 실제 오류를 보여 줌(1건이면 그 이유 그대로, 8초), `{ok, failed}` 반환. 알림에서 실패하면 '확정했어요' 기록을 남기지 않음. `toast(msg, ms)`.
- 시험 `tests/v401.test.js`.
