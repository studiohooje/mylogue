## 요청
- 대표님: 시작 문답 "어디서 운동하세요?"와 '내 헬스장'에서 지도를 열어 고를 수도 있게(이름 입력만이 아니라). 네이버도 가능한지 질문 → 카카오로 결정("ㅇㅋ 그럼 작업해봐").

## 지도 회사 선택 근거
- 네이버: 장소 검색(지역 검색)이 Client Secret을 요구해 서버(=Firebase Blaze 요금제)가 필요하고 한 번에 최대 5건. Spark 유지 원칙과 맞지 않아 보류.
- 카카오: JavaScript 키 + 도메인 제한으로 브라우저에서 바로 장소 검색(services 라이브러리) 가능. 계정의 **첫 번째** 카카오맵 활성 앱에만 일간 무료 쿼터 제공.

## 바꾼 것
- 새 파일 `app/places.js`
  - 저장 형식 `cleanPlace`: `{name,address,lat,lng,provider:'kakao'|'manual',providerId,category}`. 좌표가 범위를 벗어나거나 하나만 있으면 둘 다 null.
  - `settings.gyms`(이름 목록, 기존 운동 기록·머신 연결이 쓰는 값)는 그대로 두고 `settings.gymPlaces[이름]`에 위치를 더함. 위치 없는 직접 입력은 이름만.
  - `addGymPlace`/`removeGym`(삭제 시 위치도 함께), `cleanGymPlaces`(가져오기·복원 때 목록에 없는 이름의 위치는 버림), `centerFor`(지도 시작: 저장한 헬스장, 없으면 서울시청·넓게).
  - 카카오 SDK는 '찾기'나 '지도에서 고르기'를 처음 누를 때만 불러온다(앱 시작 속도 영향 없음). 10초 안에 못 불러오면 안내 문구와 '이름만 직접 입력' 유도.
  - 근처 목록: 지도 가운데 반경 800m '헬스' 검색, 거리순, 운동시설 분류(스포츠시설·헬스·피트니스·요가·필라테스·크로스핏 등)만 남김(연구소 등 섞임 제거). 지도를 너무 넓게 보면(레벨 7 이상) 확대 안내.
- `app/app.js`: 설정 '내 헬스장'을 새 화면으로 교체, `gym-map` 모달(렌더 뒤 지도 다시 붙이기, 지도 이동 0.35초 뒤 근처 검색, 늦게 온 응답 무시), '내 위치로'(geolocation 1회, 정확도 낮음, 저장 안 함), 검색·이름 붙이기 제출 처리.
- `app/domain.js`: `normalizeDB`에서 `gymPlaces` 정리(비어 있으면 키를 두지 않아 기존 데이터 모양 유지).
- `app/prefs.js`: 시작 문답 장소 질문 안내 문구 갱신.
- `app/aurora-theme.css`: 검색줄·결과 목록·지도 틀·가운데 핀·주소 표시 스타일.
- Android `AndroidManifest.xml`: `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION`('내 위치로'에서만 사용).
- 버전 3.6.0: package.json·lock, install.js APP_VERSION, index.html `?v=` 5곳, sw.js CACHE `mylogue-shell-v3-6-0-places`+FILES, build.mjs 복사 목록, build.gradle versionCode 19 / 3.6.0-beta.
