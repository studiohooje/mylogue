## 3.7.0 배포 누락 사고
- 3.7.0 커밋(906e264)이 **이전 APK 삭제만 담고** 나머지 파일은 빠졌다. 원인: `git add -A <여러 경로> Mylogue-Beta-3.6.0-debug.apk 2>/dev/null`에서 이미 git rm한 경로가 pathspec 오류를 내며 add 전체가 실패했고, 오류 출력을 숨겨 놓쳤다.

- 조치: 3.7.0 변경을 3.8.0에 모두 담아 배포. 앞으로는 저장소 루트에서 `git add -A` 후 `git show --stat`으로 커밋 내용을 확인한다(배포 확인 시 install.js 버전이 안 바뀌면 바로 커밋부터 의심).

## 요청(대표님)
1. AI 검토함이 칸이 넓고 컴팩트하지 않음 → 촘촘하게.
2. AI 연결이 어려움 → 한 번 연결하면 그 PC에서 계속 연결.
3. 홈 식단 카드에 타깃 탄단지·칼로리 그래프, 초과·부족을 명확하게(색 포함).
4. AI 연결한 일반 사용자도 AI 검토 알림을 관리자 알림처럼 받고 종 표시.
5. 알림 종류(AI 검토 / 관리자 승인 / 기타)별 색 구분.
6. AI 검토함 일괄 승인·일괄 취소.

## 바꾼 것
- `app/nutrition-goals.js`: `macroStatus`(±5% 달성, 부족/초과/목표 없음), `macroGoalsHTML`(목표선, 넘친 부분 줄무늬, 부족·초과 수치, 칼로리 남음/초과 칩). `app/timeline-view.js` 홈 '오늘 한눈에'를 체중·운동 2칸 + 식단 전체 폭 카드로(식단을 기록 대상으로 고른 경우).
- `app/ai-inbox.js`: 초안마다 한 줄(선택 체크, 종류 태그, 제목, 요약, 원문 한 줄, 확정/버리기), 편집 폼은 '내용 확인·수정'으로 접음. 상단 고정 일괄 도구(전체 선택, 선택 확정, 선택 버리기). 최근 처리 목록도 한 줄씩. `draftTitle`·`draftSummary` 내보냄.
- `app/app.js`: 바로 확정(`aiConfirmMany`: 초안 내용 그대로 확정, 실패 건은 수정 안내), 일괄 확정·버리기(확인 창). 알림을 관리자 + AI 연결 사용자(`prefs.aiLinked` 또는 이 기기 기존 연결)로 확대, AI 초안을 알림에 포함(확정·버리기·검토하기·나중에), 시작·복귀 시 AI 초안 새로고침.
- `app/admin-panel.js`: AI 초안 항목, 종류 태그·색 클래스(k-ai 보라 / k-user 호박 / k-request 하늘), 문구 '알림'.
- AI 연결(설정 '내 AI 연결'): 포트·8자리 코드 입력 폼 제거 → 이 PC의 도구 상태 확인(`GET 127.0.0.1:43127/status`) 후 '이 PC의 AI 도구와 연결' 버튼 한 번. 연결됨/연결 전/도구 꺼짐 배지, '이 PC 연결 해제', 고급: 포트 바꾸기.
- `app/ai-drafts.js`: `bridgeStatus`, `pairLocalAgent(port,{remember})`(ID 토큰 + 갱신 토큰 전달), `unpairLocalAgent`.
- `agent-bridge`(3.8.0):
  - 고정 포트 43127(사용 중이면 임시 포트로, 환경변수 `MYLOGUE_BRIDGE_PORT`).
  - 코드 없이 허용된 마이로그 주소(Origin)에서만 `/pair`·`/status`·`/unpair`.
  - 갱신 토큰을 `~/.mylogue/ai-bridge.json`(사용자 폴더, 권한 600, 저장소 밖)에 저장하고 시작 시 자동 연결, 요청 직전 `securetoken`으로 새 ID 토큰 발급(5분 여유), 401이면 한 번 갱신 후 재시도.
  - 해제 시 파일 삭제.
  - **보안 판단**: 같은 PC의 브라우저가 이미 같은 갱신 토큰을 보관하므로 위험 수준이 비슷하다고 보고 대표님 요청(계속 연결)을 우선했다. 브라우저가 아닌 로컬 프로그램은 Origin을 꾸밀 수 있으나, 할 수 있는 일은 자기 계정 토큰을 넣는 것뿐이다(도구는 토큰을 밖으로 돌려주지 않음).
- `prefs.aiLinked`(계정 설정에 동기화 → 휴대전화에서도 종 표시).
- 버전 3.8.0(versionCode 21), sw CACHE `mylogue-shell-v3-8-0-notice`.
