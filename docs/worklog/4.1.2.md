# 4.1.2 작업로그 — 새 기기 첫 동기화가 충돌로 멈춤

작성 2026-11-21 · Claude

## 요청
대표님: 웹(mooncurvv)에는 기록이 잘 있는데 APK 설치 후 로그인하니 첫 사용자처럼 비어 있음.

## 원인
- 동기화는 로컬·서버·기준(baseline: 마지막 동기화 상태)을 비교한다. 새 기기는 baseline이 없고, 로컬에도 기본 설정값(목표 칼로리 2200 등 `settings~*`, 시작 문답 답)이 있다.
- 서버 값(웹에서 바꾼 목표 등)과 다르면 l≠r, l≠b(없음), r≠b → **충돌**로 판정 → 충돌이 하나라도 있으면 동기화 전체를 멈춤 → 기록이 하나도 안 내려옴. (설정 화면에만 '동기화 충돌 확인 필요'로 표시됨)

## 바꾼 것
- `cloud-model.js` `isFreshDevice`(baseline 없음 + 이 기기에 직접 남긴 목록 기록·즐겨찾기 없음)와 `planSync(..., {fresh})`: 새 기기 첫 동기화에서는 기준 없는 충돌을 서버 값으로 해결(서버에 없는 키는 이 기기 값 유지).
- 이 기기에 직접 남긴 기록이 있으면 예전처럼 충돌을 보여 준다(데이터 보호).
- 충돌 상태는 앱을 다시 열면 다시 계산되므로, 업데이트 후 앱을 열면 자동으로 받아진다.

## 시험
- `tests/v412.test.js`: 예전 규칙은 충돌, 새 규칙은 충돌 0·기록·서버 설정 받기·서버에 없는 이 기기 값 유지. 기록이 있으면 fresh 아님. `npm test` 240 통과.
