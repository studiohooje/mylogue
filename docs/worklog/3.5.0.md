# 작업로그 — Mylogue Beta 3.5.0 (2026-11-20)

## 요청
- 대표님 "3.5.0 진행": 운동 '계획 → 안내' 모드(지인 피드백 — 미리 입력하고 알림 받기, 애플 러닝 인터벌처럼 "10초 휴식, 3·2·1, 2번째 세트 시작", 오버페이스 방지, 폰을 덜 보기).

## 바꾼 것
- 새 파일 `app/guide.js`
  - 계획: 종목·무게·단위·횟수·세트·휴식(10~600초), '지난 운동 그대로', '루틴 · 이름'으로 채우기, 검증.
  - 진행 상태: work → (세트 끝) → rest → (시간 끝/바로 시작) → work … → done. +30초, 이 종목 건너뛰기, 무게·횟수 바꾸기(남은 세트에 적용), 운동 끝내기(남은 세트 있으면 확인).
  - 안내: 10초 전 "휴식 10초 남았습니다", 3·2·1 비프+음성, 시작 시 높은 비프+"N세트 시작"/"다음 운동, 이름. 1세트 시작", 끝 "운동 끝! 수고했어요". 각 안내 한 번씩만.
  - 장치: Web Audio 비프(첫 터치 뒤), 기기 음성 합성(ko-KR), 진동(navigator.vibrate, Android), Screen Wake Lock(안내 중, 화면 복귀 시 다시 요청).
  - Android: `@capacitor/local-notifications` 8.3.1로 휴식 끝 시각에 알림 예약(id 5101), 휴식이 일찍 끝나거나 운동을 끝내면 취소. 처음 시작 때 알림 권한 요청. 웹에서는 아무 동작 안 함.
  - 저장: 세트 끝마다 완료 세트만으로 운동 기록을 만들어 추가/교체(note '계획→안내 모드').
- `app/prefs.js`: 계획→안내 '곧 제공' 해제, `cue`(voice/sound/vibrate/silent), `keepAwake` 설정과 설정 화면 항목.
- `app/app.js`: 운동 버튼 라우팅(계획 화면 / 진행 중이면 진행 화면), 진행 화면 닫아도 안내 유지 + 운동 화면 '안내로 돌아가기' 카드, 250ms 진행 타이머(휴식 시간·원형 표시만 직접 갱신, 단계가 바뀔 때만 다시 그림), 화면 복귀 시 따라잡기.
- `app/aurora-theme.css`: 안내 화면(큰 목표 숫자, 원형 타이머, 큰 '세트 끝' 버튼, 최근 세트 기록).
- `app/package.json`: `@capacitor/local-notifications` 8.3.1. `cap sync`로 Android 플러그인 2개(Firebase 인증, 로컬 알림).
- 버전 3.5.0 / versionCode 18, 캐시 `mylogue-shell-v3-5-0-guide`.
