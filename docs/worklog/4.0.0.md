## 코치 모드 구조

- 코치 쪽 데이터: 코치 본인 `settings`의 `coachClients·coachTemplates·coachSessions·coachGroups·coachSchedules·pushPrefs·coachSeen` 키 → 기존 동기화(records) 그대로.
- 계정 사이: `invites/{8자리}`(7일, 1회) → 회원이 같은 묶음(batch)으로 초대 사용 + `links/{코치}_{회원}` 생성(범위 기본 꺼짐, '보낸 수업'은 항상). 코치는 `users/{회원}/aiDrafts`에 `sourceModel:'trainer'` 운동 초안만 만들 수 있고 처리는 회원만. 회원은 `sessionAcks`로 회신, 코치 앱이 읽어 상태·PT 차감 반영(한 번만).
- 코치는 회원 기록 원본을 읽지 않는다. 회원이 켠 범위의 요약만(`links.shared`: 최근 7일 따로 한 운동 수·최근 체중 8개·식단 기록일 수) 회원 앱이 올린다.
- 미가입 회원: 이름만으로 수업을 쌓아 두고(대기), 초대 수락 뒤 대시보드에서 '한꺼번에 보내기'.
- 일정: 주간 타임테이블, 반복 예약(최대 12주), 예약 → 수업 입력(회원·시각 자동), 회원 일정에 코치 예약 표시(`links.schedule`).
- QR: 외부 서비스 없이 앱 안에서 생성(`qr.js`, 바이트 모드·오류정정 M·버전 1~10). jsQR로 1·4·7·8버전 해독 확인.
- 로컬 화면 확인용 `?coach=demo`는 localhost에서만 동작(배포 주소에서는 꺼짐).
