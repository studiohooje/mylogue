# 작업로그 — Mylogue Beta 3.18.3 (2026-11-21)

## 요청(대표님)
- 운동 칸 아래 영역을 가로 절반으로 나눈다(보이지 않는 가상 공간).
  - 왼쪽 절반 가운데에 몸 그림.
  - 오른쪽 절반에 일~토. 요일은 그 자리에 고정하고, 그날 운동은 오른쪽으로 펼친다.
- 내용
  - 운동이 없으면(휴식도 없으면) 빈칸, 의도적 휴식은 휴식 아이콘.
  - 운동했으면 `웨이트(하체)`, 두 가지 이상이면 `웨이트(하체) + 필라테스`.
  - 넘치면 `…`, 마우스 오버 시 전체.
- 요일 정렬은 Claude가 제안한다 → **오른쪽 절반의 왼쪽 기준 정렬**로 적용했다(글자 공간 최대, 줄 시작이 가지런함).

## 바꾼 것
- `timeline-view.js`
  - `daySummary(workouts)`: 웨이트는 부위를 괄호로 묶고(예정·휴식 제외), 나머지는 대분류(러닝·유산소·필라테스·요가·기타)로 쓴다. `catOf`(quick-entry)를 쓴다.
  - 운동 칸 그림 영역은 `wv-fig`(몸 그림) + `wv-week`(요일 7줄)로 나눴다. 각 줄의 title이 전체 내용이다.
- `aurora-theme.css`: work-vis를 2칸 grid(1fr 1fr)로 바꿨다. 줄은 요일 14px 칸 + 내용(ellipsis)이고, 오늘은 강조, 휴식은 보라 달이다.
- `tests/v3182.test.js`: 7줄, 오늘 빈칸, `금 · 웨이트(하체)`, 목요일 휴식 아이콘.
