# 작업로그 — Mylogue Beta 3.11.0 (2026-11-20)

## 요청(대표님)
1. 메인 식단을 크게 만들지 말고 체중·식단·운동을 같은 간격으로 두되 그래프를 작게.
2. 운동을 입력했다면 그 칸에 오늘 많이 부하가 걸린 신체 부위를 색으로.
3. 운동 시간(시각)을 수정할 수 있어야 함.
4. 팝업 바깥을 누르면 닫히게. 수정한 게 있으면 저장 안 됐는데 닫아도 되는지 경고.
5. (질문) 운동 분석이 체계적이지 않다 — 원했던 것을 아는지 설명. 예전 요구를 못 찾으면 '사람들이 계속 들어오고 싶고 결제까지 할 만큼 매력적인지'를 기준으로 판단해 만들 것. 유료·무료 구분 없이 지금 다 만든다(과금은 나중). → 이번 버전에서는 설명과 설계안까지, 구현은 다음 버전.

## 바꾼 것
- `app/nutrition-goals.js` `macroMiniHTML`: 홈 3칸 크기의 식단 카드(누르면 식단 화면).
  - 칼·탄·단·지 4줄 미니 막대에 목표선과 초과분(복숭아색)을 표시한다.
  - 아래 한 줄에 남음·초과·달성을 보여 준다.
- `app/timeline-view.js`
  - 3.8.0의 전체 폭 식단 카드를 걷어내고 3칸으로 되돌렸다.
  - `todayMuscleLoads`: 오늘 완료 세트로 근육별 부하를 계산한다. 주 타깃은 세트 수, 보조 타깃은 0.5배로 센다. 타깃 정보가 없는 종목(예: 이너타이)은 부위(하체 등)로 대신한다. 최댓값의 60% 이상이면 '많이'로 본다.
  - 운동 칸은 기존 Body Atlas(`anatomySvg`, load 모드)의 작은 앞·뒤 그림으로 보여 주고, 많이 쓴 부위 이름을 붙인다(누르면 운동 화면).
- 운동한 시각
  - `domain.js` `cleanWorkout`에 `loggedAt`(선택)을 넣었다. `loggedAtTime`(HH:MM)이 오면 날짜와 합친다. 날짜만 바뀌면 기존 시각을 유지한다. 없으면 빈 값으로 두고, 그때 타임라인은 기존처럼 createdAt을 쓴다.
  - 빠른 수정에 '운동한 시각'과 '운동 시간(분)'을, 자세히 수정에 '운동한 시각'을 넣었다.
- 팝업 닫기
  - 어두운 배경(`#backdrop`)을 누르면 닫는다. 기존 닫기(×) 처리를 그대로 써서 문답 건너뛰기, 안내 계속 같은 동작이 유지된다.
  - 팝업 안 입력이나 빠른 수정 버튼(양·세트·종목 변경)을 건드리면 '작성 중'으로 표시한다. 이 상태에서 ×나 배경을 누르면 확인 창이 뜬다.
  - 다른 팝업으로 바뀌면 '작성 중' 표시를 초기화한다.
- 버전 3.11.0(versionCode 24), sw CACHE `mylogue-shell-v3-11-0-home`.
