## 결정·적용
- 중복 판정(`ai-drafts.js` `findDuplicate`): 식사는 초안의 음식이 **모두** 같은 날·같은 분·같은 끼니·이름·양으로 이미 있을 때만 중복. 운동·수치 등은 기존대로 기록 단위. 시각이 다르면 항상 통과(기존 규칙도 분 단위였음). 중복이면 확인 창 → `allowDuplicate`로 따로 저장 가능(알림 확정·검토함 확정 둘 다).
- 탄단지 창(`macro-plan.js`): `planStatus`(고정 영양소의 목표 대비 %, 비율 합, 남은/넘친 %, 맞추기 후보), `planStatusHTML`, `autoRest`(체중×g·고정 g로 바꿨는데 나머지가 없으면 탄수→지방→단백질 순으로 비율 하나를 나머지로), `applyFix`. 줄 결과는 목표 대비 %로, 나머지 줄은 "자동: 남은 칼로리를 채워요 → 지금 n%", 나머지가 하나면 '몫' 입력 숨김. 기존 합계 차이·비율 합 오류 문구는 상태 줄로 대체(저장 버튼 비활성은 유지).
