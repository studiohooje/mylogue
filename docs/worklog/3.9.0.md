# 작업로그 — Mylogue Beta 3.9.0 (2026-11-20)

## 요청(대표님)
- 로그인 후 나이·키·현재 체중 입력 → 유지 칼로리 러프 계산 → 감량/증량/유지 질문 → 타깃 칼로리·탄단지 매크로 제안.
- 직접 비율 입력(고급자)과 아예 모르는 사람용 둘 다.
- GLP-1 사용, 저탄고지, 간헐적 단식 등 성향을 처음에 물어 제안에 반영.
- 제안은 여러 개를 고를 수 있게: 매크로 "4:4:2 (설명·효능·주의)", 칼로리 "2000 (설명) / 2100 (설명) / 2300 (설명)".

## 바꾼 것
- 새 `app/nutrition-plan.js`
  - 계산: Mifflin-St Jeor 기초대사량(성별 '선택 안 함'은 남녀 중간값 -78) × 활동 계수 5단계(1.2~1.9), 50kcal 단위.
  - 최소 섭취 바닥: max(기초대사량, 남 1500 / 여 1200 / 선택 안 함 1350).
  - 칼로리 제안
    - 감량: -300 / -500 / -750 / 유지(참고). GLP-1이면 -750을 빼고 -300을 추천.
    - 유지: -150 / 0(추천) / +150.
    - 증량: +250(추천) / +400 / 유지.
    - 바닥 아래 값은 경고하고 추천하지 않음.
  - 탄단지 프리셋 7종(탄:단:지 %): 균형형 50:20:30, 고단백 균형 40:30:30, 고단백 감량 40:40:20, 운동 퍼포먼스 55:25:20, 저탄수 25:35:40, 저탄고지 5:25:70, 단백질 우선(GLP-1) 35:35:30. 각각 설명·효과·주의 문구가 있다.
  - 추천 순서: 키토 > GLP-1 > 감량=고단백 감량 > 증량=퍼포먼스 > 고단백 선호=고단백 균형 > 균형형.
  - 그 밖의 안내
    - 간헐적 단식·채식·GLP-1·체중당 단백질 1.6g 참고 문구를 보여 준다.
    - 직접 칼로리·직접 비율(합 100%)을 입력할 수 있다.
    - 저장은 기존 목표 형식(비율 모드 + g 자동 계산)으로 하고, 답은 `settings.nutritionProfile`에 남긴다.
- `app/app.js`
  - 문답 모달(`goal-wizard`)을 추가했다.
  - 시작 문답을 마칠 때 식단을 기록하고 아직 목표 문답을 안 했으면 바로 이어서 연다(건너뛰기 가능).
  - 설정 '추천받아 정하기'와 홈 식단 카드(목표 없을 때)에서도 열 수 있다.
- `app/nutrition-goals.js`: 설정 목표 카드 위에 추천 진입 상자를 넣고, 기존 입력은 '직접(고급)'으로 안내한다.
- `app/aurora-theme.css`: 문답 입력 칸, 추천 배지, 비율 카드(탄단지 색 막대·g·설명·효과·주의) 스타일.
- 버전 3.9.0(versionCode 22), sw CACHE `mylogue-shell-v3-9-0-goals`, FILES·build.mjs에 nutrition-plan.js.

## 시험
- `npm test`: 166개 중 164 통과, 2 건너뜀(에뮬레이터). 새 `tests/nutrition-plan.test.js` 5개. 처음에 시험의 손계산 기대값(기초대사량 1704)이 틀려 실패했고, 실제 공식값 1689로 고쳤다.
- 화면 시험(360px): 여성·34세·163cm·62kg·가벼운 활동·감량·GLP-1+간헐적 단식으로 진행했다.
  - 유지 1,800kcal과 기초대사량 1,308kcal이 나왔다.
  - 1,500 완만한 감량이 '추천', 1,300은 '바닥 아래, 권하지 않음'으로 나왔다.
  - 탄단지는 '단백질 우선(GLP-1)'이 추천 1순위로 나왔다(단백질 131g, 체중당 2.1g).
  - 저장한 뒤 홈 카드가 1,500kcal 기준으로 '+250kcal 초과'를 표시했다.
  - 가로 넘침은 없었다.
