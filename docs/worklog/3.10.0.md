# 작업로그 — Mylogue Beta 3.10.0 (2026-11-20)

## 요청(대표님)
1. 식단이든 운동이든 이미 입력한 걸 수정하기가 어려워 보인다.
2. 헤더의 ‘마이로그’를 누르면 홈으로(범위를 크게).
3. 계정 칩(닉네임)을 누르면 이름·아이콘을 바꿀 수 있게(커스터마이징). 승인됐으면 ‘승인됨’ 문구는 필요 없음.
4. 닉네임을 누르면 이름·아이콘 + 최초 로그인 때 고른 것(기록 방식)을 바꾸는 창, 맨 아래에 그 외 설정 페이지로 이동하는 버튼.

## 수정 화면 문제 진단(3.9.0)
- 홈 타임라인 카드에는 수정 입구가 없었다(식단·운동 화면으로 가야 함).
- 식사 수정은 음식 1개씩만 됐다. 그것도 ‘1회 칼로리·1회 탄수화물’ 같은 1회분 값과 수량을 따로 보여 줘서 헷갈렸다. 한 끼의 시각·끼니를 바꾸거나 음식 하나만 빼기 어려웠다.
- 운동 수정은 전체 입력 화면(세로 약 2,800px)을 그대로 열었다. 컨디션·수면 같은 항목 아래까지 내려가야 세트가 보였다.

## 바꾼 것
- 새 `app/quick-edit.js`
  - 식사 빠른 수정: `mealGroups`로 한 끼를 묶어 연다. 날짜·끼니·시각을 한 번에 바꾼다. 음식별 −/＋(g·ml은 10, 그 외 0.5 단위)로 양을 바꾸면 영양값을 같은 비율로 환산한다. 음식 빼기·되돌리기, 한 끼 전체 삭제(확인 창)가 있다. ‘영양값 고치기’는 기존 상세 화면, ‘음식 추가’는 같은 날짜·끼니·시각으로 기존 식사 입력을 연다.
  - 운동 빠른 수정: 종목별 세트 표(무게·횟수·완료)를 보여 준다. 세트 추가(직전 세트 복사)·삭제, 종목 빼기·되돌리기, 운동 삭제(확인 창)가 있다. 저장할 때 `weight`·`originalWeight`를 함께 바꾸고, 단위는 원래대로 둔다. 빈 종목이나 빈 세트는 막는다. ‘자세히 수정’은 기존 화면이다.
- 입구
  - 홈 타임라인 식사·운동 카드 오른쪽 위 ‘수정’.
  - 식단 화면 식사마다 ‘식사 수정’.
  - 운동 화면 목록의 ‘수정’은 빠른 수정으로 연다.
- 헤더: 로고·이름 영역 전체를 `data-page="home"`(role=link, 키보드 Enter/Space)으로 만들고, 터치 영역을 넓혔다.
- 새 `app/profile.js`: `settings.profile`(닉네임 20자, 아이콘: Google 사진 / 글자+색 6가지 / 내 사진 160px JPEG로 줄여 저장)을 다룬다.
  - 계정 칩은 프로필 이름·아이콘을 쓰고, 누르면 ‘내 프로필’ 창이 열린다.
  - 창 구성은 이름·아이콘, ‘나의 기록 방식’(설정과 같은 화면, 바로 적용), ‘식단 목표 다시 정하기’, 맨 아래 ‘그 외 설정으로 이동’이다.
  - 승인된 계정은 상태 문구를 숨긴다.
- 버전 3.10.0(versionCode 23), sw CACHE `mylogue-shell-v3-10-0-edit`, FILES·build.mjs에 quick-edit.js, profile.js를 넣었다.
