# 작업로그 — Mylogue Beta 3.0.1 (2026-11-19)

## 요청
- 대표님: 로그인 버튼·사용자 프로필이 명확하게 보여야 한다. (기존에는 하단 '설정' 화면 안에서만 로그인 가능, 상단 오른쪽 문구는 650px 이하에서 숨김)

## 바꾼 것
- `app/app.js`: 고정 문자열 `header`를 `header()` 함수로 바꾸고 `accountChip()` 추가. 상태별 표시
  - 서버 미설정·Android 로그인 모듈 없음: 표시 안 함
  - 로그아웃: `#cloud-login` 버튼(사람 아이콘 + '로그인' + '기록 동기화') → 기존 로그인 동작 그대로
  - 로그인: Google 프로필 사진(없으면 이름 첫 글자) + 이름/이메일 + 승인 상태 색(청록 승인됨, 호박색 대기·신청 필요, 분홍 반려) → `data-page="settings"`
- `app/aurora-theme.css`: `.account-chip` 등 추가. 터치 높이 44px, 이름 말줄임, 650px 이하에서 부제 숨김, 380px 이하에서 로그인 칩은 '로그인'만, 계정 칩은 승인 상태만 표시.
- 버전 3.0.1, Android versionCode 12, 서비스워커 캐시 `mylogue-shell-v3-0-1-account`.

## 시험
- `npm test`: 117건 중 116건 통과, 1건 에뮬레이터 전용 건너뜀.
- `npm run build` + `verify-build.mjs` 통과.
- 헤드리스 Chrome으로 360·390·412·1280px 캡처: 로그인 칩과(로그인 상태는 화면에 예시 칩을 주입해) 계정 칩 모두 가로 넘침 없이 한 줄 정렬 확인. 실제 Google 로그인 후 사진·이름 표시는 배포 후 확인 필요.
