## 한 일
- **이전 Firebase `mylogue-5ce38`(hwj.rouget 계정) 프로젝트 삭제**: 콘솔 '프로젝트 삭제' 완료 메시지 확인. 30일 안에는 Google Cloud 콘솔에서 복원 가능. 같은 계정의 moonpd·raidkorea 프로젝트는 그대로.
- 새 파일 `app/install.js`
  - `APP_VERSION`(앱 화면 버전 표기와 APK 파일 이름의 단일 출처), `detectDevice()`(android / ios(iPadOS 데스크톱 모드 포함) / desktop)
  - `installChip()`: 상단 계정 버튼 왼쪽 '앱 설치' 버튼. Capacitor 앱 안이거나 홈 화면 앱(standalone)으로 실행 중이면 숨김.
  - `installModalBody()`: Android = APK 내려받기(+ZIP 대체 링크, 설치 4단계), iOS = Safari 공유 → 홈 화면에 추가 4단계(아이콘 SVG), PC = 가능하면 '이 컴퓨터에 앱으로 설치'(beforeinstallprompt) + 두 방법 모두.
  - `initInstall()`: `beforeinstallprompt`를 가로채 Android 크롬 자동 '웹앱 설치' 배너를 막고 APK로 유도.
- `app/app.js`: import, 헤더 버전을 `APP_VERSION`으로, 헤더에 설치 버튼, `modal==='install'` 팝업, 클릭 처리, 시작 시 `initInstall`.
- `app/aurora-theme.css`: `.install-chip`(44px 터치, 380px 이하 아이콘만), `.install-*` 팝업 스타일. 안내 글자 14px·보조 13px, keep-all.
- `app/build.mjs`, `app/sw.js` FILES에 `install.js` 추가. 캐시 `mylogue-shell-v3-1-0-install`.
- 시험 `tests/install.test.js` 3건: 기기 판별, APP_VERSION = package.json 버전·APK 파일 이름, 기기별 안내 내용.
- 첫 실행 때 앱 화면 시험 6건 실패(`addEventListener is not defined`, Node 시험 환경) → `globalThis.addEventListener?.`·`globalThis.navigator?.`로 보호 후 통과.
- 버전 3.1.0 / versionCode 14. 3.0.2 APK 삭제, 3.1.0 APK 커밋.
- 규칙 추가: CLAUDE.md 5·6절(APP_VERSION, 매 업데이트 APK 재빌드), Claude 메모리.
