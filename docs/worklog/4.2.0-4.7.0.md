## 시험

- 각 배포마다 `npm test`(4.7.0 기준 270건 통과), `npm run build` + `node verify-build.mjs`, 헤드리스 Chrome으로 360~1280px 화면 캡처·주요 흐름 클릭 확인(qa441·qa442·art450·wk450·mot460·glp470 스크립트).
- 동기화 규칙은 Node에서 `planSync` 직접 실행(tests/v412). Firestore 규칙은 이번 범위에서 바뀌지 않았다.
- **못 한 것**: Firebase 실계정에서 'AI 초안 모두 확정', 실기기에서 화면 꺼짐 방지·앱 바로가기·사진 공유·소리 없는 동작. → 실기기 점검표로 대표님 확인.

## 실수와 고친 것

- 4.2.0~4.4.3 동안 패치노트까지 미뤘다(지시를 넓게 해석). git 기록으로 채우고, 앞으로 패치마다 쓴다.
- 그래프 미리보기에서 서비스 워커 캐시 때문에 옛 CSS가 보여 잘못 판단할 뻔함 → 점검 스크립트에서 캐시를 지우고 다시 확인.
- GLP-1 단백질을 권고 하한(1.2g)으로 처음 계산하니 이전(칼로리 35%)보다 오히려 적게 나옴 → 대표님 방향에 맞춰 범위 위쪽 + 절대량 80~120g으로 조정.
