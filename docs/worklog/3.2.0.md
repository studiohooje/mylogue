# 작업로그 — Mylogue Beta 3.2.0 (2026-11-20)

## 요청 (대표님)
- GPT로 아이콘·이미지를 만들어 마이로그의 유니크함을 더하기(모던·트렌디·'자꾸 들어오고 싶게'). 앱 아이콘은 유지, 마코치는 보류.
- 기능 아이콘 10종 비교 → **03 솔리드** 선택 → Claude 추천대로 활성=솔리드, 비활성=같은 외곽의 선.
- 외곽선(비활성) 색: 연보라 → 아이보리로 바꿨으나 Claude 비교안 중 **프로스트 #c9d6e6** 선택.
- 오브제·배경 재요청(원판·아침·밤) 결과를 받은 뒤 한 번에 배포.

## GPT 작업 흐름 (지시서는 `GPT Source/`)
- 01 아이콘 10종 → 02 03번 다듬기+선 버전 → 03 배경·오브제 → 04 재요청 3건.
- Claude 검토에서 지적: 초안의 앱 아이콘 변경 제안(이미 2.1.1 확정)·마코치 '확정' 서술 오류·A안 고정 이미지 한계·비교 페이지 360px 넘침(icons-final) 등.

## 바꾼 것
- `app/brand-icons.js`: GPT `icons-final`의 line/solid 8종을 내장. `brandIcon(name, className, active)` — active면 솔리드. **운동 아이콘은 Claude가 다시 그림**(GPT 안은 한 덩어리 외곽이라 'H'처럼 읽힘 → 원판·봉 분리, 솔리드는 원판 사이 틈). `heroSlot()`(05–11 아침, 11–17 낮, 17–21 저녁, 그 외 밤), `emptyArt()` 추가.
- `app/app.js`: 하단 탭 활성 탭에 솔리드, '추가'는 솔리드. 몸·운동 빈 화면에 오브제.
- `app/timeline-view.js`: 히어로에 `hero-art hero-<시간대>` 클래스, 타임라인 빈 화면 오브제.
- `app/food-view.js`, `app/ai-inbox.js`: 빈 화면 오브제.
- `app/aurora-theme.css`: 하단 탭 비활성 #c9d6e6·활성 #8ce4e0, '추가' 글자는 프로스트·아이콘만 남청(첫 적용 때 '추가' 글자가 어둡게 묻히는 문제 발견 후 수정). 시간대별 배경(모바일 ≤650px는 900×600, 그 이상은 2000×667), 기존 장식 고리 숨김, 아침은 밝아서 왼쪽에 옅은 어둠 그라데이션+글자 그림자. 빈 화면 오브제 104px.
- `app/art/`: GPT 원본 PNG(장당 0.4~2MB)를 WebP로 압축 — 배경 8장 8~22KB, 오브제 5점 15~26KB, 합계 약 230KB. 배경은 그라데이션 띠 방지를 위해 품질 90.
- `app/build.mjs`: `art/*.webp` 복사. 서비스워커는 네트워크 우선+자동 캐시라 사전 캐시 목록에는 넣지 않음.
- 버전 3.2.0 / versionCode 15, 캐시 `mylogue-shell-v3-2-0-art`, `install.js` APP_VERSION 3.2.0.
- `.gitignore`: `GPT Source/**/*.png`(원본 대용량은 저장소에 올리지 않음. 지시서 md·SVG·비교 html은 올림).
