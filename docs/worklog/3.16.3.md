# 작업로그 — Mylogue Beta 3.16.3 (2026-11-21)

## 요청(대표님)
- 종을 눌러 연 알림 창은 다른 배경을 누르면 저절로 사라진다(흔한 알림).
- 종을 누르지 않아도 뜨는 메이저 알림은 다른 곳을 눌러도 사라지지 않고, '나중에 확인'을 눌러야 사라진다.

## 바꾼 것
- `app/app.js`
  - `adminState.via`에 알림 창을 연 방법을 기록한다: 종을 누르면 `'bell'`, 자동으로 열리면(`adminAutoOpen`) `'auto'`, 닫히면 `''`.
  - root의 click 캡처 단계에서 `closesOnOutside`가 참이면 `adminState.open=false`로 바꾸고 `.admin-panel` 요소만 지운다. 전체를 다시 그리지 않으므로 누른 입력칸의 커서가 튀지 않고, 누른 버튼의 원래 동작도 이어진다.
- `app/admin-panel.js`: `closesOnOutside(state, target)`. 종으로 연 창에서 창 밖·종 밖을 눌렀을 때만 참이다.
- 자동으로 연 창은 지금처럼 '나중에 확인'·'모두 나중에 확인'·종으로만 닫힌다.
