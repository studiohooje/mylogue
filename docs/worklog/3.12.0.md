# 작업로그 — Mylogue Beta 3.12.0 (2026-11-20)

## 요청(대표님)
- 프리웨이트·기본 머신의 타깃 근육은 조사하면 나온다. 유저가 직접 고르는 구조는 별로 → 기본 타깃을 자동으로, 비어 있는 것들을 직접 조사해서 다 채울 것.
- 머신 제조사까지 다 하는 건 무리 → 웬만한 헬스장에 있는 머신(레그 프레스, 핵 스쿼트 등)을 전부 등록.
  - 무게·강도는 범용으로: kg·lb를 모두 보여 주고, 양쪽인지 한쪽인지 감안해 모든 제조사 머신을 포괄할 선택지·무게 선택지를 만든다.
- 제조사 입력도 가능하게: 등록 요청 → 승인 → 그 헬스장에 입고. 헬스장을 고르면 일반 ‘레그 프레스’도, 승인된 ‘싸이벡스 레그 프레스’도 고를 수 있게.

## 조사
- 머신 사양 조사 노트: `research_notes/gym_machines/machines.md`(출처 23개, 범용 머신 57종, 제조사별 스택 단위, 원판식 시작 저항, 한국 단위 사정, 데이터 모델 제안).
  - 핵심 근거
    - Life Fitness 보조추 2.5kg, Cybex 10lb 판과 5lb 단위 보조추, Technogym 2.5kg, Matrix 10lb, Panatta 2.5kg.
    - 스택 표기는 실제 저항이 아니다(제조사 공식 블로그).
    - 원판식 시작 저항: 45° 레그 프레스 약 34~57kg, 핵 스쿼트 27~61kg, 펜듈럼 21~50kg, T바 로우 약 18kg.
    - 사용자는 보통 원판 합만 기록한다([추론]).
  - 확인 못 함: 국산 브랜드(DRAX·뉴텍·IMP·레드엔진) 스택 규격, Nautilus, 스미스 바 무게.
- 운동별 근육: ExRx 디렉터리·ACE·NASM의 주동근·협력근 분류를 마이로그 근육 지도 15구역으로 단순화(일반 지식 수준, 원문 대조는 일부만).

## 바꾼 것
- 새 `app/exercise-data.js`: 확장 종목 147개(가슴·등·하체·어깨·팔·복근·전신)와 유산소 7개.
  - 종목마다 주·보조 타깃, 장비(바벨·덤벨·케틀벨·머신·케이블·스미스·맨몸·EZ바·원판), 한쪽씩 여부, 한 손 여부, 별칭을 담았다.
  - 직접 만든 종목의 타깃을 추정하는 이름 규칙 22개도 넣었다.
- `app/catalog.js`
  - 기존 51종은 ID·이름을 그대로 두고 확장분을 이어 붙였다(이름이 겹치면 기존 우선). 합계 207종, 근력 191종 모두 주 타깃이 있다.
  - `findExercise`: 띄어쓰기·괄호를 무시하고 이름·별칭으로 찾는다.
  - `inferTargets`: 도감 → 이름 규칙 → 부위 기본값 순서로 타깃을 추정한다.
- `app/domain.js`
  - `cleanExercise`·`cleanCustomExercise`는 사용자 지정 → 도감(별칭 포함) → 추정 순서로 타깃을 채운다.
  - 직접 만든 종목에는 `targetSource`(user/auto)를 남긴다. 예전에 저장된 기록도 다시 정리할 때 채워진다.
- 새 `app/machines-catalog.js`
  - 일반 머신 49종을 담았다. 각 항목: `gm:` ID, 이름, 연결 종목, 방식(stack/plate/cable/smith/body), 좌우(both/iso/single), 별칭, 메모(시작 저항·보조 무게 주의).
  - `weightSteps`: 방식·단위별 ± 단계.
  - `otherUnit`: kg↔lb 환산 표시. 저장은 입력값·단위 그대로다.
  - 제조사 모델 ID 만들기와 헬스장별 제조사 머신(`brandMachinesAt`)을 처리한다.
- 빠른 운동 입력(`quick-entry.js`)
  - 머신 선택을 세 묶음으로 나눴다: 내가 등록한 머신 / 이 헬스장 제조사 머신(공용 도감) / 일반 머신(어느 헬스장이나).
  - 선택한 머신의 방식·좌우·메모를 보여 준다.
  - 세트 입력에 kg↔lb 환산과 ± 단계 버튼을 넣었다.
  - 아이소래터럴 일반 머신은 한쪽 무게 기록 → 볼륨 ×2(`weightBasis per-hand, handCount 2`)로 계산한다.
- 자세한 입력(`ui-helpers.js`): 머신 목록에 일반 머신 묶음을 더했다. 아이소래터럴을 고르면 한쪽 기준으로 바뀐다. 기록 목록에서도 일반 머신 이름이 보인다.
- 제조사 머신 입고: 관리자가 머신 등록 요청을 승인하면(설정 목록·알림 팝업 모두) 공용 도감에 자동으로 올라간다.
  - 올라가는 항목: `machineModels`(제조사·모델·연결 종목·타깃)와 `gymMachines`(헬스장 ↔ 모델).
  - 그 헬스장을 고른 사용자에게 바로 보인다. 실패하면 알린다.
- 버전 3.12.0(versionCode 25), sw CACHE `mylogue-shell-v3-12-0-machines`, FILES·build.mjs에 exercise-data.js와 machines-catalog.js를 넣었다.
