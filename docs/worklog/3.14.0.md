# 작업로그 — Mylogue Beta 3.14.0 (2026-11-21)

## 요청(대표님)
- 자동완성(검색어 추천)을 당장 구현해야 한다.
  - 'ㄷ'만 써도 검색창 아래에 캡슐 칩 약 5개가 가로로 뜬다(포털처럼 세로 목록이 아님).
  - '닭' → 닭가슴살·닭다리살 같은 대분류. 누르면 제품 소분류가 펼쳐지고, 내가 가장 많이 먹은 것이 위에 온다.
- 한/영 오타 지원: 'ekfrrktmatkf'·'ekfr'를 '닭'으로 알아듣는다.
- 운동도 같다: '레' → 레그 프레스·레그 익스텐션. 소분류 순서는 다음과 같다.
  1. 제조사 없는 일반 머신(각도별 포함)
  2. 내가 많이 쓴 머신(제조사 포함)
  3. 전체 사용자 빈도
- 음식 정렬 예: 김단단 30 → C 3 → A 1 → 전체 사용자가 많이 먹은 D.
- 전체 사용자 빈도는 익명 집계로(대표님 선택: '익명 집계 포함').
- (작업 중 추가) 대표값을 사용자가 고치면 그 사람에게만 고친 값이 늘 보이게 한다. 개인화된 값이라는 걸 테두리 색 등으로 알 수 있게.

## 바꾼 것
- 새 `app/suggest.js`: 검색 엔진.
  - 한글을 두벌식 자판 순서로 풀어 비교한다. 겹받침·겹모음은 누르는 순서로 나눠서, '다'·'달'처럼 조합 중인 글자도 '닭'에 맞는다.
  - 초성 검색(자음 2개 이상일 때 중간 일치).
  - 영문 자판 → 한글 자모 변환('ekfr' → ㄷㅏㄹㄱ).
  - `matchScore` 0~100. `rankItems`는 내 횟수 → 전체 횟수 → 일치도 순서로 정렬한다.
- `app/food-catalog.js`: 비어 있던 `FOOD_CATALOG`에 일반 음식 48개 대표값을 넣었다.
  - 100g 기준이고, 대분류 `group`과 별칭을 붙였다.
  - 값은 식약처 식품영양성분 DB·USDA 수준을 반올림한 것으로, `source:'대표값'`이다.
- 새 `app/suggest-ui.js`
  - 음식: 대분류(대표값 group + 이름에 group이 들어간 제품) 칩, 그룹에 속하지 않는 개별 음식 칩. 그룹을 펼치면 내 횟수 → 전체 횟수 → 대표값 순서로 보여 준다.
  - 운동: 종목 칩. 머신이 있는 종목은 펼치면 일반 머신 → 내가 쓴 머신(횟수순) → 나머지(전체 횟수순) → '머신 없이' 순서다.
- `app/quick-entry.js`
  - 검색창 아래 추천 칩 영역(`#sg-food`, `#sg-ex`).
  - 기존 결과 목록도 같은 엔진으로 거르고 정렬한다(오타 검색이 목록에도 적용).
  - 그룹을 펼치면 아래 목록을 숨긴다.
  - '내 값': 대표값·공용 음식과 같은 이름인데 내 음식/최근 기록의 영양값이 다르면 내 값이 우선이고 `personal` 표시(보라 테두리 + '내 값' 배지)를 붙인다.
- `app/app.js`
  - 한글 조합 중(composition)에도 추천 칩만 바로 다시 그린다.
  - 칩 펼치기와 머신 고르기 처리.
  - 익명 집계: 동기화 성공 뒤 최근 30일 새 기록만, 한 번에 최대 60건, 기록 ID로 중복 방지(`scopedKey('mylogue.pop-counted')`). 시작할 때 종류별 상위 400개 횟수를 불러온다.
  - 검색어 입력은 '작성 중'으로 보지 않는다(닫을 때 불필요한 확인 창이 뜨던 문제).
- `app/catalog-cloud.js`: `loadPopularity`, `bumpPopularity`(트랜잭션으로 +1 또는 새로 만들기), `popId`.
- `app/firestore.rules`: `popularity/{foods|exercises|machines}/items/{id}`.
  - 승인된 사용자만 읽고 쓸 수 있다.
  - 담는 것은 name·count·updatedAt뿐이고, 처음 만들 때 count는 1이다.
  - 갱신은 +1만 허용하고 삭제는 막는다.
  - **Firestore 규칙 배포 완료.**
- `app/cloud-ui.js`: 기록 이용 신청 안내에 익명 횟수 집계 한 줄.
- 버전 3.14.0(versionCode 28), sw CACHE `mylogue-shell-v3-14-0-suggest`, FILES·build.mjs에 suggest.js와 suggest-ui.js를 넣었다.

## 알려진 한계
- 제조사 제품(김단단·바르닭 등)은 영양값을 지어내지 않았다. 사용자가 등록하거나 관리자가 공용 도감에 올린 제품만 나온다.
- 전체 사용자 빈도는 승인된 사용자의 새 기록부터 쌓인다(지금은 사용자가 적어 영향이 작다).
