# 작업로그 — Mylogue Beta 3.18.0 (2026-11-21)

## 요청(대표님)과 결정
- 운동 '의도적 휴식'. 헤일로 완성에 악영향이 없어야 한다.
- 식사·운동·몸 기록 버튼에 우리 아이콘을 넣는다.
- 추가 메뉴의 AI 입력을 가운데 정렬한다. 홈 AI 버튼은 가운데 '운동 기록'과 같은 너비로 둔다.
- 홈 '오늘 한눈에 보기'
  - 체중: 30일 그래프, 'N일 전'.
  - 식단: '먹은 양 / 목표'(옅고 작게). '남음·달성' 문구는 뺀다.
  - 운동 안 한 날: 회복 느낌. '회복 중' 글자 없이 파랑·초록 펄스(대표님 결정).
  - '마지막 측정', '첫 운동을 기다려요', '기록이 쌓일수록 선명해져요'는 지운다.
- 목표 초과 막대(대표님 결정)
  - 평소엔 지금 축(목표×1.25)을 쓴다.
  - 하나라도 넘치면 네 막대 모두 ×2, 또 넘치면 ×4·×8로 늘린다.
- 인바디 체중은 평소 체중계 체중과 다르게 추적한다(대표님 결정).
  - '체중' 그래프와 '인바디' 그래프를 나눈다.
  - 체지방량·골격근량은 인바디 안으로 넣는다.
  - 인바디 kg 그래프는 항목별 작은 그래프로 나눴다. 값 차이가 커서 한 축에 그리면 선이 납작해지기 때문이다.
- 몸 화면: 기간을 드롭다운 대신 버튼으로, 마우스 오버 시 커서 옆에 날짜·체중.
- 예정 기록: 미래 시각으로 넣으면 '예정' → '확정' 버튼. '예정 포함' 토글(기본 꺼짐, 반투명).
  - 1시간 넘게 미확정이면 중요 알림이다. 종이 없어도 자동으로 뜨고 '나중에 확인'으로만 닫힌다. 종은 지금처럼 관리자·AI 연결 사용자만 본다(대표님 결정).
- 알림창에 AI 초안 일괄 확정·버리기.
- 기존 PC AI 연결은 유지하고 안내만 추가한다.
- 웹 타임라인은 3칸으로 컴팩트하게, 시각을 강조한다. 휴대폰은 그대로.
- 운동 대분류: 웨이트·러닝·필라테스·요가·기타 → 웨이트 아래 부위.
  - 부하·소비 칼로리는 미정이지만 기록과 헤일로는 가능하게 한다.
  - 종목별 기본 항목: 러닝은 거리·페이스·심박·강도, 필라테스는 수업 시간·형태·강도·메모.
- '몸' → '수치'(대표님 결정). 기록 종류를 가리키는 곳만 바꿨다. 맨몸·몸 부위·몸 쓰는 일은 그대로다.
