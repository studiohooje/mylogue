# 작업로그 — Mylogue Beta 3.15.0 (2026-11-21)

## 요청(대표님)
1. '내가 n번' 대신 'n회'를 작게 표시한다.
2. 아래 목록이 대중적인 순서라는 걸 드러내지 않는다. 우리만의 알고리즘으로 보이게 한다.
3. 레그 프레스처럼 머신이 꼭 필요한 종목에는 '머신 없이'가 있으면 안 된다. 다른 종목도 대충 했는지 전수 점검한다.
4. '머신 없이'를 많이 썼으면 맨 아래가 아니라 위쪽에 둔다.
5. (작업 중 추가) 연결할 수 있는 머신을 모두 조사해 넣는다.
   - 헬스장에 흔한 머신 종류를 대분류로, 제조사를 소분류로 등록한다.
   - 주동근·보조근은 사용자가 고르지 않는다. 머신마다 우리가 미리 정해 제공한다.

## 바꾼 것
- `app/machines-catalog.js`
  - 머신 종류 49 → 59개. 새로 넣은 종류:
    - 하체: 버티컬 레그 프레스, 파워 스쿼트(레버식), 니링 레그 컬, 멀티 힙, 리버스 하이퍼, GHD
    - 가슴·등: 와이드 체스트 프레스, 로우 로우, 로어 백(시티드 백 익스텐션)
    - 어깨: 슈러그 머신
  - 머신 종류마다 근육 부하표 `T`(주동근·보조근)를 넣었다. 케이블 크로스오버, 케이블 스테이션, 스미스는 동작마다 근육이 달라 비워 두고 종목 값을 쓴다.
  - `ALSO`: 같은 머신으로 하는 다른 종목을 연결했다. 이제 모든 머신·케이블·스미스 종목에 머신 종류가 있다.
  - `needsMachine(ex)`: 장비가 머신·케이블·스미스면 '머신 없이'를 숨긴다.
  - `BUILTIN_BRANDS`, `brandsOf(gmId)`: 제조사 모델이 종류의 방식·좌우·근육을 물려받는다.
  - `genericMachine(id)`: `bm:` ID도 찾는다.
  - `machineTargets(machine, exercise)`: 머신 주동근이 종목 주동근과 겹치면 머신 값을 쓴다. 다른 동작(레그 프레스로 카프 레이즈)이면 종목 값을 쓴다. 내 머신은 `baseId`의 종류 값을 쓴다.

  - Cybex Prestige VRS·Eagle NX

- `app/catalog.js`: 케이블 운동의 장비 분류를 고쳤다.
- `app/suggest-ui.js`
  - 음식 목록 제목은 대분류 이름만 쓰고, 행에는 칼로리와 작은 'n회' 배지를 둔다. '많이 먹는 제품', '대표값', '많이 먹은 순'을 지웠다.
  - 머신 목록 제목은 '머신 고르기'만 남겼다. '일반 → 내가 많이 쓴 순'을 지웠다.
  - '머신 없이'는 할 수 있는 종목에서만 보인다. 내 횟수(머신 없이 기록한 횟수)대로 사용한 머신들 사이에 정렬하고, 안 썼으면 맨 아래에 둔다. 태그는 그 종목의 장비(맨몸·바벨 등)다.
  - 머신 종류 행 옆에 '제조사 N ▾' 버튼을 두고, 누르면 그 아래로 제조사 모델이 펼쳐진다. 내가 쓴 제조사 모델은 위쪽 '사용한 머신'에 같이 올라온다.
  - 칩 펼침 표시(▾)는 실제 머신이 있을 때만 붙는다.
- `app/quick-entry.js`: 저장할 때 머신의 근육 부하를 기록에 넣는다. 제조사 모델 이름 표시를 추가했다.
- `app/ui-helpers.js`: 운동 수정 화면의 머신 선택에 '제조사 모델' 그룹을 추가했다.
- `app/app.js`
  - 제조사 펼치기(`data-sg-brand`)를 처리한다.
  - 제조사 모델을 고르면 그 라인의 단위(lb/kg)가 기본값이 된다.
  - 수정 화면에서 머신을 바꾸면 근육 부하를 다시 계산한다.
- `app/profile-forms.js`, `app/domain.js`: 내 머신 등록에 '머신 종류'(`baseId`, `gm:`만 허용)를 추가했다. 종류를 고르면 근육은 앱이 맞춘다.
- `app/aurora-theme.css`: 'n회' 배지, 제조사 버튼과 펼친 행(이름 위·라인 아래 두 줄)의 스타일.
