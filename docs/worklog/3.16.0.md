# 작업로그 — Mylogue Beta 3.16.0 (2026-11-21)

## 요청(대표님)
- 휴대폰에서 AI로 편하게 입력하고 싶다. 실사용 테스터인 친구는 휴대폰 ChatGPT를 주로 쓴다. 되는 것과 안 되는 것을 분명히 말해 달라는 요청이었다.
  - 1차 답변: 지금의 로컬 MCP 연결은 휴대폰에서 불가능하다.
  - 서버 없이 바로 되는 방법은 '지시문 + 코드 붙여넣기/공유'다(1단계).
  - ChatGPT 안에서 바로 검토함에 넣는 방식(2단계)은 서버와 OAuth가 필요하다. 휴대폰 지원도 OpenAI 쪽 보고상 불확실하다.
- AI가 준 명령어(코드)를 붙여넣는 입력 칸을 만든다. 1단계의 실제 예시도 보여 달라고 했다.
- 'AI로 입력'은 신비하고 꼭 누르고 싶은 버튼으로 만든다.
  - 홈의 식사/운동/몸 버튼 위, 맨 위에 둔다. '빠른 기록' 제목은 없앤다.
  - 누르면 코드 입력 칸과 검토함 이동 버튼이 나온다.
- 하단 '추가' 메뉴에도 맨 위에 AI 입력을 둔다.
- 입력 칸 옆에 사용법 설명을 둔다. 내용은 지시문 복사 → 쓰는 AI(무료·휴대폰 OK)에 붙여넣기 → 평소 말투로 말하기 → 받은 코드를 붙여넣기.
- AI가 정한 칼로리·탄단지는 본인에게만 보이는 '내 값'으로 계속 쓰게 하되, 중복으로 쌓이지 않게 한다.
- AI는 마이로그에 등록된 걸 모른다. 알게 할 수 있는지 물었다.
- (작업 후 답변) Firebase Blaze와 다른 서비스 비교·비용 컨설팅.

## 결정
- 붙여넣은 답은 지금의 AI 검토함 초안 형식(식사 items, 운동 exercises, 몸 수치)으로 바꿔서 같은 검토함에 넣는다. 확정은 사람이 한다.
  - 로그인과 이용 승인이 필요하다(검토함과 같은 조건).
- 중복 방지는 AI 프롬프트에 기대지 않고 마이로그가 보장한다.
  - 같은 내용을 두 번 붙여넣어도 초안은 하나다(내용 지문 = 문서 ID, 트랜잭션으로 있으면 건너뜀).
  - AI로 확정한 음식은 이름+단위가 같으면 하나로 묶고 가장 최근 값을 쓴다. 기록이 오래돼도 '내 값'으로 남는다.
  - 프롬프트에도 "전에 쓴 이름·단위·값을 그대로" 규칙을 넣어 보조한다.
- AI가 내 목록을 알게 하는 방법: '내 음식·운동 목록 복사' 버튼으로 내 음식(값 포함)과 자주 하는 운동·머신을 글로 복사해 대화에 한 번 붙인다. 서버 없이 휴대폰에서도 된다.

## 바꾼 것
- 새 `app/ai-paste.js`
  - `AI_PROMPT`: 지시문. 형식 예시, 추정 범위 규칙, 모르면 null, 세트 풀어 쓰기, 머신은 말한 이름 그대로, 같은 음식은 같은 이름·값.
  - `extractCode`: 코드 블록, 앞뒤 설명, 둥근 따옴표, 끝 쉼표를 받아 준다.
  - `parsePaste`: 식사·운동·몸 초안을 만든다.
    - 한글 키·별칭을 받는다(kcal/calories/칼로리 등).
    - '3세트' 숫자를 세트로 풀어 쓴다. lb/kg를 구분한다.
    - 종목은 도감에서 찾고, 머신은 일반 머신·제조사 모델 이름(별칭 포함)으로 맞춘다. 맞추면 근육 부하를 자동으로 넣는다.
    - 유산소는 분·km로 받는다.
    - `cleanMeal`·`cleanWorkout`·`cleanBody`로 검증하고, 틀리면 'n번째 기록(식사): 이유'로 알려 준다.
  - `matchMachine`
  - `aiInputHTML`, `aiPreviewHTML`: 사용법, 지시문 복사·보기, 내 목록 복사, 붙여넣기 칸, 클립보드 붙여넣기, 실시간 미리보기, 검토함에 넣기, 검토함 열기(대기 건수).
  - `aiContextText`: 내 목록 복사용 글.
- `app/ai-drafts.js`: `addPastedDrafts`. ID는 `p-` + 지문이고 rules의 draftShape를 그대로 지킨다. 규칙 변경은 없다.
- `app/app.js`
  - 'ai-input' 모달과 버튼 처리(지시문 복사, 내 목록 복사, 클립보드, 지우기, 넣기). 넣은 뒤 검토함으로 이동하고 '검토함에 n건 넣었어요' 토스트를 띄운다.
  - 추가 메뉴 맨 위에 'AI로 입력'.
  - 공유받기: URL `?text=`(PWA 공유 대상), `mylogue-share` 이벤트, `mylogue.pendingShare`.
- `app/timeline-view.js`: '빠른 기록' 제목을 지우고, 맨 위에 'AI로 입력' 버튼(테두리 그라데이션 흐름, 빛 번짐, 반짝이는 아이콘)을 넣었다. 움직임 줄이기 설정이면 애니메이션을 끈다.
- `app/quick-entry.js`: AI로 확정한 음식(`source` ai-*)은 최근 20개 밖이어도 후보에 남고 '내 값'으로 표시한다.
- `app/manifest.webmanifest`: `share_target`(GET title/text/url). Android Chrome에 설치한 PWA에서 공유받기가 된다.
- Android
  - `AndroidManifest.xml`: SEND text/plain intent-filter.
  - `MainActivity.java`: `deliverShare`. 공유받은 글을 JSON 따옴표로 감싸 웹으로 넘긴다. 처음 켤 때는 1.5초 뒤, 켜져 있을 때는 바로 넘긴다.
- `app/aurora-theme.css`: AI 버튼과 AI 입력 창 스타일. 입력 칸은 16px, 일반 글꼴.
- 버전 3.16.0(versionCode 30), sw CACHE `mylogue-shell-v3-16-0-ai-input`. FILES와 build.mjs에 ai-paste.js를 넣었다.

## 1단계 실제 예시(대표님 질문 답)
- 사용자가 ChatGPT에 지시문을 한 번 붙여넣는다.
- 그다음 이렇게 말한다: "점심 제육덮밥, 콜라 한 캔. 저녁 하체. 45도 레그프레스 100키로 12개 3세트. 아침 체중 72.4"
- AI 답의 형태는 `tests/v3160.test.js`의 `answer`에 있다.
- 붙여넣으면 미리보기가 '✓ 3개 기록을 찾았어요'를 보여 준다.
  - 식사: 12:30 제육덮밥(850kcal, 추정 700~1000), 코카콜라
  - 운동: 하체 · 레그 프레스 → 45° 레그 프레스(원판식) 연결, 3세트, 근육 자동
  - 몸: 72.4kg
- '검토함에 넣기'를 누르면 검토함에 3건이 생긴다. 확정해야 기록이 된다.
