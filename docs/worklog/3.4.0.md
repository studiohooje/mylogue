# 작업로그 — Mylogue Beta 3.4.0 (2026-11-20)

## 요청 (대표님)
- 지인 피드백(운동 기록 방식 다양화 등) 반영. 처음 가입할 때 문답으로 성향을 파악해 입력 방식 기본값을 정하고, 개인 설정에서 언제든 바꾸게, 바꾸는 방법도 명확히 안내. 불특정 다수의 입맛에 맞게 다른 선택지도.
- 준비(리서치·목업) 후 실제 작업: `docs/plans/2026-11-20_맞춤시작_준비.md`, `mockups/onboarding-modes/index.html`.

## 바꾼 것
- 새 파일 `app/prefs.js`: `db.settings.preferences`(tracks, level, workoutMode, mealMode, place, halo, restSec, onboarded, hintShown). 기록 데이터 형식은 그대로.
  - 시작 문답 5문항(모두 건너뛰기 가능), 결과 화면에 바꾸는 경로 안내.
  - 설정 '나의 기록 방식'(기록할 것, 운동 기록 방식, 식단 입력 방식, 운동 설명, 기본 휴식 시간, 헤일로 보이기, 문답 다시 하기).
  - 운동·식단 화면 위 '기록 방식 ▾' 칩 → 설정의 해당 칸으로 이동.
  - 운동 '다 끝나고 한 번에'(종목·무게·단위·횟수·세트 수, 지난 운동 불러오기) → 기존 cleanWorkout 형식, 세트 수만큼 완료 세트 생성, 종목 이름으로 카탈로그 자동 연결.
  - 식단 '끼니만 간단히'(끼니·이름·대략 열량·날짜·시각) → cleanMeal, 단위 '끼', note '대략 열량(간단히 입력)'.
  - '계획→안내'(운동), '사진 먼저'(식단)는 선택은 되지만 '곧 제공' 표시, 실제로는 세트마다/정확히로 동작.
- `app/app.js`: 첫 실행(기록 없음·문답 전)에 문답 자동 표시, 기존 사용자는 홈에 '나에게 맞추기' 카드. 닫으면 건너뛰기로 처리(다시 묻지 않음). 하단 탭·빠른 기록 시트를 기록할 것에 맞춤. 새 모달 3종, 라우팅(운동/식단 버튼이 방식에 맞는 화면으로). 세트 저장 시 기본 휴식 타이머 자동 시작. 세 번째 기록 뒤 한 번만 '바꾸는 방법' 안내.
- `app/halo.js`: 고른 종류만 채우면 완성, 세 점은 고른 것만, 아이콘(줄기·상단 호) 완성 표시는 세 종류 모두 고른 경우만. 헤일로 숨기기.
- `app/timeline-view.js`: 홈 빠른 기록 버튼과 헤일로 문구를 기록할 것에 맞춤.
- `app/aurora-theme.css`: 문답·설정·칩·새 입력 화면 스타일. 입력 글자 16px.
- `app/build.mjs`, `app/sw.js`: prefs.js 추가. 휴식 타이머 interval에 `unref`(시험 환경에서 프로세스가 끝나지 않던 문제 해결, 브라우저 영향 없음).
- 버전 3.4.0 / versionCode 17, 캐시 `mylogue-shell-v3-4-0-prefs`.
