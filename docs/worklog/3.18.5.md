# 작업로그 — Mylogue Beta 3.18.5 (2026-11-21)

## 요청(대표님)
- GPT 헤더 목업(`GPT Source/header-mockups/`) 중 3번(헤일로 고리형)으로 한다. '오늘 2/3 기록' 자리에는 영문 'mylogue'를 넣는다.
- 2번처럼 그라데이션을 넣되, 마이로그·mylogue 둘 다 같게 할지는 Claude가 제안한다. 정렬(가운데/왼쪽)도 제안한다.

## 제안·결정
- 그라데이션은 주인공인 '마이로그'에만 은은하게 넣는다(흰색 → 민트 → 라벤더). 'mylogue'는 작은 글씨라 그라데이션을 넣으면 뭉개지므로 민트 단색, 넓은 자간 소문자로 한다. 큰 글씨의 민트를 받아 한 세트로 보이게 한다.
- 정렬은 왼쪽을 유지한다. 오른쪽 종·앱 설치·프로필과 부딪히지 않고, 로고 → 홈 동작이 익숙한 자리다.
- 3번의 고리는 실제로 동작한다: 오늘 기록한 종류 수 / 기록할 종류 수(설정의 tracks, 예정 기록 제외).

## 바꾼 것
- `app/app.js`
  - 헤더 brand를 `brandMarkHTML(haloProgress())`(로고 + 둘레 고리 SVG, 종류 수만큼 칸을 나누고 채운 칸은 그라데이션) + `.brand-title` 마이로그 + `.brand-en` mylogue로 바꿨다.
  - aria-label·title에는 '오늘 n/m 기록'만 넣는다. 헤더에는 버전·베타 표기를 두지 않는다(대표님 지시, 마우스 오버 포함).
  - 설정 맨 아래에 '마이로그 베타 x.y.z' 버전 표기를 옮겼다(앱 화면 버전 표기 유지).
  - halo.js의 `dayRecords`를 가져온다.
- `app/aurora-theme.css`: brand-mark 46px(휴대폰 40px), 고리 선 3px, 다 채우면 은은한 빛, 제목 그라데이션, 영문 스타일.
