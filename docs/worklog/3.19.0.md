# 작업로그 — Mylogue Beta 3.19.0 (2026-11-21)

## 요청(대표님)
- 탄단지 목표를 체중 대비(체중 × n g)로 정하는 자유도를 준다.
  - 단백질만 체중 대비로 하고 나머지를 탄수·지방이 비율로 나눠 가진다.
  - 탄수만 체중 대비로 할 수도 있다.
  - 탄수·단백질 둘 다 체중 대비로 하고 나머지를 지방이 채울 수도 있다.
  - 단순 비율 방식도 그대로 둔다.
  - 체중은 당일 또는 가장 최근 측정을 쓴다.
- 고정량(예: 단백질 딱 200g)도 정할 수 있게 한다.
- 식단 화면의 '목표 탄단지 열량 비율 · 탄수 40%…' 줄이 글자 칸에 붙어 있고 잘 안 보인다.
  - 탄단지 고유 색으로 예쁘게 보여 준다.
  - 오른쪽 '수정'에서 목표 칼로리와 방식을 바꾼다.
  - '제안해 주세요'는 처음 로그인 때처럼 제안한다.

## 바꾼 것
- 새 `app/macro-plan.js`
  - 규칙 `{mode:'ratio'|'perKg'|'grams'|'rest', value}`를 영양소마다 둔다.
  - `computeMacroPlan(plan, weight)`: 정한 영양소의 칼로리를 빼고, 남은 칼로리를 '나머지' 영양소들이 value 비율로 나눈다. 결과는 g·kcal·%·합계다.
  - 오류: 체중 기록 없음, 정한 값만으로 칼로리 초과, 모두 비율일 때 합계 100% 아님, 나머지가 없어 칼로리와 차이 남.
  - `applyMacroPlan`은 결과를 기존 형식(calorieGoal·carbsGoal·proteinGoal·fatGoal·…PctGoal)으로 저장하고 `goalMode:'plan'`, `macroPlan{…, weightUsed}`를 남긴다. 다른 화면은 그대로 동작한다.
  - `refreshMacroGoals`: 체중 대비 규칙이 있고 최근 체중이 바뀌었을 때만 다시 계산한다.
  - `planFromSettings`: 저장된 방식(plan, ratio, g)에서 수정 창의 시작값을 만든다. 마법사로 바꾼 뒤(goalMode ratio)에는 옛 계획을 쓰지 않는다.
  - `PRESETS` 4개, `macroPlanCardHTML`(목표 카드), `macroPlanFormHTML`(수정 창).
- `app/food-view.js`: 옛 비율 한 줄을 목표 카드(최근 체중 = 체중계 기록 우선)로 바꿨다.
- `app/app.js`
  - 'macro-plan' 모달.
  - 방식 버튼(방식을 바꾸면 그 방식의 기본값을 채움), 빠른 선택.
  - 값 입력 시 합계·결과만 다시 그린다(입력 커서 유지).
  - 저장.
  - 체중 저장 뒤와 시작할 때 `refreshGoalsByWeight()`.
- `app/aurora-theme.css`: 카드와 수정 창 스타일(탄수 #f0d466 · 단백질 #6fd6a3 · 지방 #ff7b93).
- `sw.js`·`build.mjs`에 macro-plan.js를 넣었다.
