## 바꾼 것
- 새 파일 `app/halo.js`
  - `dayRecords(db,date)`: 몸(createdAt)·식사(mealGroupId 묶음의 가장 이른 loggedAt)·운동(createdAt) 시각. 기록 날짜와 다른 날 입력된 경우 시각은 null(종류만 셈).
  - `rhythmFor(db,date)`: 지난 7일 중 기록 있는 날 3일 미만이면 학습 중(06~24시, 모두 리듬 안). 아니면 첫/마지막 기록 평균 ±1h, 최소 폭 8h.
  - `inRhythm`: 같은 종류 지난 기록 ±1.5h. `haloMessage`: 습관만 말하고 판단 표현 없음.
  - `findZone`: 글자 줄 영역(+12px) 피한 오른쪽 아래 최대 칸. `haloSVG`: 순수 함수, 원호·빛 구슬·양 끝 채움·세 점·완성 시 줄기와 상단 호, 뒤에 옅은 어둠(베일).
  - `mountHalo`: 실측 → 칸 반지름 36 미만이면 카드 아래 공간 확보 → 그림 → **겹침 검사 후 0이 아니면 지움**. 글꼴 로드(`document.fonts`)·창 크기·글자 영역 크기 변화 시 다시 그림.
- `app/timeline-view.js`: 히어로 부제를 상태 문구(`.hero-msg`)로, `<svg class="halo-art">` 추가.
- `app/app.js`: 홈 렌더 후 `mountHalo` 호출(오류 시 콘솔만).
- `app/aurora-theme.css`: 헤일로 레이어·문구 스타일.
- `app/build.mjs`, `app/sw.js`: `halo.js` 추가. 캐시 `mylogue-shell-v3-3-0-halo`.
- `app/halo-qa.mjs`: 화면 검사 스크립트(가상 기록 7일 + 오늘 4가지 × 5개 폭 × 보통/큰 글자, 겹침·넘침 0 아니면 실패 코드).
- 버전 3.3.0 / versionCode 16.
