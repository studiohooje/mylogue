## 4. 이름 후보 (약어 MCL 유지)

| 후보 | 장점 | 주의 |
|---|---|---|
| **MyConditionLog(s)** | 한국어 '컨디션'은 몸 상태·식단·운동을 모두 아우르는 일상어 | 영어권 앱스토어에서 'condition'은 질병·증상 추적 앱으로 읽힘 |
| MyChangeLog | '몸의 변화 기록'이라는 제품 메시지와 정확히 맞음 | 개발 용어 changelog와 같아 검색·상표 구별이 약함 |
| MyCoreLog | 코어(몸통)·핵심, 운동 앱 느낌 | 의미가 넓어 식단이 덜 드러남 |
| MyCareLog | 친근함 | 의료·돌봄 앱처럼 보여 건강 효과 표현 심사 부담 |
| MyCycleLog | 하루 루틴의 순환 | 생리주기 앱으로 오해되기 쉬움 → 비추천 |

복수형 `Logs`보다 단수 `Log`가 영어로 자연스럽다(MyConditionLog). 참고로 MCL은 운동 분야에서 무릎 '내측측부인대(Medial Collateral Ligament)' 약어로도 쓰인다. 확정 전 특허청 KIPRIS 상표 검색 권장.

## 5. 입력 방식 개선 5안 (요약)

공통 선행 작업: 식사 입력 3경로를 하나로 합치고, 몸 기록을 '체중 한 칸 + 펼치기'로 바꾼다.

1. **한 줄 입력** — 검색창 하나에 `닭가슴살 200 현미밥 210`, `레그프레스 40x15 60x12`, `체중 72.4`처럼 치면 기기 안의 규칙 파서가 기존 음식·종목과 맞춰 미리보기 칩을 만들고 Enter로 저장. AI 없음.
2. **'평소처럼' 예측 카드** — 시간대·요일·최근 기록으로 지금 할 법한 기록 1~3장을 홈에 띄움("12:30 · 현미밥 210g + 닭가슴살 200g → 그대로 기록 / 양만 수정"). 반복 식사·같은 요일 운동이 한 번 탭.
3. **운동 중 모드** — 전체 화면, 큰 '세트 완료' 버튼, 키보드 없는 ±스테퍼(2.5kg·1회), 자동 휴식 타이머, 화면 꺼짐 방지, 지난번 순서대로 다음 종목 제안. 한 손 조작.
4. **먼저 찍고 나중에 정리** — 카메라 버튼 하나로 사진+시각만 '미정리 카드'로 저장 → 저녁에 정리 대기열에서 사람이 고르거나 AI에게 넘김. 폰에서도 AI 경로를 만들 수 있는 다리.
5. **음성 한 마디** — 마이크 버튼으로 "점심 닭가슴살 200그램 현미밥 한 공기"를 말하면 1안의 파서로 미리보기 → 확인. 아이폰 사파리는 브라우저 음성 인식, Android 앱은 음성 인식 플러그인 필요.
