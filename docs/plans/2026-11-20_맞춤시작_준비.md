# 작업 준비 — 맞춤 시작 문답 · 기록 방식 선택 · 운동 안내 모드 · 헬스장 검색 · 사업계획서 분리

> 2026-11-20. 대표님 지시: "불특정 다수의 입맛에 맞게, 처음 문답으로 성향을 파악해 입력 방식 기본값을 정하고 언제든 설정에서 바꾸게. 리서치·목업 등 준비를 전부 끝낸 뒤 실제 작업."
> 출발점: 지인(정부사업 관련) 피드백 — 컨셉·헤일로 호평, 자료 노선(IR vs 제품설명서) 불명확, 근거 최신화, 수익 모델 가닥 필요, 운동 기록 방식 다양화(세트마다 / 계획→알림 / 끝나고), 헬스장 지도 연동, '과금 = 트레이너 고용'.
> 목업: `mockups/onboarding-modes/index.html` (앱에 적용 전)

## 1. 시작 문답 (5문항, 모두 건너뛰기 가능, 30초)

| # | 질문 | 선택지 | 정해지는 기본값 |
|---|---|---|---|
| 1 | 무엇을 기록하고 싶나요? (복수) | 운동 · 식단 · 몸 | 하단 탭·홈 구성, **헤일로 완성 기준**(고른 종류만 채우면 완성) |
| 2 | 운동은 얼마나 해 봤어요? | 이제 시작 / 1년 안 됨 / 꾸준히 | 운동 설명·사용 근육·자세 안내 표시 정도, 추천 루틴 노출 |
| 3 | 운동할 때 기록은? | 세트마다 / 계획→안내 / 끝나고 한 번에 | **운동 기록 방식** |
| 4 | 식단은 어떻게? | 정확히 / 끼니만 간단히 / 사진 먼저 / 안 함 | 식사 입력 첫 화면, 식단 탭 표시 |
| 5 | 어디서 운동해요? | 헬스장(검색) / 집 / 여러 곳 | 장소 목록, 홈트 우선 노출 |

- 건너뛰면: 운동·식단·몸 전부 / 1년 안 됨 / 세트마다 / 정확히 / 이름만 입력(현재와 동일).
- 이미 기록이 있는 기존 사용자에게는 강제하지 않고 홈에 한 번만 "나에게 맞추기" 카드.

## 2. 바꾸는 방법 안내 (세 군데)

1. 문답 결과 화면에 경로 표시: **설정 › 나의 기록 방식 › 항목 누르기**.
2. 해당 화면 바로가기 칩: 운동 화면 위 '기록 방식 ▾', 식단 화면 위 '입력 방식 ▾'.
3. 첫 일주일, 세 번째 기록 뒤 한 번만 말풍선 "방식이 불편하면 여기서 바꿔요".
- 설정에 "시작 문답 다시 하기" 버튼.

## 3. 문답 외 설정 전용 선택지 (불특정 다수 대응)

| 항목 | 선택지 | 대상 |
|---|---|---|
| 안내 방식 | 소리 / 진동(Android) / 음성 / 화면만 | 폰 안 보는 사람, 이어폰 사용자 |
| 기본 휴식 시간 | 30초~3분 | 근비대·근력·서킷 |
| 템포(메트로놈) | 끔 / 2-0-2 등 | 반복 속도까지 맞추는 사람 |
| 화면 꺼짐 방지 | 운동 중에만 / 끔 | 폰 거치 |
| 단위 | kg / lb | 해외 머신 |
| 하루 시작 시각 | 00~06시 | 야간·교대 근무(헤일로 범위) |
| 화면 밀도 | 간단히 / 자세히 | 숫자 부담 vs 전부 보기 |
| 헤일로 표시 | 켬 / 끔 | 그래픽이 부담스러운 사람 |
| 몸 기록 범위 | 체중만 / 체성분 / 사진 | 인바디 없는 사람 |

## 4. 운동 기록 3가지 방식

- **세트마다**(현재 방식): 세트별 ✓, 기존 휴식 타이머.
- **계획 → 안내**(신규): 종목·세트·횟수·휴식을 미리 정함 → "휴식 10초 남았습니다 / 3·2·1 / 2세트 시작" 소리·음성 안내, 화면 켜 둠, 무게 바꿀 때만 수정. 지난 기록·루틴으로 계획 자동 채움.
- **끝나고 한 번에**(신규): "45kg × 10회 × 3세트" 한 줄 입력, 지난번 불러와 고치기.
- 세 방식 모두 같은 운동 기록 형식으로 저장(데이터 계약 변경 없음, 완료 세트만 통계 반영 유지).

## 5. 리서치 결과

### 5-1. 운동 안내 모드의 기술 조건
- 화면 꺼짐 방지(Screen Wake Lock): Android Chrome 84(2020)부터, iOS Safari 16.4부터, **iPhone 홈 화면 앱은 iOS 18.4에서 버그 수정 후** 지원. 탭을 벗어나면 자동 해제. ([web.dev](https://web.dev/blog/screen-wake-lock-supported-in-all-browsers), [caniuse](https://caniuse.com/wake-lock), [WebKit 버그](https://bugs.webkit.org/show_bug.cgi?id=254545))
- iPhone 홈 화면 앱: 알림(Web Push)은 16.4부터 되지만 백그라운드 작업은 약함 → **iPhone은 '화면 켜 두고 진행'이 기본**. ([firt.dev](https://firt.dev/notes/pwa-ios/), [MagicBell](https://www.magicbell.com/blog/pwa-ios-limitations-safari-support-complete-guide))
- 폰 잠금 시 웹 타이머는 늦거나 멈출 수 있음 → **Android APK는 휴식 종료 알림을 미리 예약**(Capacitor 로컬 알림 플러그인 추가 필요, 실기기 시험 필요).
- 진동 API는 iPhone 미지원 → iPhone은 소리·음성. 소리는 첫 터치 뒤에만 재생 가능.
- 미확인: iOS에서 화면 켠 상태 음성 합성(3·2·1)의 끊김 여부 → 실기기 시험 항목.

### 5-2. 헬스장 장소 검색
- 카카오 지도 웹 SDK의 장소 검색(키워드 검색)으로 브라우저에서 "헬스플러스 안산" → 주소 포함 목록. 앱 키 + 허용 도메인 등록 필요.
- 무료 사용량은 개발자 계정의 **첫 번째 지도 앱**에만 제공, 초과분만 과금. **2026-07-21 이후 활성화 앱에 새 정책** 적용 → 등록 전 공식 쿼터표 확인. ([카카오 데브톡 공지](https://devtalk.kakao.com/t/api-notice-on-new-kakao-map-api-features-and-free-quota-policy/150222), [쿼터 문서](https://developers.kakao.com/docs/ko/getting-started/quota), [카카오 발표](https://www.kakaocorp.com/page/detail/8159?lang=ENG))
- 저장: 장소 ID·이름·주소만. 사용자 위치는 저장하지 않음. APK(Capacitor) 안 도메인 허용은 시험 필요.
- 필요한 대표님 결정: 카카오 개발자 앱 등록(계정·약관 동의는 대표님이 직접).

## 6. 사업계획서 분리안

| 자료 | 독자 | 구성 |
|---|---|---|
| **제품 소개서**(현 슬라이드 개편) | 테스터·파트너·지인 | 한 문장 → 헤일로(대표 이미지) → 맞춤 시작 → 기록 방식 3가지 → 화면 → 설치 → 로드맵 |
| **사업계획서 PSST**(신규) | 정부지원사업·투자 | 문제인식(2025 생활체육조사·2026 지속 기록 근거) → 실현가능성(3.x 실제 앱·검증 계획) → 성장전략(무료 기록 → 'AI 트레이너' 구독 → 트레이너 B2B → 커뮤니티·제휴, 가격 비교 Hevy·Strong·플랜핏) → 팀구성(대표 + 채용 예정 직무). 공고 원문 양식(hwp/docx)이 나오면 그 칸에 옮김 |

수익 모델 가닥(가설): 무료 = 기록·헤일로·사용 근육·기본 자세(미끼), 유료 = AI 코치(부하·회복 계산 추천), 사진·말 입력, 안내 모드 고급 기능 / 장기 = 랭킹·함께하기, 트레이너용 회원 관리, 식단 제휴. 가격은 실측 후, 비교 기준은 위 5-3.

## 7. 실제 작업 순서 (대표님 승인 후)

| 순서 | 작업 | 버전 | 비고 |
|---|---|---|---|
| 1 | 설정에 `preferences` 추가 + 시작 문답 + '나의 기록 방식' 화면 + 바로가기 칩 | 3.4.0 | 데이터 계약 변경 없음(설정만) |
| 2 | 헤일로 완성 기준을 '기록할 것' 선택에 맞춤 | 3.4.0 | halo.js |
| 3 | 운동 '끝나고 한 번에' 입력 | 3.4.0 | 기존 저장 형식 재사용 |
| 4 | 운동 '계획 → 안내' 모드(화면 켜 둠, 소리·음성) | 3.5.0 | 실기기 시험 필수 |
| 5 | Android 휴식 알림 예약(로컬 알림 플러그인) | 3.5.x | APK 전용, 권한 요청 |
| 6 | 헬스장 장소 검색 | 3.6.0 | 카카오 앱 등록 후 |
| 7 | 제품 소개서 개편 + PSST 사업계획서 | 문서 | 코드와 별개로 병행 가능 |

각 단계: 5개 폭 화면 확인 → 시험 → 웹·APK 함께 배포 → 작업로그·패치노트.

## 8. 대표님 확인이 필요한 것
1. 문답 5문항 구성과 건너뛸 때 기본값 그대로 갈지.
2. 운동 3가지 방식 중 이번(3.4.0)에 '끝나고 한 번에'까지, '계획→안내'는 다음(3.5.0)으로 나눌지.
3. 카카오 개발자 앱 등록(헬스장 검색) 진행 여부 — 계정·약관은 대표님이 직접.
4. 지인 테스터: 웹에서 로그인·승인 신청 → 관리자 화면에서 승인.
5. 사업계획서 두 갈래로 분리 진행 여부.
