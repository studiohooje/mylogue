## 0. 결론 먼저

1. **연구 근거는 탄탄하다**(관찰 연구 중심). 가장 쓸 만한 건 ① 식사 기록을 많이 한 사람이 기록하지 않은 사람보다 약 2배 감량(Kaiser 등 2008), ② 자기기록과 체중 감량의 일관된 연관(Burke 2011 체계적 고찰), ③ 성공 집단은 하루 2~3번 꾸준히 기록(Harvey 2019), ④ 매일 체중 재기 개입의 효과(Steinberg 2013). 단 **"마이로그를 쓰면 2배"라고 쓰면 안 된다.** 연구는 '기록'의 효과이고, 대부분 인과가 아닌 연관이다.
2. **실명 발언은 생각보다 확인이 안 된다.** 크리스 범스테드는 "기록하라"는 직접 발언을 원문으로 찾지 못했다(요약 기사만 있음). 레인 노턴(Layne Norton)·제임스 클리어(James Clear)·연구 책임자 잭 홀리스(Jack Hollis)는 출처가 확인된다. 한국 유튜버·의사의 "기록하라" 발언은 이번 조사에서 **원문 확인 0건**.
3. **실명 사용은 앱 홍보·영업 문구에서는 하지 않는 것이 안전하다.** 한국은 유명인 성명·초상을 허락 없이 영업에 쓰면 부정경쟁방지법(인적 식별표지 무단사용)에 걸릴 수 있고, 추천처럼 보이면 표시광고법 문제도 생긴다. **연구자 이름과 논문 인용**(출처 표기)은 상대적으로 안전하다.
4. **문구 방향**: "기록하면 효과가 있다는 건 연구가 말해요. 기록을 쉽게 만드는 건 마이로그가 할게요." — 효과는 연구에 맡기고, 마이로그는 **쉬움**만 약속한다. 압박·죄책감·숫자 목표 강요 없음.
5. **기록 의지가 없는 사람에게는 근거보다 '첫 1번 누름'이 중요하다.** 첫 화면은 설득 문구보다 "체중 하나만 / 방금 먹은 것 하나만"으로 시작.

| **표시광고법** + 공정위 **추천·보증 심사지침** | 추천·보증 광고는 추천자가 실제 사용·경험했어야 하고, 대가 관계는 공개해야 함. 2026년 개정으로 AI 가상인물 추천도 표시 의무 [2차: [법률신문](https://www.lawtimes.co.kr/news/articleView.html?idxno=222498), [디지털데일리](https://www.ddaily.co.kr/page/view/2026040811563569528)] | "○○도 기록하라고 했어요" + 마이로그 홍보가 붙으면 **○○가 마이로그를 추천한 것처럼** 오인될 수 있음 → 부당 표시·광고 위험. 효과를 과장해도 부당광고 |
| **의료법 제56조**(의료광고) | 의료광고 주체는 의료인·의료기관. 치료 경험담·과장 광고 금지 [2차: [로톡](https://www.lawtalk.co.kr/posts/96705)] | 마이로그는 의료기관이 아니므로 의료광고 자체를 할 수 없음 → **"치료·처방·질환 개선"** 표현 금지. 의사 이름·직함을 앞세워 효과를 말하는 것도 피함 |
| **의료기기 vs 웰니스 판단기준**(식약처, 2026-02 개정) | 질병 진단·치료 목적이면 의료기기, 일상 건강관리 목적이면 웰니스 [2차: [식약처](https://www.mfds.go.kr/brd/m_1059/view.do?seq=15229), [메디칼타임즈](https://medicaltimes.com/Main/News/NewsView.html?ID=1098191)] | "비만 치료", "당뇨 관리" 같은 **질병 표현을 쓰면 의료기기로 볼 여지**. 문구는 "체중·식단·운동 기록", "건강관리"로 한정 |

### 3-2. 판단: 할 수 있는 것 / 위험한 것 / 하면 안 되는 것

**할 수 있는 것** (위험 낮음)
- **연구 인용**: "미국 Kaiser Permanente 연구(2008)에서…" + 학술지명·연도. 연구자 이름(Hollis)도 서지 표기로는 무방 [판단: 연구자는 '널리 알려지고 경제적 가치 있는 표지'에 해당할 가능성이 낮고, 학술 인용은 공정한 관행].
- **익명 일반화**: "트레이너·영양사들이 자주 하는 말이 있어요: 먼저 3일만 평소대로 적어 보세요." — 특정인을 식별하지 않음.
- **공공기관·학회 권고 인용**(원문 확인 후): 예) 학회 진료지침의 자기 모니터링 권고.
- **본인 허락을 받은 인용**: 트레이너·코치·영양사에게 서면 동의(사용 범위·기간·매체·대가 여부)를 받고 쓰기. 마이로그 코치 모드의 실제 코치가 1순위 후보.
- **앱 안 '읽을거리'에서의 정확한 인용**: 교육 목적의 짧은 인용 + 출처 링크, 홍보와 분리된 화면 [판단: 그래도 위험이 0은 아님].

**위험한 것** (하려면 변호사 확인)
- 앱 안 화면이라도 **"크리스 범스테드도 기록을 강조했어요"** 같은 유명인 이름 문구. 앱은 결국 영업 수단이라 (타)목의 '영업을 위한 사용'으로 다툴 여지가 있고, 발언 원문이 확인되지 않아 **사실과 다른 표시**가 될 위험까지 겹침.
- 소개서·사업계획서에 유명인 발언 인용. 투자자 대상 자료도 외부 배포물이면 같은 문제.
- 의사·영양사 '직함'을 앞세운 효과 문구("의사들도 인정한 기록 앱").

**하면 안 되는 것**
- 스토어 설명·광고·SNS 홍보에 유명인 **이름·사진·영상·목소리**를 허락 없이 사용.
- 유명인이 마이로그를 쓰거나 추천한 것처럼 보이는 표현.
- "마이로그를 쓰면 2배 빠진다", "살이 빠지는 앱" 같은 **효과 보장** 표현.
- "비만 치료·질환 개선·처방" 등 의료·질병 표현.
- 확인 안 된 발언·잘못 알려진 명언(드러커·사인펠드) 사용.

### 3-3. "앱 화면 속 문구"와 "광고 문구"의 차이 [판단]

| | 앱 화면 속 팁(로그인 후) | 광고·스토어·소개서 |
|---|---|---|
| 목적 | 사용 중인 사람의 이해·동기 | 새 사용자 유치(영업) |
| 표시광고법 | 상품 '표시'로 볼 여지는 있으나 위험 낮음 | 광고 그 자체 |
| 퍼블리시티 | 영업 관련성 낮지만 0은 아님 | 영업 사용이 뚜렷 |
| 권장 | 연구 인용·익명 일반화·허락받은 인용 | **연구 인용만**, 효과는 '연구 결과'로 한정, 마이로그는 '쉬움'만 약속 |

## 4. 마이로그 적용안

### 4-1. 톤 원칙

1. **효과는 연구가, 쉬움은 마이로그가.** 마이로그가 감량을 약속하지 않는다.
2. **압박 없음.** "오늘 아직 안 했어요", "연속 기록이 끊겼어요" 금지. 빈 날은 언급하지 않는다(대표님 결정: 식단·운동 리마인드 없음).
3. **한 화면에 근거 하나.** 숫자를 늘어놓지 않는다.
4. **출처를 누를 수 있게.** 문구 옆 작은 'ⓘ 연구' → 서지·링크. 신뢰는 출처에서 나온다.
5. **해요체, 짧게.** 칭찬은 행동에(“남겼어요”), 몸에 대한 평가는 하지 않음(“날씬해졌어요” 금지).
6. **완벽 대신 '대충도 기록'.** 간단한 기록도 괜찮다는 연구와 맞춘다.

### 4-2. 위치별 문구 예시

**① 온보딩(처음 한 번)** — 설득은 한 장만, 바로 첫 기록으로
1. "기록하는 사람이 더 잘 관리한다는 연구가 많아요. 기록을 쉽게 만드는 건 마이로그가 할게요."
2. "먹은 걸 적은 사람이 더 많이 감량했다는 연구도 있어요. ⓘ"
3. "완벽하지 않아도 돼요. 대충 남겨도 기록이에요."
4. "체중 하나만 남겨 볼까요? 5초면 돼요."
5. "다른 앱처럼 매일 알림으로 재촉하지 않아요. 생각날 때 열어 주세요."
6. "처음 3일은 평소대로만 적어 보세요. 내가 뭘 먹는지 보이기 시작해요." (트레이너들이 흔히 권하는 방법 — 익명 일반화)

**② 빈 화면(기록이 없을 때)** — 탓하지 않고 가장 작은 행동 하나
1. "방금 먹은 것 하나만 남겨 볼까요?"
2. "어제 먹은 게 기억나면 그것도 좋아요."
3. "사진 대신 이름만 적어도 충분해요."
4. "아직 비어 있어요. 체중부터 시작해도 돼요."
5. "기억나는 것만 남겨도 기록이에요."

**③ 기록 직후** — 행동 칭찬, 가끔(매번이 아니라 10번에 1번 정도) 근거 한 줄
1. "남겼어요."
2. "이번 주 3일째 남겼어요." (연속이 아니라 '이번 주 n일')
3. "자주 남기는 사람이 더 잘 관리한다는 연구가 있어요. ⓘ" (가끔만)
4. "어제 그대로 1번에 끝났어요."
5. "대충 남긴 끼니는 나중에 고쳐도 돼요."
6. "체중 기록 4주째예요. 흐름이 보이기 시작해요."
7. (첫 기록) "첫 기록이에요. 시작이 제일 어려워요."

**④ 리마인드(이미 있는 체중·인바디만)** — 정보형, 재촉 금지
1. "체중을 마지막으로 남긴 지 3일 됐어요. 생각나면 한 번 재 볼까요?"
2. "인바디 잰 지 2주 됐어요. 다음에 재면 사진 한 장이면 돼요."
3. "체중을 자주 재는 사람이 유지도 잘한다는 연구가 있어요. ⓘ" (설정 화면 설명에만)

**⑤ 소개서·사업계획서**
1. "기록이 건강관리에 도움이 된다는 건 오래된 연구 결과입니다. 문제는 기록이 귀찮다는 것. 마이로그는 그 귀찮음을 없앱니다."
2. "기록을 그만두는 가장 흔한 이유는 '노력이 너무 든다'입니다(CHI 2015). 마이로그는 한 번 누름 기록을 목표로 합니다."
3. "식사 기록을 꾸준히 한 사람이 약 2배 감량했다는 연구(미국, 2008)가 있습니다. 마이로그는 효과를 약속하지 않습니다. 기록을 쉽게 만들 뿐입니다."
4. 숫자는 늘 연구명·연도·'관찰 연구' 표시와 함께.

**⑥ 스토어 문구**(가장 보수적으로)
1. "체중·식단·운동을 하루로 잇는 가장 쉬운 기록"
2. "기록하고 싶어지는 기록 앱"
3. "어제 그대로, 한 번에. 대충도 기록이 돼요."
4. "알림으로 재촉하지 않아요. 생각날 때 열면 돼요."
5. (부제 정도) "기록이 건강관리에 도움이 된다는 연구를 바탕으로 만들었어요." — 효과 보장 아님
- 금지: 유명인 이름, "살 빠지는", "2배", 질병명.

### 4-3. 기록할 마음이 없는 사람을 위한 접근성

| 아이디어 | 내용 | 이유 |
|---|---|---|
| **첫 기록 = 숫자 하나** | 온보딩 끝이 설명이 아니라 체중 칸 하나(또는 "방금 먹은 것" 칸 하나) | 그만두는 1순위 이유가 노력. 첫 장벽을 가장 낮게 |
| **'대충 기록'을 정식으로** | 이름만, 양은 '조금·보통·많이' | 간단한 기록도 단기 효과에 손해 없다는 연구 |
| **목표 없이 시작** | 칼로리 목표 설정을 첫날에 강요하지 않음. 3일 기록 뒤 "평소 이 정도 드시네요" 보여 주고 그때 목표 제안 | 레인 노턴식 '3일 진단 기록'과 같은 흐름 |
| **칭찬은 행동에, 가끔** | "남겼어요" 기본, 근거 문구는 가끔 | 매번 같은 말은 습관화로 무뎌짐 |
| **보이는 곳에 두기** | 앱 바로가기·위젯(연동·편의성 제안서) | 알림 없이 리듬 |
| **기록이 '쓸모'를 바로 보여 줌** | 기록 2~3개만 있어도 "점심이 하루의 절반이에요" 같은 작은 발견 | 기록 이유를 설득 대신 경험으로 |
| **끊겨도 돌아오기 쉬움** | 며칠 비어도 그 이야기를 하지 않음. "다시 오셨네요" 정도 | 건강 기록 중단은 죄책감과 연결(Epstein 외 2016) |

## 5. 대표님이 정할 것

1. **실명 사용 범위**: (권장) 연구자 이름·논문만 / 허락받은 코치·트레이너 인용 추가 / 유명인 실명(변호사 확인 후)
2. **"약 2배" 숫자를 쓸지**: 소개서에만(출처 포함) / 앱 안 'ⓘ 연구'에만 / 쓰지 않음
3. **근거 문구 노출 빈도**: 기록 직후 10번에 1번 / 처음 2주만 / 'ⓘ'를 눌렀을 때만
4. **'ⓘ 연구' 화면을 만들지**: 연구 4~5개를 쉬운 말로 정리한 화면(출처 링크 포함)
5. **허락받을 사람 후보**: 코치 모드 시험 중인 실제 강사·트레이너에게 한 줄 추천을 받을지(서면 동의·대가 여부 공개)
6. **변호사 확인 여부**: 스토어·광고·소개서 문구 확정 전 1회 검토

## 부록. 확인 방법 메모

- 유명인 발언을 쓰려면: 원 영상 링크 + 시각(분:초) + 원문 그대로 + 번역문을 기록해 두고, 그래도 영업 문구엔 쓰지 않는다.
- Kaiser 2008 연구 원문: Hollis JF 외, *Weight loss during the intensive intervention phase of the weight-loss maintenance trial*, Am J Prev Med 2008년 8월호 [논문 제목·쪽수는 원문 확인 필요].
- 법 조문: 국가법령정보센터에서 부정경쟁방지법 제2조 제1호 (타)목, 저작권법 제28조, 표시광고법, 공정위 추천·보증 심사지침 원문 확인.
