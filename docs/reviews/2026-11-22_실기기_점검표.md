# 실기기 점검표 (휴대폰으로 5~10분)

> 2026-11-22. 자동 시험과 PC 화면 캡처로는 확인할 수 없는 것만 모았다. 안드로이드 앱(APK)을 최신으로 설치한 뒤 위에서부터 눌러 보고, 안 되는 번호만 알려 주세요.

## A. 꼭 봐야 하는 것 (안드로이드 앱)

| # | 해 볼 것 | 이렇게 되면 정상 |
|---|---|---|
| 1 | 앱 아이콘을 **길게 누르기** | '체중 기록·식사 기록·운동 기록' 바로가기가 뜨고, 누르면 그 창이 바로 열린다 |
| 2 | 갤러리에서 인바디 결과지 사진 → **공유 → 마이로그** | 마이로그가 열리고 '인바디 사진 읽기' 창에 사진이 보인다. '숫자 읽기'를 누르면 숫자가 채워진다 |
| 3 | ChatGPT 등에서 글을 **공유 → 마이로그** | 'AI로 입력' 창에 그 글이 들어간다(전처럼) |
| 4 | 운동 → 빠른 기록 창을 열고 **2분 기다리기** | 화면이 꺼지지 않는다 |
| 5 | 수치 → ＋ 기록 | 지난번 체중이 큰 숫자로 보이고, −0.1·+1 버튼으로 바뀐다. '인바디'를 고르면 이 버튼들이 사라진다 |
| 6 | 운동 빠른 기록에서 지난번에 한 종목 고르기 | '지난번 11/○ · 60×10 · …'이 보이고, 첫 세트가 지난번 값으로 채워진다 |
| 7 | 식단 화면 그래프를 **손가락으로 누르기** | 그날 값이 뜬다. 오른쪽 위 ⓘ를 누르면 더 이상 안 뜬다(앱을 껐다 켜도 기억) |

## B. 계정이 필요한 것

| # | 해 볼 것 | 정상 |
|---|---|---|
| 8 | PC의 AI로 초안 2~3건을 만들고 휴대폰에서 **모두 확정** | 몇 초 안에 모두 확정되고, 같은 초안을 두 번 보내면 두 번째는 "같은 기록이 있어요"라고 묻는다 |
| 9 | 새 휴대폰(또는 앱 데이터 지운 상태)에서 로그인 직후 체중 하나 기록 | 동기화가 멈추지 않고 웹의 기록·목표가 내려온다 |
| 10 | 설정 → 나의 기록 방식 → GLP-1 '쓰고 있어요' | '다시 제안받기' 버튼이 뜨고, 누르면 목표 문답이 열린다. 식단 화면 맨 위에 '단백질 먼저' 막대가 보인다 |

## C. 한 번 보면 좋은 것

| # | 해 볼 것 | 정상 |
|---|---|---|
| 11 | 식사 하나 지우고 6초 지난 뒤 설정 → 휴지통 → 되살리기 | 그 식사가 다시 생긴다 |
| 12 | 앱을 두세 번 껐다 켜기 | 홈 '한눈에 보기' 아래 한 줄이 바뀐다. ×를 누르면 그날은 안 보인다 |
| 13 | 갤럭시 노트8(또는 작은 폰) | 식단 흐름의 탄단지가 한 카드 안 3줄로 보이고, 가로로 밀리지 않는다 |
| 14 | 아이폰(웹 앱)에서 입력칸 누르기 | 화면이 저절로 확대되지 않는다 |
