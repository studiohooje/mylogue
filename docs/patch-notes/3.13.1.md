# 마이로그 베타 3.13.1

- **웹에서 뒤로가기가 돼요.** 휴대폰의 뒤로 버튼도 같아요. 팝업이 열려 있으면 팝업이 닫히고, 아니면 이전 화면으로 돌아가요. 고치던 내용이 있으면 먼저 물어봐요.
- **아래 메뉴(홈·식단 등)를 누르면 항상 맨 위부터** 보여요. 아래로 내려가 있다가 다른 메뉴에 다녀와도 마찬가지예요.
- **많이 쓴 근육은 빨강, 보통은 주황, 조금은 노랑**으로 보여요(홈 운동 칸, 회복 지도, 부위 지도 모두).
- **홈 운동 칸의 몸 그림이 커졌어요.** 넓은 화면에서는 오른쪽에 크게, 글자와 겹치지 않게 놓였어요.
- 아래쪽에 잠깐 뜨는 안내 문구가 화면 가운데에서 살짝 오른쪽으로 밀려 보이던 문제를 고쳤어요.
- ‘평소 하는 운동’ 같은 선택 칩이 줄마다 폭을 채워 가지런해 보여요.
