# 마이로그 베타 3.18.2

- **아래 메뉴가 새로 정리됐어요.** `수치 · 식단 · 운동 | 홈 · 추가 | 분석 · 기록 · 설정`
  - 가운데 ‘홈’과 ‘추가’가 특별한 버튼이에요.
  - ‘분석’이 메뉴로 나왔어요.
- **분석에 ‘AI 코치’가 미리 공개됐어요(플러스 · 추후 공개).** 내 기록 숫자로 만든 예시 화면으로 어떤 코칭을 받게 될지 보여 드려요.
  - 오늘 남은 끼니 메뉴와 탄단지 달성률
  - 회복 중인 부위를 피한 다음 운동 플랜
  - 내 기록 기반 무게 목표
  - 체중 목표 도달 예측
- 홈의 기록 버튼 순서를 아래 칸과 맞췄어요: **수치 기록 · 식사 기록 · 운동 기록**.
- 운동 칸
  - 왼쪽에는 몸 앞·뒷면 그림을 크게, 오른쪽에는 이번 주 흐름(요일별 운동·휴식)을 보여 줘요.
  - 어제까지 많이 쓴 부위만 6초 간격으로 은은하게 깜빡여요.
- ‘수치’에 다시 들어오면 항상 ‘체중’ 탭부터 보여요.
