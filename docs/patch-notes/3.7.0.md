# 마이로그 베타 3.7.0

- **평소에 어떤 운동을 하는지 골라 주세요.** 시작 질문에 ‘평소에 어떤 운동을 해요?’가 생겼어요. 웨이트, 야외 러닝, 필라테스, 요가, 발레, 크로스핏, 하이록스 등 여러 개 고를 수 있고 건너뛰어도 돼요. 설정 › 나의 기록 방식에서 언제든 바꿀 수 있어요.
  - 지금은 웨이트·맨몸 운동을 세트로 기록해요. 골라 주신 운동은 다음에 무엇부터 만들지 정하는 데 쓸게요.
- **‘내 헬스장’이 ‘내 운동 장소’가 됐어요.** 필라테스를 고르면 ‘지도에서 고르기’에 근처 필라테스 스튜디오도 함께 나와요(요가, 클라이밍, 수영장, 복싱 등도 마찬가지).
- **시작 질문은 로그인한 계정에서, 아직 맞추지 않았을 때 한 번만** 나와요. 한 번 맞추면 다시 뜨지 않아요.
- **AI 연결이 되면 설정 화면에 ‘연결됨’이 크게 보여요.** 언제까지 쓸 수 있는지도 함께 보여 줘요.
