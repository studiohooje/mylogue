# 마이로그 베타 3.3.0

- **오늘의 헤일로가 생겼어요.** 홈 맨 위 카드에 오늘의 기록이 빛의 고리로 그려져요.
  - 기록할 때마다 그 시각 자리에 빛 구슬이 맺혀요. 몸은 복숭아빛, 식사는 청록, 운동은 연보라예요.
  - 평소 리듬대로 기록하면 구슬끼리 밝게 이어지고, 평소와 다른 시각이면 속이 빈 구슬로 조용히 표시돼요.
  - 몸·식사·운동을 모두 기록하면 고리 아래 세 점이 켜지며 **마이로그 아이콘이 완성**돼요.
- 고리의 양 끝은 내가 보통 하루를 시작하고 마무리하는 시각에 맞춰져요. 처음 일주일은 기본 시간(6시~24시)으로 시작해요.
- 얼마나 먹었는지, 몇 세트 했는지는 모양에 넣지 않았어요. 오늘 하루를 꾸준히 남겼는지만 보여 드려요.
- Android 앱도 같은 내용으로 업데이트됐어요.
