# 마이로그 베타 3.11.0

- **홈 ‘오늘 한눈에 보기’를 다시 체중 · 식단 · 운동 세 칸으로** 나란히 보여 줘요.
  - 식단 칸에는 칼로리·탄수화물·단백질·지방이 작은 막대로 보여요. 목표선이 있고, 넘치면 그만큼 다른 색으로 보여요. 아래에 ‘○○ 남음’이나 ‘+○○ 초과’가 나와요. 누르면 식단 화면으로 가요.
  - 운동 칸에는 **오늘 많이 쓴 부위**가 작은 앞·뒤 몸 그림에 색으로 칠해지고, 부위 이름도 함께 보여요. 누르면 운동 화면으로 가요.
- **운동한 시각을 정하고 고칠 수 있어요.** 운동 수정(빠른 수정·자세히 수정 모두)에서 운동한 시각과 운동 시간(분)을 바꿀 수 있어요. 타임라인 순서도 그 시각을 따라요.
- **팝업 바깥(어두운 부분)을 누르면 닫혀요.** 고치던 내용이 있으면 “아직 저장되지 않았어요. 닫을까요?”라고 먼저 물어봐요(× 버튼도 같아요).
