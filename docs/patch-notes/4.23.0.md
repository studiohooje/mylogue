# 마이로그 베타 4.23.0

## 휴식 알림이 화면이 꺼져도 와요
- '지정해 두고 쉬기'면 휴식이 끝나는 시각에 휴대폰 알림이 와요(앱이 꺼져 있거나 화면이 꺼져 있어도). 휴식 시간을 바꾸거나 다음 세트를 시작하면 알림도 맞춰 바뀌어요.
- 웹에서는 다른 탭에 있을 때 알림을 보내요(브라우저에서 허락한 경우).

## 운동 추천과 요령이 더 정확해졌어요
- '기구가 없거나 붐빌 때' 바꿔 할 운동이 같은 움직임 안에서만 나와요. 사이드 레터럴 레이즈엔 옆 어깨 운동만, 레그 컬엔 레그 컬만 나와요(예전엔 뒤 어깨·카프가 섞였어요). 어려운 동작은 뒤쪽에 보여요.
- 요령 문장 말투를 '~해요'로 맞췄어요.

## 무게·기록
- '한쪽씩'으로 적은 세트는 양쪽을 다 한 것으로 보고 볼륨을 계산해요.
- 웜업 기록이 없으면 메인 무게를 보고 **웜업 단계 제안**(예: 30kg×10 → 42.5kg×6 → 57.5kg×3)을 보여 드려요(참고용).
- '하던 순서'로 시작한 종목을 다 하면 "계획한 3종목을 다 했어요! 🔥" 하고 칭찬해 드려요.

## 나만의 유지칼로리가 더 정확해져요
- 체중을 적을 때 **체중이 흔들릴 만한 일**(생리 중·짠 음식·회식·아픔·약 용량 바뀜·크레아틴 시작)을 골라 둘 수 있어요(선택).
- 고른 날은 덜 반영하고, 약 용량이나 크레아틴처럼 체중 높이가 한 번에 바뀌는 일은 따로 맞춰요. 갑자기 튄 체중도 저절로 덜 반영해요.

## 편의점 음식
- CU 간편식 285가지를 더했어요. 'CU 김밥', '씨유 도시락'처럼 찾을 수 있어요.
