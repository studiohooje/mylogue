# 마이로그 베타 4.29.1

## AI를 쓸 때 더 안전하게
- AI 버튼을 여러 번 눌러도 같은 요청은 한 번만 보내요. 너무 짧은 시간에 여러 번 부르면 잠깐 기다리게 해요.
- AI 서버가 잠시 답하지 않으면 계속 두드리지 않고 잠깐 쉬었다가 다시 할 수 있게 해요. 다시 보내기는 언제나 직접 눌러요.
- 레시피 자동 분해도 처리 중에는 다시 보내지 않아요.

## 운영
- 운영자 계정에 AI 사용 금액 알림이 생겼어요. 이번 달 알림 기준의 70%·90%·100%와 오늘 상한에 닿으면 오른쪽 위 종에 알려 줘요.
- AI를 다른 회사 모델로도 바꿀 수 있게 준비했어요(아직 연결 전).
