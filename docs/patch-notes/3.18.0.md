# 마이로그 베타 3.18.0

- **‘몸’이 ‘수치’가 됐어요.** 아래 메뉴 ‘수치’, 홈 ‘수치 기록’, 화면 이름 ‘내 수치’.
- **홈 ‘오늘 한눈에 보기’가 정돈됐어요.**
  - 체중 칸: 숫자 아래에 최근 30일 체중 그래프가 보이고, 언제 쟀는지는 ‘어제 · 3일 전’처럼 보여요.
  - 식단 칸: ‘1,590 / 2,200’처럼 먹은 양 옆에 목표가 작게 붙어요.
  - 운동 칸: 운동을 아직 안 한 날에는 어제까지 쓴 부위가 파랑·초록으로 은은하게 깜빡여요.
- **목표를 많이 넘겨도 그래프가 따라가요.** 하나라도 막대를 넘치면 모든 막대가 목표의 2배까지 늘어나고, 그래도 넘치면 4배·8배로 늘어나요. 넘친 부분은 붉은 줄무늬예요.
- **먹을 예정·할 예정도 미리 넣어 둘 수 있어요.**
  - 지금보다 뒤 시각으로 넣으면 ‘예정’으로 저장돼요(반투명 카드).
  - ‘확정’을 눌러야 실제 기록이 돼요.
  - ‘예정 포함’을 켜면, 예정대로 먹었을 때의 그래프를 반투명하게 미리 볼 수 있어요.
  - 예정 시각이 1시간 넘게 지났는데 확정하지 않았으면 알림이 떠요.
- **평소 체중과 인바디를 따로 봐요.**
  - ‘체중’: 평소 체중계 기록만 선으로 이어요. 점선은 7일 평균이에요.
  - ‘인바디’: 체중·골격근량·체지방량을 각각 보거나, 체지방률(%)로 봐요.
  - 기록할 때 ‘평소 체중계 / 인바디’를 고를 수 있고, 인바디 결과지 사진으로 읽은 값은 자동으로 인바디로 들어가요.
  - 기간은 버튼(7일·30일·90일·전체)으로 바꾸고, 그래프에 마우스를 올리면 날짜와 값이 커서 옆에 떠요.
- **운동 기록이 넓어졌어요.**
  - 웨이트·러닝·유산소·필라테스·요가·기타로 먼저 고르고, 웨이트는 부위로 한 번 더 나눠요.
  - 러닝은 시간·거리·평균 페이스·심박·느낀 강도, 필라테스는 수업 시간·형태(개인·듀엣·그룹)·강도·메모를 남겨요. 헤일로에도 반영돼요.
  - **‘오늘은 의도적 휴식’**: 쉬는 날을 기록하면 헤일로가 그대로 채워져요.
- 식사·운동·수치 기록 버튼에 아이콘이 생겼고, ‘AI로 입력’ 버튼은 가운데에 깔끔하게 놓였어요.
- 알림에서 AI 초안을 **모두 확정·모두 버리기**할 수 있어요.
- ‘AI로 입력’ 창에서 **PC의 AI와 직접 연결**하는 방법도 안내해요(기존 연결은 그대로).
- 컴퓨터 화면에서는 오늘의 타임라인이 3칸으로 컴팩트하게 보이고, 시각이 더 또렷해졌어요.
