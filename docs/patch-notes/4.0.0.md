# 마이로그 베타 4.0.0

큰 업데이트예요. 운동 화면이 새로 짜였고, '기록' 메뉴가 **일정**으로 바뀌었어요.

## 운동
- **내 운동 장소**: 헬스장·필라테스·요가·크로스핏·클라이밍 등 다니는 곳을 등록하면, 장소마다 몇 번 갔는지 세어 드려요.
- **이번 주 흐름**: 월~일에 무엇을 했는지(예: 하체, 필라테스, 휴식, 예정) 한눈에 보여요.
- **예정된 운동**: 미리 넣어 둔 운동을 세트마다 '완료'로 눌러 가며 하고, 끝나면 확정해요. 누르지 않은 세트는 하지 않은 세트로 남아요. 종목을 정하지 않은 예정(예: 웨이트(하체))은 '기록하기'로 바로 입력해요.
- **이번 주 부위 균형**: 부위별로 몇 세트 했는지 막대로 보여요.
- '총 운동 횟수·누적 볼륨' 칸은 뺐어요.

## 일정(전 '기록')
- 달력 하루 칸에 **체중 / 먹은 칼로리와 탄단지 색 막대 / 한 운동**이 보여요.
- 오늘이나 앞으로의 날짜를 고르면 **운동 예정**을 넣을 수 있어요(웨이트는 부위까지). 예정은 확정하기 전까지 통계에 들어가지 않고, 지우기 전까지 남아 있어요.

## 더 편해진 입력
- 날짜·시각 칸 아래에 **어제·오늘·내일, 지금, 가까운 정시, ±15분·±30분·±1시간** 버튼이 생겼어요.
- 앞으로의 시각으로 넣은 기록은 AI로 넣어도 **예정**으로 들어가요.
- AI 입력 창 맨 아래에 'PC의 AI와 직접 연결' 안내를 따로 모았어요. 연결해 두면 복사·붙여넣기 없이 말만 하면 돼요.

## 고친 것
- 홈에서 일부 식사·운동을 수정하려고 하면 "찾을 수 없습니다"가 뜨거나 식사가 사라지던 문제를 고쳤어요.
- 탄단지 중 하나가 목표를 넘으면, 막대 전체가 줄어드는 대신 **넘친 줄만** 길어지고 은은하게 깜빡여 알려 줘요.
- 식단 화면에 AI의 내부 메모가 보이던 것을 숨겼어요.
- 분석의 'AI 코치' 미리보기 이름을 **AI 인사이트**로 바꿨어요.
