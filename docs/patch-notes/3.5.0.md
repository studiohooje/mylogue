# 마이로그 베타 3.5.0

- **운동 ‘계획 → 안내’ 모드가 생겼어요.** 설정 › 나의 기록 방식에서 ‘계획→안내’를 고르면 돼요.
  - 운동 전에 종목·무게·횟수·세트·휴식을 정해요. ‘지난 운동 그대로’나 저장한 루틴으로 한 번에 채울 수 있어요.
  - 운동 중에는 큰 **‘세트 끝’** 버튼 하나만 누르면 돼요.
  - 휴식은 원형 타이머로 보여 주고, “휴식 10초 남았습니다 → 3, 2, 1 → 2세트 시작”을 소리와 음성으로 알려 줘요. 휴식이 끝나면 다음 세트로 자동으로 넘어가요.
  - 무게나 횟수가 달라지면 ‘무게·횟수 바꾸기’로 남은 세트에 바로 적용해요.
- **안내 방식을 고를 수 있어요.** 소리+음성 / 소리만 / 진동만(Android) / 화면만. 안내 중에는 화면이 꺼지지 않게 할 수도 있어요.
- **Android 앱은 화면이 꺼져도** 휴식이 끝나면 알림으로 알려 줘요. 처음 안내를 시작할 때 알림을 허용해 주세요.
- 세트를 끝낼 때마다 바로 저장돼요. 중간에 앱을 닫아도 한 세트까지 남아요.
