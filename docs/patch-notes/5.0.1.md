# 마이로그 베타 5.0.1 (준비 중)

## 새로 생긴 것
- **카카오·이메일로도 가입·로그인**할 수 있어요. 로그인을 누르면 '카카오 · Google · 이메일' 중에 골라요.
- 이메일로 가입하면 인증 메일이 가요. 메일의 링크를 누른 뒤 이용 신청을 할 수 있어요. 비밀번호를 잊었으면 '비밀번호를 잊었어요'로 다시 정해요.
- 메이트 초대 링크를 연 사람이 로그인 전이면, 그 화면에서 바로 가입·로그인할 수 있어요. 로그인하면 초대가 다시 열려요.
- 초대 화면에 **초대 코드가 크게** 보이고 '코드만 복사'가 생겼어요. 메이트 탭과 방 설정에서 코드로 들어갈 수 있어요.

## 고친 것
- **초대 링크를 열어도 초대 화면이 안 뜨던 문제**를 고쳤어요.
- 사진 찍을 때 고르는 순서를 **음식 · 체중계 · 운동·기타**로 바꾸고, 처음엔 음식이 골라져 있어요.
- 메이트 방의 대화가 90일이 지나면 방을 열 때 자동으로 정리돼요(사진은 이미 90일 뒤 자동으로 지워져요). 기록에 남긴 숫자는 그대로예요.
