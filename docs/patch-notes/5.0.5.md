# 마이로그 베타 5.0.5 (준비 중 · 아직 배포 전)

## 바뀐 것
- **운동 종목이 90개 늘었어요.** 리버스 그립 벤치프레스, 플로어 프레스, 펜듈럼 스쿼트, 시시 스쿼트, 저처 스쿼트, 예이츠 로우, 실 로우, 베이지안 컬, 조트맨 컬, 토 투 바, 버드독, 행 클린 같은 동작을 이제 따로 기록할 수 있어요. 그림은 곧 채워지고, 그 전까지는 부위 표시로 보여요.
- 펜듈럼 스쿼트·행잉 니 레이즈·덤벨 쓰러스터·로우 로우 머신은 다른 운동의 다른 이름이 아니라 **각자 따로** 기록돼요.
- 새 종목에도 동작 요령·주의할 부위·바꿔 할 운동이 붙어 있어요.
- **필라테스** 동작 중 그림이 정해지지 않았던 11개(롱박스 시리즈, 푸시스루바, 롤백바 등)에 알맞은 자세 그림이 나와요.
- **음식 검색**: '돼지불고기'처럼 '(집밥)'이 붙은 이름도 그대로 쳐서 찾을 수 있어요. 값이 맞지 않던 음식 일부(당류가 탄수화물보다 많은 등)는 '확인 필요'로 표시하고 검색 뒤로 보냈어요.
- **메이트**: 첫 화면에서 마이태그를 크게 권하지 않아요. 마이태그는 오른쪽 위 프로필에서 정해요.
- 화면 곳곳의 정렬과 글자 크기를 다듬었어요.
