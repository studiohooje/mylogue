# 마이로그 베타 3.19.0

- **탄단지 목표를 내 방식대로 정할 수 있어요.** 탄수·단백질·지방마다 정하는 방식을 따로 골라요.
  - **비율 %**: 목표 칼로리의 몇 %
  - **체중 × g**: 최근 체중 × 2g처럼. 체중을 새로 기록하면 목표가 자동으로 다시 계산돼요.
  - **고정 g**: 예) 단백질은 딱 200g
  - **나머지**: 다른 영양소를 채우고 남은 칼로리를 가져가요. 나머지가 둘이면 비율로 나눠요(예: 탄수 60 : 지방 40).
  - 빠른 선택: 균형 40·30·30 / 단백질 체중×2 · 지방 25% · 나머지 탄수 / 단백질 체중×1.8 · 탄수 체중×4 · 나머지 지방 / 저탄수
- **식단 화면의 목표가 한눈에 보여요.** 목표 칼로리와 탄수·단백질·지방을 고유 색으로 보여 주고, 각각 몇 g·몇 %·어떤 방식인지 표시해요.
  - **수정**: 목표 칼로리와 영양소별 방식을 바꾸면 합계가 바로 계산돼요.
  - **제안해 주세요**: 처음 시작할 때처럼 나이·키·체중·목표로 추천받아요.
