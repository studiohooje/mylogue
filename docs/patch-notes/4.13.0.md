# 마이로그 베타 4.13.0

## 외식·배달 메뉴가 훨씬 많아졌어요
- 음식 검색에 프랜차이즈 메뉴가 크게 늘었어요. **175개 브랜드**, 음식 DB 전체 **4만 3천여 개**예요.
  - 새로 들어온 곳: 버거킹, BBQ, KFC, 한솥, 파파존스, 미스터피자, 피자헛 일부, 7번가피자, 반올림피자, 피자알볼로, 피자스쿨, 공차, 배스킨라빈스, 설빙, 포케올데이, 프랭크버거, 쉐이크쉑, 또래오래, bhc 대표 치킨(뿌링클·맛초킹·골드킹 등), 처갓집, 페리카나, 바른치킨, 배떡, 김가네, 신전떡볶이 등
- **'bhc 뿌링클'**, **'한솥 제육'**처럼 브랜드와 메뉴를 띄어 써도, 순서를 바꿔 써도 찾아요.
- 중량 없이 1개 값만 공개된 메뉴(한솥 등)도 '1개'로 담을 수 있어요.

## 출처를 더 분명하게 보여 드려요
- 브랜드가 영양값을 공개하지 않은 메뉴는 같은 종류 메뉴의 공식 값으로 계산한 **추정** 값으로 넣었어요. 붉은 **'추정'** 꼬리표가 붙고, 공식 값보다 아래에 나와요. 예: 기영이숯불두마리치킨 저당 빨간양념 숯불치킨.
- 신문 보도·한국소비자원 시험처럼 홈페이지 밖에서 공개된 값에는 **'공개 자료'** 꼬리표가 붙어요.
- 같은 브랜드의 포장 제품(파우치죽, 밀키트 등)은 매장 메뉴와 구분해 '제품'으로 보여요.
- 검색 안내문: "공개 자료를 옮긴 참고값이라 실제와 다를 수 있어요."

## 이야기 페이지
- '마이와 로그'를 **'구두점'** 이야기로 새로 썼어요. 한국어 문장부호 이름(쉼·마침·물음·따옴)이 모두 하는 일의 이름이라는 데서 출발해, 끊길 뻔한 기록을 다시 잇는 **이음(;)**, AI 초안을 감싸는 **따옴(“ ”)**이 등장해요.
- 약속 04를 "모르는 숫자는 모른다고 적습니다 — 추정은 추정이라고 분명히"로 고쳤어요.

## 이용약관
- 제5조의2(음식 DB)를 더했어요. 음식 영양값은 공개 자료를 옮긴 참고값이고, 추정 값은 표시하며, 브랜드와 관계가 없고, 틀린 값·게재 중단 요청을 받아 고친다는 내용이에요.
