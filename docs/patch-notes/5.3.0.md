# 마이로그 베타 5.3.0 (2026-11-26)

## 화면 전체를 한 번 정리했어요 — 같은 숫자는 한 번만
- **운동**: '이번 주' 카드는 세트·볼륨·유산소만(운동한 날은 맨 위 원에 이미 있어요). 오늘 운동은 오늘 카드에만, 일지는 지난 날부터. '새 기록'은 한 목록으로 합치고 최고 기록 표는 **더 보기 › 최고 기록**으로, 12주 달력도 **더 보기**로 옮겼어요.
- **식단**: 하루 누적 카드에 같은 칼로리가 세 번 나오던 걸 줄였어요. 목표 칼로리 카드는 빼고 위의 **목표 수정** 하나로(탄단지 비율도 그 안에). 식단 흐름은 지난 기간 평균만 보여요.
- **홈**: 한눈에 보기 운동 칸도 타임라인과 같은 **운동 이름**으로. 타임라인 옆 '＋기록'은 뺐어요(위 버튼·입력 탭과 겹쳐서). 'AI가 작성한 기록' 카드는 **검토할 게 있을 때만** 떠요.
- **분석**: 리포트 카드는 **이미지로 저장할 때만 펼쳐요**. 'AI 코치'는 **AI에게 묻기**로 이름을 바꿨어요.

## 체중 기록이 쉬워졌어요
- 식사·운동처럼 먼저 **체중 기록 / 인바디 기록**을 골라요. 그래프도 따로 그려요.
- 체중은 **숫자판이 곧 입력칸**이에요. 가운데 숫자를 눌러 직접 고치거나 ±0.1·±1로 맞춰요.
- 인바디는 체성분 칸이 바로 보이고, 체중은 그 안에서 꼭 넣어요.
- 측정일은 한 줄로 작게, '체중이 흔들릴 만한 일'은 **체중 관련 특이사항**으로 바꾸고 **짠 음식 · 과식 · 음주**를 따로 골라요.

## 입력 창이 모두 같은 모양이에요
- 식사·운동·수치·AI 입력 창이 **모두 아래에서 올라오고**, 제목 크기·닫기 버튼도 같아요.
- 처음 고르는 화면(방금/전에/앞으로 · 실시간/한 번에 · 체중/인바디)도 같은 카드 모양이에요.
- 식사 창 맨 아래의 '날짜·시각 · 오늘 누적' 줄은 위와 겹쳐서 뺐어요.
- 지난 식사 카드: 칼로리는 머리줄 오른쪽, 아래에 **통째로 기록**(바로 저장, 되돌리기 가능) · **세부 수정** 두 버튼.

## 메이트로그가 메신저처럼
- 방 안: **내 글은 오른쪽 민트 말풍선**, 메이트 글은 왼쪽에 얼굴·이름, 이어 쓴 글은 묶어서. 시각은 말풍선 옆, 사진도 말풍선 안에. 날짜는 가운데 구분선으로, 아래 입력줄은 둥근 칸과 보내기 버튼.
- 오른쪽 위 **＋** 안에 **방 만들기 · 초대 코드로 들어가기**를 모았어요. 본문의 큰 초대 코드 상자는 없앴어요.
- 90일 보관·마이태그 안내는 맨 아래 **작은 한 줄**로.
