# 마이로그 베타 5.4.5 (2026-11-26)

## 홈
- 날짜를 바꿔도 위쪽 큰 박스 높이가 **오늘 크기 그대로** 있어요. 날마다 글이 달라도 화면이 위아래로 출렁이지 않아요.

## 기록 창이 더 깔끔해졌어요
- '어떻게 기록할까요?'의 세 가지 선택지가 **같은 크기·같은 배열**로 더 작고 단정해졌어요(식사·운동 모두).
- 입력 창 안 덩어리 사이 간격을 하나로 맞췄어요. 세 갈래 탭과 아래 목록이 붙어 보이던 문제도 고쳤어요.
- 검색 칸은 '종목 검색' · '음식 검색'으로만 간단하게.

## 운동 기록
- **하던 순서 살짝 바꾸기**: 하던 순서를 그대로 시작하거나, '살짝 바꾸기'로 몇 개는 빼고(✕) · 순서를 바꾸고(↑↓) · 아래 종목을 눌러 더해서 시작해요. '처음 순서로'로 되돌릴 수 있어요.
- **날짜·헬스장·세션 이름**을 맨 위로 올렸어요.
- '지난 운동처럼 하기'는 **지난 운동에서** 탭에서만 보여요.
- 처음 고르는 창에 있는 '의도적 휴식'이 입력 창에 한 번 더 나오던 중복을 뺐어요.
- 헷갈리던 '종목·루틴 상세 입력' 링크를 뺐어요.
- **이 기구 뭐지? 사진으로 찾기**: 운동 '도움받기'에서 헬스장 기구를 찍으면 AI가 **기구 이름 · 주로 쓰는 근육 · 사용 요령**을 알려 주고, **그 종목으로 바로 시작**하거나 종목 검색에서 볼 수 있어요. 기록은 만들지 않아요. 알아보지 못하면 횟수는 돌려드려요.

## 로그인
- 로그인 직후 예전 기록이 안 보이다가 껐다 켜야 나오던 문제를 고쳤어요. 서버에서 기록이 오면 화면이 바로 바뀌어요.
- 구글 로그인 창을 닫았을 때 영어 오류(Firebase: Error …)가 이메일 가입 창에 뜨던 문제를 고쳤어요. 창을 닫은 건 조용히 넘어가고, 다른 문제는 한국어로 알려 드려요.
