# 마이로그 베타 4.2.0

- 홈·식단·운동 화면 위에 날짜 바가 생겼어요. 화살표나 옆으로 밀기로 다른 날을 보고, 그 날짜로 바로 기록할 수 있어요.
- 기록 창의 날짜와 시각 입력을 '언제' 칸 하나로 모았어요.
- 휴식한 날은 시간 없이 '휴식'으로 맨 위에 보여요.
- 운동 화면에서 헬스장을 눌러 바로 고를 수 있어요.
- 오늘 운동 요약에는 많이 한 부위만 순서대로 보여요.
- 탄단지 목표 '제안해 주세요' 버튼을 목표 설정 창 안으로 옮겼어요.
- 화면 위 버튼들의 높이를 맞췄고, 모드 이름을 '마이로그 | 코치로그'로 바꿨어요.
