# 5.9.6 패치노트

- **운동 화면의 '종목 성장'이 '늘어난 무게'로 바뀌었어요.** 한 종목만 보여 주던 큰 그래프 대신, 무게가 오른 종목마다 작은 그래프와 '처음 무게 → 지금'이 한 줄씩 나와요.
- **식단·운동 화면의 묶음 제목을 하나로 맞췄어요.** '오늘 먹은 양 · 식단 흐름 · 먹은 것 · 더 보기', '종목 · 늘어난 무게 · 더 보기'가 모두 같은 모양이에요.
- **'목표 수정'을 눈에 띄는 버튼으로 바꿨어요.**
- **식단 흐름의 겹 테두리를 없애고, 점수 그래프를 가운데 넓게 펼쳤어요.** ⓘ 버튼의 네모 테두리도 없앴어요.
- **남은 칼로리와 '예정 포함'을 한자리에 모았어요.**
- **'더 보기' 옆 개수, 예정 식사의 '누적에 안 들어가요' 문구를 뺐어요.**
- **운동 요일에서 일요일·공휴일은 빨강, 토요일은 파랑으로 보여요.**
- **'가슴 삼두'처럼 띄어 쓴 운동 제목도 '가슴·삼두'로 맞춰 보여요.**
