# 마이로그 베타 4.6.0

- 끼니를 '식사1 · 식사2'로 부를지 '아침 · 점심 · 간식 · 저녁 · 야식'으로 부를지 고를 수 있어요. 처음 시작 문답에서 묻고, 설정의 '나의 기록 방식'에서 언제든 바꿀 수 있어요. 이름으로 고르면 먹은 시각에 따라 붙고, 같은 이름이 또 나오면 '아침 2'처럼 번호가 붙어요.
- 홈 '한눈에 보기' 아래에 오늘의 한 줄이 조용히 보여요. 앱을 열 때마다 바뀌고, 아침·낮·저녁·밤에 맞는 말도 섞여요. 연구가 근거인 문장은 ⓘ를 누르면 출처가 나와요. ×를 누르면 그날은 다시 안 보여요.
- 기록을 남기면 '남겼어요. 이번 주 3일째 기록이에요.'처럼 짧은 한마디를 해 줘요.
- 기록이 비어 있는 날에는 '방금 먹은 것 하나만 남겨 볼까요?' 같은 안내와 바로 기록하는 버튼이 보여요.
