# 마이로그 베타 4.14.0

## 백 온 트랙 — 다시 리듬으로
한동안 기록을 비웠다가 돌아오면, 홈 맨 위에 작은 카드가 떠요.
> 기록은 한 번 끊기면 모든 게 귀찮아지죠. 알아요. 비워 둔 날, 어떻게 할까요? 어느 쪽이든 괜찮아요.
- **[생각나는 만큼 채워 볼게요]** · **[비워 두고 오늘부터]** 중 고르면 돼요. 비워 두기를 골라도 아무것도 깨지지 않아요.
- 채우기를 고르면 최근 5일이 날짜별로 접혀 나와요. 적고 싶은 날만 펼쳐서
  - 식사: 생각나는 식사만(이름만 적어도 돼요)
  - 운동: 기억나는 만큼만, 또는 '이날은 쉬었어요'
  - 체중: 안 쟀다면 안 적어도 돼요
- 더 이전 날짜도 골라서 적을 수 있어요.
- **말로 한 번에 적기**: "화요일 점심 김치찌개, 목요일 헬스 하체, 어제 몸무게 70.8kg"처럼 적으면 요일·어제·날짜를 보고 날짜별로 나눠 넣어 줘요. 확인하고 저장하면 돼요.
- 언제 뜨나요: 최근 30일 동안 기록한 날이 많을수록 빨리, 적을수록 늦게 떠요(25일 이상 → 3일째, 20일 → 5일째, 16일 이하·처음 쓰는 분 → 7일째). 하루에 한 번만, 닫으면 다시 안 떠요. 알림으로 부르지 않아요.
