# 마이로그 베타 3.2.0

- **하단 탭 아이콘이 새로워졌어요.** 지금 보고 있는 탭은 청록색으로 꽉 차고, 나머지는 은빛 선으로 보여서 어디에 있는지 한눈에 알 수 있어요.
- **홈 맨 위 카드가 시간에 따라 바뀌어요.** 아침엔 맑은 민트빛, 낮엔 선명한 청록, 저녁엔 은은한 노을빛, 밤엔 고요한 보랏빛이에요.
- **기록이 없는 화면도 심심하지 않게.** 몸·식단·운동·타임라인·AI 검토함이 비어 있을 때 마이로그만의 그림이 반겨 드려요.
- Android 앱도 같은 내용으로 업데이트됐어요. 기존 앱 위에 설치하면 기록은 그대로 남아요.
