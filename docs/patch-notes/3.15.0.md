# 마이로그 베타 3.15.0

- **헬스장 머신을 대폭 늘렸어요.** 머신 종류가 59가지로 늘었어요(버티컬 레그 프레스, 파워 스쿼트, 멀티 힙, 리버스 하이퍼, GHD, 슈러그 머신, 로어 백 등).
- **제조사 모델도 골라요.** 머신 종류 옆의 ‘제조사’를 누르면 해머스트렝스·라이프피트니스·사이벡스·테크노짐·매트릭스·파나타·짐80 모델 139가지가 펼쳐져요.
  - 모델을 고르면 그 기계의 기본 단위(lb/kg)로 시작해요.
- **쓰이는 근육은 마이로그가 알아서 넣어요.** 머신마다 주로 쓰이는 근육과 보조 근육을 미리 정해 두었어요. 고르기만 하면 부위 지도와 분석에 바로 반영돼요.
  - 같은 머신으로 다른 동작을 하면(예: 레그 프레스로 카프 레이즈) 그 동작에 맞춰 넣어요.
- **‘머신 없이’는 머신 없이 할 수 있는 운동에만 나와요.** 레그 프레스·케이블 운동·스미스 운동에서는 빠졌어요. 머신 없이 자주 했다면 목록 위쪽에 보여요.
- **횟수는 작게 ‘6회’처럼 보여요.**
- 내 머신을 등록할 때 ‘머신 종류’만 고르면 근육은 자동으로 맞춰져요.
