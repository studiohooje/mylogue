# 마이로그 베타 4.1.0

## 같은 음식을 하루에 여러 번
- 같은 음식을 하루에 두세 번 먹어도 **시각이 다르면** 그대로 기록돼요.
- 같은 시각이어도 한 끼에 다른 음식이 하나라도 있으면 새 기록으로 받아요.
- 한 끼 전체가 같은 시각에 똑같을 때만 "이미 같은 기록이 있어요"라고 묻고, '확인'을 누르면 따로 저장할 수 있어요.

## 탄단지 목표 정하기가 쉬워졌어요
- 맨 아래에 **지금 몇 %인지** 바로 보여요. 예: "단백질 176g이 목표의 31%예요. 남은 69%를 나머지 영양소가 나눠요."
- 비율로 정한 영양소의 합이 모자라거나 넘치면 "9% 남아요 / 5% 넘어요"라고 알려 주고, **"탄수화물을 48.6%로 맞추기", "탄수화물을 나머지로(자동)"** 버튼으로 한 번에 맞춰요.
- 단백질을 체중×g이나 고정 g로 바꾸면, 탄수화물이 자동으로 **'나머지'**가 되어 남은 칼로리를 채워요(다시 비율로 바꿀 수 있어요).
- 영양소마다 목표 칼로리 대비 몇 %인지 같이 보여요.
