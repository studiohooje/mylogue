# 마이로그 베타 4.28.0

## 식단
- **식단 점수가 더 너그러워졌어요.** 목표보다 조금 넘치거나 모자란 날은 조금만 깎아요(칼로리 ±10%, 탄수·지방 ±15% 안이면 만점). 지난 날짜도 같은 기준으로 다시 계산돼요.
- 라면·막국수·쌀국수·카레라이스 등 **한식 대표값 61가지를 식약처 자료로 바로잡았어요.** 근거가 확인된 119가지는 '값 확인 필요' 표시를 뗐어요. 이미 남긴 기록은 그대로예요.
- 카페·피자 메뉴의 크기(Tall·Large·L 등)가 단위 칸에 보이던 것을 '잔·조각·판·컵'으로 바꾸고 크기는 이름에 적었어요.
- 영어(chicken breast, coke zero, big mac)와 한 글자 오타(닭가슴쌀, 된장찌게)로도 음식을 찾아요.
- 수량을 직접 치면 열량 줄이 바로 바뀌어요. 식사 기록 창의 '오늘 누적'이 홈과 같은 숫자예요(예정 식사 제외).
- 업체가 탄수화물·지방을 알려 주지 않은 메뉴는 '값이 이상해요' 경고를 띄우지 않고, 하루 요약에 몇 개가 빠졌는지 알려 줘요.

## 운동
- **운동을 기록하다가 헬스장을 바로 추가할 수 있어요.** 헬스장 칸에서 '＋ 새 헬스장 추가'를 고르고 이름만 적으면 바로 골라져요.
- HIIT·타바타·에어로빅·줌바·파워 요가·노르딕 워킹·아쿠아로빅·맨몸 서킷의 소모 열량을 국제 기준표로 더했어요. '빠르게 걷기'는 걷기와 따로 계산해요.

## 기록과 계정
- 따로 보관한 기록이 있다는 안내가 다른 알림에 가려지지 않아요.
- 가입 동의에서 '모두 동의'는 필수 항목만 켜요. 운영자 열람(선택)은 맨 아래로 옮겼어요. 예전에 필수로 동의하셨던 분께는 선택으로 바뀌었다는 안내가 한 번 떠요.
- 도움말에서 '문의 메일에 오류 기록 붙이기'로 앱에 남은 오류 기록을 보낼 수 있어요(내 기록 내용은 들어 있지 않아요).
- 운영자가 앱 안에 짧은 공지를 띄울 수 있어요(점검 안내 등).
- 안드로이드 앱의 기록이 휴대폰 자동 백업(구글 백업)에 실리지 않아요. 휴대폰을 바꿀 때는 로그인 동기화나 '백업 파일 받기'를 써 주세요.
- 도움말에 새 기능 문답 7개를 더했어요.
