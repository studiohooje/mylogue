# 마이로그 베타 5.0.0 (준비 중)

## 새 기능: 로그메이트
- **메이트 탭**이 생겼어요. 셋로그처럼 체중계 숫자, 먹은 것, 운동한 순간을 사진으로 찍어 방에 올려요.
- **내 방**(나만 보는 사진 기록)과 **친구 방**(초대한 메이트끼리, 최대 8명)을 만들 수 있어요.
- 사진은 **앱 안에서 찍기만** 돼요. 찍은 사진 왼쪽 위에 **찍은 시각**이 새겨져요.
- 올릴 때 '어디에 올릴까요?'는 **지난번에 고른 방**이 미리 골라져 있어요.
- 체중계 사진을 올리면서 체중을 적으면 **체중 기록에도 남아요**.
- **초대는 링크·QR**로 해요. 방장이 아니어도 초대할 수 있고, 방장은 다른 메이트에게 넘길 수 있어요.
- 메이트 이름을 누르면 **체중·식단·운동 카드**가 떠요. 카드를 누르면 그 메이트의 기록을 **보기 전용**으로 볼 수 있어요.
- 방을 만들 때 **수치·식단·운동을 각각 공개·비공개**로 정해요. 나중에 바꾸려면 **메이트 모두 동의**해야 해요. 한 명이라도 거절하면 그대로예요.
- 방의 대화·사진은 **90일 동안 보관**되고 그 뒤 자동으로 지워져요. '내 기록에 남기기'로 옮긴 숫자는 기록으로 계속 남아요.

## 사진으로 식단 남기기
- 메이트 방에 올린 내 사진에서 **'식단으로 가져오기'**를 누르면, 사진을 다시 찍지 않고 AI가 식단 초안을 만들어요. 먹은 시각은 사진 찍은 시각으로 들어가요.
- **'혼자 / 2명 / 3명…'**을 고르면 칼로리·탄단지를 나눠서 내 몫만 기록해요.
- 반대로 **식사 기록 창에서 '메이트로그에서 가져오기'**를 눌러 최근 올린 식사 사진을 고를 수도 있어요.
- AI는 버튼을 누를 때만 불러요.

## 하단 메뉴
- **홈 · 그래프 · 입력 · 메이트 · 분석 · 설정** 여섯 칸으로 바뀌었어요. 칸 크기가 모두 같고, 마이로그 그라데이션으로 칠했어요.
- **그래프**를 누르면 수치·식단·운동·일정이 떠요. '추가'는 **'입력'**으로 이름이 바뀌었어요.
