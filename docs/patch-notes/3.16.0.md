# 마이로그 베타 3.16.0

- **‘AI로 입력’이 생겼어요.** 홈 맨 위와 아래 ‘추가’ 메뉴 맨 위에 있어요.
  1. **지시문 복사**를 눌러, 평소 쓰는 AI(ChatGPT·Gemini·Claude 등, 무료 버전·휴대폰 앱 모두 OK) 대화창에 한 번 붙여넣어요.
  2. 그 대화에서 평소처럼 말해요. “점심에 제육덮밥 먹고 콜라 한 캔”, “하체 했어. 레그프레스 100키로 12개 3세트”, “아침 체중 72.4”
  3. AI가 준 **마이로그 코드**를 복사해 붙여넣으면, 무엇이 들어갈지 바로 보여 줘요. ‘검토함에 넣기’ → 검토함에서 확인하고 확정하면 끝!
- **Android에서는 더 쉬워요.** ChatGPT 답의 ‘공유’에서 마이로그를 고르면 입력 칸에 바로 채워져요.
- **AI가 정한 칼로리·탄단지는 ‘내 값’으로 계속 써요.** 다른 사람에게는 보이지 않아요. 같은 이름·단위의 음식은 하나로 묶이고 최근 값을 써요. 같은 답을 두 번 붙여넣어도 한 번만 들어가요.
- **내 음식·운동 목록 복사**: AI는 마이로그에 뭐가 있는지 볼 수 없어요. 내 목록을 대화에 한 번 붙여 주면 같은 이름과 값을 다시 써서 더 깔끔해요.
- 머신 이름을 말하면 마이로그의 머신·제조사 모델과 맞춰, 쓰인 근육까지 자동으로 넣어요.
