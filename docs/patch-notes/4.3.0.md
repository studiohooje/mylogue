# 마이로그 베타 4.3.0

- 식단 화면에 '식단 흐름'이 생겼어요. 식단 점수와 칼로리·탄수·단백질·지방을 그래프로 볼 수 있어요.
- 수치 화면에 '한눈에'가 생겼어요. 일간·주간·월간 체중 흐름, 목표선, 주간 변화, 체성분 변화, 요일 패턴을 볼 수 있어요.
- 운동 화면에 12주 운동 잔디, 주별 운동 흐름, 종목 성장, 새 기록이 생겼어요.
- 이상해 보이는 음식 값(예: 1mL에 40kcal)을 모아 보여 주는 '정리할 값' 카드가 생겼어요. 고치면 그 기록만 바뀌어요.
- 팩·스쿱처럼 무게가 다른 단위는 '1팩(100g)'처럼 무게를 함께 적을 수 있어요.
- 음식을 고르면 자주 먹은 양을 먼저 보여 줘요. '어제 이 시각 식사 그대로'도 한 번에 넣을 수 있어요.
- 예정 기록 확인 버튼 이름을 '먹었어요', '했어요'로 바꿨어요.
- 체중을 3일, 인바디를 2주 넘게 안 남기면 알려 줘요. 설정에서 끄거나 기간을 바꿀 수 있어요.
