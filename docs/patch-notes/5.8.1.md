# 마이로그 5.8.1

**인바디 전체 기록**
- 인바디 칸의 흐름선 점에 마우스를 올리거나 누르면, 그날 날짜와 수치가 보여요.
- 인바디 카드 오른쪽 위 '전체 기록'에서 그동안 잰 인바디를 모두 볼 수 있어요. 1년·전체를 고르고, 골격근량·체지방량·체지방률을 바꿔 가며 볼 수 있어요.
- 전체 기록 그래프는 실제 날짜 간격대로 그려요. 3월과 6월 사이처럼 오래 비었던 기간은 그만큼 넓게, 2주 넘게 빈 구간은 흐린 선으로 이어요.
- 아래 목록은 달마다 접혀 있어요.

**체중 그래프**
- 일간 체중 그래프도 실제 날짜 간격대로 그려요. 며칠씩 건너뛰고 잰 기간이 한 칸으로 붙지 않아요. 2주 넘게 빈 구간은 흐린 선이에요.
- 추세선(7일 평균)은 '최근 7번 잰 값'이 아니라 '최근 7일 안에 잰 값'의 평균이에요.
