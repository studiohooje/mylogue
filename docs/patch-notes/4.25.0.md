# 마이로그 베타 4.25.0 (준비 완료 · 아직 배포 전)

## AI로 입력한 음식의 단위가 g로 바뀌던 문제를 고쳤어요
- AI가 '2팩', '1공기', '1그릇'처럼 적은 음식을 검토함의 '내용 확인·수정'에서 확정하면, 단위가 g로 바뀌어 저장되는 문제가 있었어요(예: 킹닭 닭다리살 1팩 → 1g). 이제 AI가 적은 단위가 그대로 남고, 팩·봉·공기·그릇·인분 등 모든 단위를 고를 수 있어요.
- AI 답에 '1팩(100g)'처럼 숫자가 여러 개 섞여 있어도 앞의 양만 읽어요. '반', '한 팩 반', '1/2'도 알아들어요.
- AI에게 주는 지시문에 '팩 단위는 g으로 바꾸지 말고 그대로, 1팩 무게는 따로' 규칙을 넣었어요. 직접 저장한 음식은 AI에게 '100g 기준 값'으로 정확히 알려 줘요.
- 1g에 177kcal처럼 단위가 이상해 보이는 음식은 붙여넣을 때와 검토함 카드에서 바로 짚어 드려요.
- 이미 g로 잘못 저장된 기록은 식단 화면의 '정리할 값'에 모여요. '단위를 팩으로'처럼 한 번 눌러 그 기록만 바로잡을 수 있어요.

## 영양 막대가 한눈에 비교돼요
- 목표선이 네 막대 모두 같은 자리에 있어요. 넘친 만큼은 목표선 뒤에 줄무늬로 그려져요. 많이 넘쳐도 막대 끝은 넘지 않아요.
- 탄수화물이 목표보다 많으면 막대 아래에 '탄수화물이 목표보다 75.7g 많아요 · 밥으로 치면 약 1공기'처럼 한 줄로 알려 줘요. 다음 끼니나 예정된 식사에서 밥·면만 조금 줄이면 돼요.
