# 마이로그 베타 3.4.0

- **나에게 맞춘 마이로그.** 처음 시작할 때 질문 다섯 개로 기록 방식을 정해요. 30초면 끝나고, 건너뛰어도 돼요.
- **운동은 세 가지 방식 중에 골라요.**
  - 세트마다 바로 기록
  - 다 끝나고 한 번에: “45kg × 10회 × 3세트”처럼 몰아서 입력, 지난 운동 불러오기도 돼요
  - 미리 계획하고 안내 따라가기: 곧 제공돼요
- **식단은 ‘끼니만 간단히’도 돼요.** “점심 · 약 700kcal”처럼 빠르게 남겨요. 식단을 안 쓰면 식단 탭을 숨길 수 있어요.
- **기록할 것만 보여요.** 운동만 기록하는 분은 운동만 채워도 오늘의 헤일로가 완성돼요.
- **언제든 바꿀 수 있어요.** 설정 › 나의 기록 방식, 또는 운동·식단 화면 위쪽의 ‘기록 방식’ 버튼.
- 세트를 저장하면 휴식 타이머가 자동으로 시작돼요(기본 90초, 설정에서 변경).
- Android 앱도 같은 내용으로 업데이트됐어요.
