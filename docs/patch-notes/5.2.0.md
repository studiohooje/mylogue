# 마이로그 베타 5.2.0 (2026-11-26)

## 오늘의 타임라인이 가벼워졌어요
- 카드 테두리 없이 **시간 축 위에 바로** 놓았어요. 식사·운동이 작은 아이콘 원으로 이어져 하루 흐름이 한눈에 보여요.
- 음식은 **한 줄에 하나씩**(이름 + 양), 두 개까지 보이고 더 있으면 **'… 외 N개'**를 누르면 나머지가 보여요.
- 칼로리는 오른쪽에 크게, 영양 비율 막대는 얇게.

## 식사 기록 창이 정리됐어요
- 맨 위에서 **지난 식사에서 · 메이트로그에서 · 직접 입력하기** 세 가지 중 하나를 골라요.
- 지난 식사는 **좁은 카드**로 옆으로 넘겨 봐요. 음식은 한 줄에 하나, 이름이 길면 뒤를 '…'로 줄이고 **양(1팩·150g)은 늘 보여요**. 3개 넘으면 '… 외 N개'를 누르면 나머지가 보이고, 맨 아래 **총 칼로리**. 카드를 누르면 통째로 담겨요.

## 음식을 개수로도 넣어요
- **삶은 달걀은 '1개(≈50g)'**로 바로 열려요. 2개를 담으면 '삶은 달걀 2개'로 남아요. 'g'로 바꿔 무게로 넣을 수도 있어요.
- 바나나·사과·귤·고구마·옥수수·만두·핫도그·어묵 등 **개수로 먹는 음식**도 같아요(요리는 제외: 달걀찜·사과파이 등).
- 기본 음식 35개에 1개(장·토막·공기·캔) 무게를 넣었고, 이상하게 표시되던 단위 110개를 정리했어요.
