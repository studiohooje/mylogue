# 5.10.2 패치노트

- **오늘의 타임라인에서 운동 칸의 시각·'···'이 식사 칸과 같은 줄에 맞춰졌어요.** 운동 칸만 왼쪽으로 치우쳐 보이던 문제예요.
- **운동 요일의 '오늘' 칸이 비어 보이던 문제를 고쳤어요.** 펼친 화면·PC에서도 청록 바탕에 오늘 한 부위가 보여요.
- **타임라인 운동 칸에도 소모 칼로리가 오른쪽에 보여요.** 식사 칼로리와 같은 자리에 주황색으로 나와요(아래 요약 줄의 '약 ○kcal 소모'는 겹쳐서 뺐어요).
- **AI 인사이트 설명 글의 줄간격을 넓히고, 설명·버튼·안내 글 사이를 띄웠어요.**
- **분석의 '11월 리캡' 버튼을 새로 꾸몄어요.** 한 달 동안 차오르는 달(말일에 보름달)과 함께 'N월 리캡'이 크게 보이고, 그리는 별자리·며칠째·헤일로 수가 아래에 나와요.
