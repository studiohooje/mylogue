# 마이로그 베타 5.0.6 (준비 중 · 아직 배포 전)

## 바뀐 것
- **앱이 훨씬 빨리 열려요.** 로그인한 계정은 열 때마다 서버 확인을 기다리느라 '기록을 여는 중이에요'가 길게 떴는데, 이제 바로 내 기록이 보이고 확인은 뒤에서 해요.
- **누를 때마다 더 가벼워졌어요.** 입력 창 안에서 버튼을 누를 때 뒤의 페이지까지 다시 그리지 않아요. 페이지 이동도 빨라졌어요.
- **식사 검색이 끊기지 않아요.** 식사 창을 열면 음식 목록을 미리 준비하고, 많은 브랜드 메뉴는 나눠서 준비해 글자를 칠 때 멈추지 않아요.
- **밝은 화면**에서 영양 막대·그래프 색이 원래 밝은 색으로 보여요(전에는 흙갈색처럼 보였어요).
- **보안**: 다른 사람의 마이태그로 사칭해 초대할 수 없게 막았어요. '마이로그·운영자·관리자' 같은 말이 들어간 마이태그는 쓸 수 없어요.
- 필라테스 동작 검색이 엉뚱한 동작으로 가던 이름 몇 개를 바로잡았어요.
