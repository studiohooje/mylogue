# 마이로그 5.9.0

**코치로그가 새로 바뀌었어요(코치님용)**
- 메뉴가 세 칸으로 줄었어요: 오늘 · 회원 · 일정. 설정은 오늘 화면 오른쪽 위 ⚙에 있어요.
- 처음에 PT 트레이너인지 필라테스 강사인지 고르면, 그에 맞는 화면과 기록 방식이 나와요.
- **오늘**: 방금 끝난 수업이 맨 위에 와요. 다음 수업 카드에는 지난번 준비사항·지난 기록·주의할 점이 미리 떠요. 할 일(끝내기 전 수업, 시간 변경 요청, 이의, 남은 회차가 적은 회원 등)은 회원마다 한 줄씩 모여요.
- **수업 끝내기**: 한 번 누르면 출석·회차 차감·장부·회원에게 수업 기록 보내기·다음 예약까지 끝나요. 늦은 취소·노쇼도 여기서 고르고, 그날 안에는 되돌릴 수 있어요.
- **수업 기록**: 지난 같은 수업에서 미리 채워 두어요. 바뀐 것만 고치면 돼요. 필라테스는 스튜디오마다 리포머 회사에 맞춰 스프링을 적고, 그룹·듀엣 수업도 한 번에 끝내요.
- **수강권 장부**: 차감·노쇼·서비스 회차·홀딩이 모두 줄로 남아요. 고쳐도 원래 줄은 남고 고친 줄이 더해져요.
- **장소별 설정**: 센터 장부인지 내 장부인지, 회원에게 남은 회차를 보여 줄지, 회원에게 직접 메시지를 보낼지, 취소·노쇼 규정을 장소마다 정해요.
- **변화 리포트**: 회원의 체성분·운동 변화(필라테스는 회원이 한 말과 배운 동작)를 모아 상담에 써요.
- 통증·생리 같은 건강 정보는 코치님만 봐요.

**회원님 쪽**
- 내 코치 카드에서 수강권별 남은 회차와 '내 장부'를 볼 수 있어요(코치님이 보이게 해 둔 경우).
- 코치님이 보낸 수업 기록이 이상하면 검토함에서 '이의 있어요'를 눌러 알려 주세요.
- 코치님께 공유하는 내용은 내가 고른 범위 안에서 날짜별 하루 요약(체중·식사 끼니 수와 합계·혼자 운동)이에요. 무엇을 먹었는지는 보내지 않아요.

**그 밖에**
- 첫 화면 '마이로그 이야기'에서 예전 캐릭터 소개 칸을 뺐어요. 이야기 페이지의 색 설명에서도 예전 캐릭터 이름을 뺐어요.
- 체중이 줄어든 숫자의 빼기 기호를 한 모양(−)으로 맞췄어요.
- 달력 칸에서 '필라테스' 같은 이름이 고르게 두 줄로 나뉘어요.
- 첫 화면 문장이 어색한 곳에서 끊기지 않게 다듬었어요.
