# 마이로그 베타 4.18.0

> 4.17.2(편의점 음식·검색 정리)도 함께 들어 있어요.

## 나만의 유지칼로리
- 분석 탭에 **나만의 유지칼로리** 카드가 생겼어요. 키·체중으로 계산한 평균값이 아니라, 내가 먹은 것과 체중 흐름으로 '내 몸이 실제로 쓰는 양'을 알려 드려요.
- 헤일로가 쌓일수록 정확해져요. **21번**이면 가닥이 잡히고, **28번**이면 목표를 세울 만큼, **42번**이면 꽤 정확해요. 막대로 얼마나 남았는지 보여 드려요.
- 최근 8주 기록으로 계산해요. 기록을 오래 쉬면 예전에 계산된 값을 '대략·부정확'으로 보여 드려요.
- 식단 목표에서 **내 유지칼로리를 기반으로 계산하기**를 고를 수 있어요. 옆의 ?를 누르면(PC는 올리면) 어떻게 계산하는지 설명이 나와요.

## 목표 종류가 늘었어요
- **바디프로필·대회 준비, 체중 늘리기, 리버스 다이어트, 다이어트 휴식**을 더했어요. 리컴프는 **상승 다이어트(리컴프)**로 이름을 바꿨어요.
- 리버스 다이어트는 주마다 하루 칼로리를 조금씩 올려 유지 칼로리까지 데려가요.

## 머신 기록이 하나로 이어져요
- 같은 머신이 띄어쓰기·표기만 다르게 여러 번 등록되지 않아요(예: 뉴텍 레그프레스 = 뉴텍 레그 프레스 머신 = Newtech Leg Press). 이미 있으면 그 머신을 골라 드려요.
- 제조사가 달라도 같은 운동이면 성장·볼륨·횟수가 하나로 쌓여요. 분석의 종목 성장에서 **제조사별로 나누기**로 나눠 볼 수 있어요.
- 운동 카드에 한 운동의 그림이 차례대로 다 나와요. 직접 적은 이름이나 제조사 머신도 같은 운동 그림으로 이어져요.

## 고친 것
- 웹에서 브라우저를 닫으면 로그아웃되던 문제를 고쳤어요. 이제 직접 로그아웃할 때까지 유지돼요.
- 한 번 동의했으면 같은 기기에서 다시 묻지 않아요.
- 알림을 다 처리하면 알림 창이 저절로 닫혀요.
- 근육 지도의 파란 '회복 중' 표시는 의도적 휴식일에만 보여요.
