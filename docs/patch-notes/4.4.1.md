# 마이로그 베타 4.4.1

- 우유처럼 ml로 적은 음식을 수정 창에서 저장만 해도 열량이 1/100로 줄던 문제를 고쳤어요.
- 식사 수정에서 단위를 바꾸면(예: 210g → 1공기) 영양값은 그대로 두고 단위만 바꿔요.
- 어느 입구로 넣든 미래 시각이면 '예정'으로 들어가요.
- 예전에 넣은 예정 식사가 '먹었어요'를 눌러도 확정되지 않던 문제를 고쳤어요.
- '다른 날 식사 복사'가 끼니별로, 원래 시각 그대로 복사돼요. 예정 식사는 빼고 복사해요.
- 하단 ＋ → 식단과 '음식 하나 입력'도 빠른 검색으로 열려요.
- 새 휴대폰에서 첫 동기화 전에 기록해도 동기화가 멈추지 않아요.
- '첫 인바디 기록을 기다려요' 알림은 체중을 기록하는 분께 한 번만 보여요.
- 분석 화면은 예정 기록을 빼고 계산해요.
- 일정 화면의 휴식 표시를 운동 화면의 '의도적 휴식'과 하나로 맞췄어요.
