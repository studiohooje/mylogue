# 마이로그 베타 5.4.2 (2026-11-26)

## 코치로그 — 코치만의 화면으로 완성
- **코치로그로 바꾸면 앱 전체가 코치 색(주황·레드)**: 머리 이름도 '코치로그 · coachlogue', 배경·카드·입력 창·아래 메뉴까지 모두 바뀌어요. 아래 메뉴 아이콘도 회원 = 사람, 수업 = 덤벨.
- **코치태그**: 프로필에서 이름 + 칭호(코치·트레이너·강사·선생님·쌤·프로·원장·직접 입력·칭호 없음)를 정해요. 회원들에게만 보이는 이름이에요.
- **회원 등록**: 앱 회원 / 미가입 회원, **수업 종류(웨이트·필라테스·요가·기타)를 여러 개** 고르고, 목표·주의할 점까지 한 창에서.
- **수강권 만들기**: 횟수권·기간권, 회차·형태·기간을 칩으로 고르고 저장 전 카드 미리보기. 결제 금액은 선택이고 코치님만 봐요(회당 금액 자동).
- **수업 계획 미리 등록**: 회원의 수업 종류대로 걸러진 '이 회원과 했던 운동'(지난 무게·횟수)에서 골라 계획을 짜요. 그날만 다른 종류로 바꾸거나 필라테스 웜업 + 웨이트처럼 섞어도 돼요. 계획은 정한 방식(지금 · 하루 전 · N시간 전 · 직접 · 안 보냄)으로 회원에게 가요. 수업 시작을 누르면 계획이 띠에 보여요.
- **식단 제안(코치 전용)**: 하루 식단표(끼니별 + 목표 대비 합계·탄단지 + 대체 음식) · 끼니별 조합(아침 A·B·C…) · 한 끼만 콕. 음식은 마이로그 검색 그대로 골라요.
- **개인 운동 루틴**: 수업에서 했던 운동에서 골라(혼자일 땐 무게 -10%), 주 몇 회까지 정해 보내요. 회원이 하면 이번 주 몇 번 했는지 보여요.
- **코치 설정**: 수업 계획 보내기 기본값, 전날 출석 확인, 결제 금액 칸, 자주 쓰는 코멘트.

## 회원(마이로그)
- **내 코치 카드**: 코치님이 짠 '내일 할 운동' 보기, 출석 응답, 확정 전 수업, **지난 수업 운동으로 혼자 해 보기**.
- 식사 창 '도움받기 › 코치 제안'에서 **지금 끼니가 먼저** 보이고, 조합형은 A·B·C 중 하나를 골라 통째로 기록하거나 양을 고쳐요.
- 운동 창 '도움받기'에서 **코치 루틴**이나 **지난 수업 그대로**로 시작하면, 실시간 입력 위에 '코치 루틴 2/4 · 목표 · 다음 운동' 띠가 떠요. 끝내면 코치님께 '했어요'가 가요.
