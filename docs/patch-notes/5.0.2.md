# 마이로그 베타 5.0.2 (2026-11-25)

## 바뀐 것
- **이용 신청 없이 바로 쓸 수 있어요.** 로그인하고 처음 동의 화면에서 동의하면 곧바로 기록이 서버에 보관되고, 메이트도 바로 쓸 수 있어요.
- 예전에 '승인 대기'로 남아 있던 계정은 앱을 열면 자동으로 쓸 수 있게 돼요.
- 이메일로 가입했다면 인증 메일의 링크를 누른 뒤부터 쓸 수 있어요.
- 프리미엄(플러스)은 이제 운영자가 지정한 계정만 써요(베타 동안 모두에게 열려 있던 것을 닫았어요).

## 운영자
- 관리자 화면의 가입자 목록에서 계정마다 **플러스 켜기/끄기**, **코치 켜기/끄기**를 할 수 있어요. 코치 권한을 받은 계정은 코치로그(회원 연결·초대)를 쓸 수 있어요.
