# 마이로그 베타 3.14.0

- **검색어 추천이 생겼어요.** 음식·운동을 찾을 때 검색창 바로 아래에 추천이 캡슐 모양으로 가로로 떠요(최대 5개).
  - **한 글자만 쳐도** 돼요. ‘ㄷ’만 쳐도 닭가슴살·닭다리살·닭안심이 나와요. 초성(ㄷㄱㅅ)도 알아들어요.
  - **한/영 전환을 깜빡해도** 돼요. ‘ekfr’처럼 영어 자판으로 쳐도 ‘닭’으로 알아듣고, 운동도 ‘fp’를 ‘레’로 알아들어요.
- **대분류를 누르면 제품·머신이 펼쳐져요.**
  - 음식: ‘닭가슴살’을 누르면 내가 많이 먹은 제품부터(예: 김단단 30번 → C사 3번 → A사 1번), 그다음 다른 사용자들이 많이 먹은 제품, 마지막에 대표값이 나와요.
  - 운동: ‘레그 프레스’를 누르면 제조사 없는 일반 머신(45°·아이소래터럴 등)이 맨 위, 그다음 내가 많이 쓴 머신, 다른 사용자가 많이 쓴 머신 순서예요. ‘머신 없이’도 고를 수 있어요.
- **자주 먹는 기본 음식 48가지의 대표 영양값**(닭가슴살·현미밥·고구마·달걀·그릭요거트 등, 100g 기준)이 들어갔어요. 제품 라벨 값이 있으면 그 값을 쓰세요.
- **내가 고친 값은 따로 표시해요.** 대표값과 같은 음식을 내 기록이나 내 음식에서 다른 영양값으로 쓰고 있으면, 나에게는 항상 내 값으로 보이고 보라색 테두리와 ‘내 값’ 표시가 붙어요(다른 사람에게는 영향 없어요).
- 추천 순서를 위해 **음식·운동·머신 이름별 선택 횟수만 이름 없이 합산**해요. 누가 무엇을 먹었는지·체중 같은 기록은 보내지 않아요.
- 검색어만 입력하고 창을 닫을 때 ‘저장되지 않았어요’라고 묻던 것을 고쳤어요.
