# 마이로그 베타 5.5.0 (2026-11-27)

## 운동
- 비슷한 종목끼리 묶었어요. 벤치프레스·로우·컬처럼 같은 동작을 고르면 **다른 방식으로 바로 바꿀 수** 있어요.
- 헬스장 기구 도감이 세 배 가까이 늘었어요. 더 많은 회사의 머신을 찾을 수 있어요.
- 필라테스 동작이 더 많아졌어요. 링·폼롤러·짐볼 동작과 리포머·캐딜락 동작이 새로 들어왔고, 다른 이름으로 불러도 더 잘 찾아요.
- **머신 로우**를 고르면 기본 · 와이드 그립 · 내로우 그립 중에서 손잡이 방식을 고를 수 있어요. 그립마다 기록이 따로 쌓여요.
- 기구 도감에 **가온핏 리니어 로우**가 들어왔어요.

## 음식
- 다이어트 브랜드 제품 600여 개가 음식 검색에 추가됐어요. 도시락·간식·샐러드 소스·프로틴 음료 등이에요.

## 메이트로그
- 새로 만드는 방에서는 **체중·체성분 숫자가 기본으로 비공개**예요. 보여 주고 싶으면 방을 만들 때 켜면 돼요.
