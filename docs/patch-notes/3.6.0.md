# 마이로그 베타 3.6.0

- **내 헬스장을 이름이나 지도로 찾아 추가할 수 있어요.** 설정 › 내 헬스장에서 해 보세요.
  - **이름으로 찾기**: “스포애니 역삼역점”처럼 지점 이름이나 동네를 넣고 ‘찾기’를 누르면 주소와 함께 목록이 나와요. 맞는 곳의 ‘추가’를 누르면 끝이에요.
  - **지도에서 고르기**: 지도를 움직여 헬스장을 가운데에 두면 근처 헬스장이 아래에 나와요. ‘내 위치로’를 누르면 지금 있는 곳으로 지도가 옮겨져요. 위치는 지도를 옮길 때 한 번만 쓰고 저장하지 않아요.
  - 목록에 없는 곳(아파트·회사 헬스장)은 지도 가운데 지점에 이름을 붙여 추가할 수 있어요.
  - 지도 없이 **이름만 직접 입력**하는 방법도 그대로 있어요.
- 내 헬스장 목록에 주소가 함께 보여요.
- Android 앱은 ‘내 위치로’를 처음 누를 때 위치 권한을 물어봐요. 허용하지 않아도 지도를 직접 옮겨 쓸 수 있어요.
