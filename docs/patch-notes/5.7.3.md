# 마이로그 5.7.3

- **체중은 직접 잰 값 그대로**: 홈과 수치 페이지에 '추세 체중'(7일 평균) 대신 가장 최근에 잰 체중과 언제 잰 값인지가 나와요. 오늘 83.6kg을 적었으면 83.6kg이에요.
- **수치 페이지 윗줄이 작아졌어요**: 오늘 체중·주 페이스·30일 변화·목표까지 남은 양을 한 줄 네 칸으로 작게 보여 줘요. 작은 폰에서도 잘리지 않아요.
- **체중 그래프가 읽기 쉬워졌어요**: 세로축 숫자가 자기 눈금선 가운데에 붙고, 주간 변화는 주마다 한 칸에 값과 날짜가 함께 나와요.
- **최고 기록은 양쪽과 한쪽씩을 따로**: 한쪽씩 한 무게와 양쪽으로 한 무게를 섞어 비교하지 않아요. 한쪽씩 처음 했으면 '한쪽씩 첫 기록'으로 알려 드려요.
- **앱이 더 가벼워졌어요**: 기구 목록(약 2천 개)은 처음 켤 때 받지 않고, 쓰던 기구만 기기에 남겨 둬요. 새 헬스장·새 기구를 찾을 때만 전체를 받아요.
- **같은 음식이 두 번 나오던 것 정리**: 제조사 이름이 붙은 것과 안 붙은 것으로 두 번 보이던 제품(저당 닭가슴살 등) 67개를 하나로 합쳤어요.
- **식단 페이지 날짜도 가운데로**: 운동 페이지와 같은 자리에 날짜가 있어요.
- **메이트로그 사진 보호 한 번 더**: 서버에서도 사진의 위치·기기 정보를 지워요.
