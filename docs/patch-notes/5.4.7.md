# 마이로그 베타 5.4.7 (2026-11-26)

## 새 기능 · 한 달 리캡
- 분석 화면에 **이달의 리캡**이 생겼어요. 한 달 동안 채운 **헤일로로 실존하는 별자리**를 그려요(헤일로가 많을수록 더 큰 별자리).
- 아래에는 **몸**(체중 흐름, 인바디가 있으면 체지방·골격근) · **운동**(많이 늘어난 종목, 주마다 들어 올린 무게, 러닝 페이스) · **식단**(목표 칼로리 안에서 지킨 날)과 **이달의 업적 · 마일스톤**이 모여요.
- 리캡은 **말일에 완성**돼요. 그전까지는 지금까지의 기록으로 채워지고, 별자리를 ‘그리는 중’이에요.

## 고친 점
- **웹에서 홈 날짜를 바꾸면 큰 박스가 커지던 문제**를 고쳤어요. 이제 지난 날도 오늘과 똑같은 크기예요.
- 운동 화면 ‘이번 주 운동한 날’ 카드의 줄간격을 맞췄어요. ‘목표 바꾸기’가 글줄과 나란히 서고, 아래 안내 상자도 카드에서 알맞게 떨어져 보여요.
- 분석 화면의 예전 ‘월간 리포트 카드’는 새 한 달 리캡으로 바꿨어요.
