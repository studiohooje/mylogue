# 마이로그 베타 5.7.0 (2026-11-27)

## 헬스장
- 설정에 **헬스장 둘러보기**가 생겼어요. 기구가 등록된 헬스장을 이름이나 내 주변으로 찾고, 누르면 기준운동별로 어떤 기구가 있는지 볼 수 있어요. 빠진 기구는 '기구 추가·수정 요청'으로 알려 주세요.
- 기구 이름은 좁은 칸에서는 제조사 한글명만 보이고, **'…'**를 누르면 제조사·모델·방식 전체 이름이 나와요. 제조사마다 대표 색으로 보여요.
- 헬스장을 정하고 운동하면 **그 헬스장에서 자주 한 운동**이 기구까지 나눠서 위에 와요. 기구까지 골라 둔 기록이 많으면 그 기구 칸이 먼저 보여요.
- 오늘 운동을 시작할 때 고른 헬스장과 지금 위치가 많이 떨어져 있으면 **'이 헬스장이 맞나요?'**라고 한 번 물어봐요. 위치는 그때만 확인하고 저장하지 않아요.
