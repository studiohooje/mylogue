# 마이로그 베타 3.9.0

- **식단 목표를 추천받아 정할 수 있어요.** 처음 시작할 때(식단을 기록한다고 고른 경우) 이어서, 또는 설정 › 일일 식단 목표의 ‘추천받아 정하기’에서 언제든.
  1. 나이·키·체중(최근 몸 기록이 있으면 미리 채워요)과 평소 활동량으로 **유지 칼로리를 대략 계산**해요.
  2. 감량·유지·증량 중 목표를 고르고, GLP-1 계열 약 사용·저탄고지·간헐적 단식·채식 같은 해당 사항을 골라요.
  3. **칼로리를 여러 개 제안**해요. 예: “2,100kcal 표준 감량(주 0.5kg 안팎)”, “2,300kcal 완만한 감량”. 기초대사량보다 낮은 값은 권하지 않는다고 알려 줘요.
  4. **탄단지 비율도 여러 개 제안**해요. 예: “고단백 감량 4:4:2”, “균형형 5:2:3”, “저탄고지”, “단백질 우선(GLP-1 사용 중)”. 비율마다 하루 g, 설명, 효과, 주의할 점이 함께 나오고 나에게 맞는 것에 ‘추천’이 붙어요.
  - 잘 아는 분은 칼로리와 비율을 **직접 입력**할 수도 있어요.
- 정한 목표는 홈 ‘오늘 식단’ 카드의 부족·초과 표시에 바로 쓰여요.
- 계산은 일반 성인 기준의 대략값이에요. 질환·임신·약 복용 중이면 의료진과 상의하세요.
