# 마이로그 베타 3.10.0

- **기록을 고치기 쉬워졌어요.** 홈 타임라인의 식사·운동 카드, 식단 화면의 식사마다 **‘수정’** 버튼이 생겼어요.
  - **식사 수정**: 한 끼를 통째로 열어요. 음식마다 −/＋로 양을 바꾸면 칼로리·탄단지도 같은 비율로 바뀌어요. 음식 하나만 빼거나, 먹은 시각·끼니·날짜를 한 번에 바꿀 수 있어요. 영양값 자체를 고치려면 ‘영양값 고치기’.
  - **운동 수정**: 종목별 세트가 표로 바로 보여요. 무게·횟수·완료를 고치고, 세트를 더하거나 지우고, 종목을 뺄 수 있어요. 머신·컨디션 같은 나머지는 ‘자세히 수정’.
- **헤더의 ‘마이로그’를 누르면 홈으로** 가요(로고와 이름 전체를 넓게 눌러도 돼요).
- **오른쪽 위 내 이름을 누르면 ‘내 프로필’**이 열려요.
  - 표시 이름과 아이콘(Google 사진 · 글자와 색 · 내 사진)을 바꿀 수 있어요.
  - 처음 시작할 때 골랐던 ‘나의 기록 방식’을 여기서 바로 바꾸고, 시작 문답·식단 목표를 다시 정할 수 있어요.
  - 맨 아래 ‘그 외 설정으로 이동’으로 전체 설정에 갈 수 있어요.
- 승인된 계정에서는 이름 아래 ‘승인됨’ 표시를 없앴어요(대기·반려일 때만 보여요).
