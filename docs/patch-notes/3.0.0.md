# 마이로그 3.0.0 패치노트

**마웨로그가 '마이로그(Mylogue)'로 이름을 바꿨어요.**

- 새 이름: 마이로그 / Mylogue. 'Mylogue'는 '나와 나누는 기록'이라는 뜻이에요.
- 마이로그는 새 앱으로 설치돼요. 마웨로그와 따로 설치되니, 기존 앱은 기록을 옮긴 뒤 지우셔도 돼요.
- **기록 옮기기**: 마웨로그 → 설정 → 백업 파일 내려받기 → 마이로그 → 설정 → 백업 복원. 사진도 함께 옮겨져요.
- 예전에 AI가 만들어 준 기록 파일(JSON)도 그대로 가져올 수 있어요.
- 화면과 기록 방법은 이전과 같아요.
- 새 계정 승인: 마이로그에서 Google 로그인 후 다시 승인 신청을 해 주세요.
